# 竜騎士の条件の案（2026-11-14・オーナーの返事 4A「種類を変える案を作って見せる」）

- **このメモは案だけ。コードは変えていない。** 数はすべて【提案】。
- もと: `docs/review/2026-11-14-growth-fix.md`（竜騎士の条件「大きな敵を2体倒す」は数では直らない）。
- 狙い: 槍騎士が**ふだんしている事**で、**2つ目の鍵の中でそろう**重さにする（ほかの最上位と同じ「鍵2を終えた時に、4人に3人はそろう」）。

## 0. 今の困りごと（短く）

- 竜騎士の条件は「大きな敵を2体倒す」。大きな敵は2つ目の鍵までにほとんど出ない。
- 測った数（下の §3）: 槍騎士40人のうち、**鍵2を終えた時に大きな敵を倒していた人は、ほぼ0**（25%点・中央・75%点が全部0）。最後までにそろったのは 10/40人・平均34.5戦目（冒険のほぼ終わり）。
- そのため槍騎士の人は、ほとんどが特殊の「重装衛士」の方へ行く（重装衛士の条件は 40/40人が 16.9戦目にそろう）。**「攻める竜騎士」への道が、実際には閉じている。**
- 「跳躍の成功」は使えない: 跳躍は竜騎士の決め技で、竜騎士になって初めて手に入る（槍騎士は持っていない）。

## 1. 案（おすすめを先に）

### 案A（おすすめ）: 「戦闘の1ターン目に、物理カードを10回成功させる」【提案】

| 項目 | 中身 |
|---|---|
| どんな事か | 槍騎士の能力《突撃》（1ターン目の攻撃×1.5）と、竜牙《先駆け》（1ターン目はコスト1）の、**「最初の一撃」の遊び方**そのもの。竜騎士の跳躍（空から一撃）にもつながる |
| 4人で取られないか | 取られない（倒した数ではなく、自分のカードの成功を数える） |
| 要る物 | 小さい記録を1つ足す（カードの成功の記録に「1ターン目なら別にもう1つ数える」）。今の「物理カードの成功」の記録のすぐ横に1行 |
| 数の根拠 | **まだ測っていない**（今の記録に1ターン目の区別が無い）。鍵2を終えるまでに槍騎士が出る戦闘は 15戦前後、1ターン目の物理の成功が1戦に1回前後なので、10 は「2つ目の鍵の中でそろう」重さの見込み。作る時に growth.sim で測って、25%点に合わせる |
| 心配な所 | 測るまで数が決まらない。bot は1ターン目に守りの札を先に使う事があるので、bot の数は人より少なめに出るかもしれない |

### 案B: 「物理カードを50回成功させる」【提案】

| 項目 | 中身 |
|---|---|
| どんな事か | 槍騎士がふだん一番する事（突進突き・串刺し・足払い など、攻めの札） |
| 4人で取られないか | 取られない |
| 要る物 | **何も足さない**（拳王の「物理カードの成功35回」と同じ記録 `success:physical` をそのまま使う） |
| 数の根拠 | 測った（§3）: 鍵2を終えた時の数は 25%点 53・中央 64・75%点 72。→ **50** なら、4人に3人以上が鍵2の中でそろう |
| 心配な所 | 拳王と同じ種類の条件になる（槍らしさは薄い）。「数だけ違う」とまでは言えないが、竜騎士らしさは案Aより弱い |

### 案C: 「槍を装備して敵を2体倒す」【提案】

| 項目 | 中身 |
|---|---|
| どんな事か | 侍の「刀を装備して倒す」と同じ形。槍騎士は最初から槍（鉄の槍）なので、侍のような「拾えるかどうか」の問題は無い |
| 4人で取られないか | **取られる**（止めを刺した人だけが数える。前の大賢者の件と同じ問題） |
| 要る物 | 何も足さない（記録 `kills:weapon:spear` はある） |
| 数の根拠 | 測った（§3）: 鍵2を終えた時の数は 25%点 1・中央 2・75%点 4。2体なら中央くらい（半分はそろう）。1体なら軽すぎる |
| 心配な所 | 4人だと仲間に止めを取られて届きにくい。槍騎士は守りも担うので、倒す数そのものが少ない（倒した数の中央 3） |

## 3. 測った数（根拠）

- 道具: `src/engine/__tests__/growth.sim.test.ts`（ふつう・賢い bot・40種・4人C = 守護者→槍騎士・盗賊→怪盗・武闘家＋僧侶）。測る時だけ、鍵2を終えた時の「記録の全部」を写す1行を足して流した（**コミットしていない**。ゲームは変えていない）。
- 記録は中位になった時に0へ戻るので、下の数は「槍騎士になってから鍵2を終えるまで」の数。40人とも鍵2を終えた。

| 記録 | 25%点 | 中央 | 75%点 |
|---|---|---|---|
| 大きな敵を倒す（今の条件） | 0 | 0 | 0 |
| 敵を倒す（全部） | 2 | 3 | 4 |
| 槍を装備して倒す | 1 | 2 | 4 |
| 物理カードの成功 | 53 | 64 | 72 |
| 完全成功 | 59 | 76 | 91 |
| ブロックで防いだ量 | 133 | 192 | 229 |
| ブロック25以上のターン | 3 | 5 | 7 |

- 同じ流しで: 竜騎士の条件がそろった人 10/40（平均34.5戦目）・鍵2の中までは0人。重装衛士は 40/40（平均16.9戦目）。
- 「ブロックで防いだ量」は拳聖・重装衛士の方の条件と同じ種類で、竜騎士（攻め）の向きと逆なので、案に入れなかった。
