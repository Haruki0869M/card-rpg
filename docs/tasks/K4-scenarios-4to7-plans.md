# K4 企画シート（4本目〜7本目。すべて提案）

2本目・3本目と同じ作り方（地図・地域5・町4・ダンジョン鍵3つ＋最終＋ランダム・敵28体＋亜種5・固有装備13・依頼4〜5・祠4・突発イベント5＋ダンジョン用6・ボス手前の物語の部屋と、制覇後の物語）。量は同じなので、ここでは**違い**だけを書く。台詞は「1場面2〜4行・1行30字まで」。

**解放の条件（K5 の `unlockRequires`）**: 2本目は侵食の魔王、3本目は凍てつく王国、4本目は呪われた群島、5本目は砂塵の王朝、6本目は星降る天空城（それぞれ前の本をクリア）。7本目は他の6本すべてをクリア。

## 4本目「砂塵の王朝」（遺跡と砂漠）
- **筋**: 砂に埋もれた古い王朝の王が、永遠の命を求めて民の魂を砂に変えている。三つの聖印を集め、砂塵の王を眠らせる。
- **違い**: 昼は暑さ・夜は寒さでHPが減る。オアシスのマスで休める。
- **地域**: 砂の入口（暑さなし）→ 日干し煉瓦の廃墟街 → 砂丘の海 → 王家の谷 → 砂塵の王宮。
- **ダンジョン（ボス）**: 蠍の墓所（砂蠍王）→ 影の書庫（影の宰相）→ 石像の神殿（砂の守護獣）→ 最終「砂塵の王宮」（砂塵の王。3段階）。
- **敵の方針**: 蠍・ミイラ・砂の精・石像・蛇・盗掘者の亡霊。雷と毒が主。ミイラは火に弱い。
- **必要なエンジン作業（共通で先に作れる）**: 寒さ・暑さの設定に「昼だけ／夜だけ」（`ClimateDef.when`）を足す。他の地域は昼の暑さ、夜の寒さを同じ地形で出せる。小さな作業（1段）。

## 5本目「星降る天空城」（浮島と星）
- **筋**: 夜空から落ちる星のかけらが、天空城の主「星読みの女王」を狂わせている。三つの星環を集めて星の暴走を止める。
- **違い**: 夜が長い（時間帯の長さが夜に偏る）。夜に強い敵と、夜だけ現れる名所。星を読む（占星術師の「星読み」）と役に立つ場面が多い。
- **地域**: 雲の港 → 風の回廊 → 星見の丘 → 月の庭園 → 天空城。
- **ダンジョン（ボス）**: 風車の塔（風の番人）→ 星見の天文台（星の司書）→ 月光の庭（月の乙女）→ 最終「天空城」（星読みの女王）。
- **敵の方針**: 星のかけら・風の精・天使の像・月の獣・時計仕掛けの兵。聖と闇、雷が主。
- **必要なエンジン作業**: シナリオごとの「夜の長さ」（`turnsPerTimeOfDay` を時間帯別に）と、夜だけ出る名所/イベント（`night` はイベントにある）。小〜中の作業。**後回しも可**（夜が長いだけなら、敵の夜のレベル加算の設定のみで足りる）。

## 6本目「機械仕掛けの帝国」（歯車と蒸気）
- **筋**: 暴走した大機械が、国じゅうの人を歯車の部品にしようとしている。三つの動力核を壊して、大機械を止める。
- **違い**: 蒸気の吹き出すマス（暑さの設定を流用、昼夜なし）。罠と仕掛けの判定が多く、機工士・銃・罠師が活躍する。
- **地域**: 煙突の街 → 歯車の工場 → 蒸気の谷 → 動力炉 → 大機械の心臓部。
- **ダンジョン（ボス）**: 歯車の工場（工場長ゴーレム）→ 蒸気の発電所（暴走ボイラー）→ 時計塔（時計仕掛けの賢者）→ 最終「大機械の心臓」（大機械。3段階）。
- **敵の方針**: 機械兵・蒸気の精・歯車の虫・砲台・人形。雷が弱点、毒は効かない（耐性）が多い。
- **必要なエンジン作業**: **なし**（暑さの設定を流用）。罠の部屋は既存の「仕掛けの判定」イベントで足りる。

## 7本目「夢幻の大迷宮」（総集編）
- **筋**: 6つの世界の記憶が混ざった夢の迷宮。過去の6体の悪が夢の形で蘇り、迷宮の主「夢喰い」が現実を呑もうとしている。
- **違い**: 他の6本の世界の景色・敵の再登場（亜種ではなく**同じ絵を使い回した強化版**）。ボスは過去の6体の再来。
- **地域**: 6つ（各シナリオの景色を1地域ずつ）→ 夢の最奥。
- **ダンジョン**: 鍵は「夢の欠片」3つ。ボスは過去のボスの再来から3体（砂塵の王・亡霊提督・氷の女王など）、最終は夢喰い。
- **敵の方針**: 28体のうち、再登場の敵（強化版・新ID）を中心にし、絵を新しく作る敵は10体前後にして、描き直しを減らす（亜種2割の決まりの例外にする。**オーナーの確認が必要**）。
- **必要なエンジン作業**: 解放条件「6本すべてクリア」（`unlockRequires` で書ける。**エンジン作業なし**）。他のシナリオの地形を混ぜる（地域の `terrain` で書ける）。
