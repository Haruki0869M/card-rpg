### 2-1. 大きさ

| | 今 | 新しい形（提案） |
|---|---|---|
| 幅 × 高さ | 8列 × 35行（280マス） | **15列 × 42行（630マス・2.25倍）** |
| スタート | [3,33] | [7,40]（真ん中の下） |
| 地域の行（シナリオ1） | [0,2]・[3,9]・[10,20]・[21,27]・[28,34] | [0,2]・[3,11]・[12,24]・[25,33]・[34,41]（同じ比率で 1.2倍） |

- 幅を**奇数の15**にするのは、真ん中の列（7列目）に街道を通せるからです。依頼の範囲（14〜16列・40〜44行）の真ん中です。
- **古い保存は今の大きさのまま**です。地図（幅・高さ・全部のマス）は保存データに入っていて、読み込む時に作り直さないので、何もしなくても守られます（段階1で 49→35行にした時と同じ仕組み）。幅が変わるのは初めてなので、「地図のデータの幅」ではなく「保存の中の幅」を見ているかを全部確かめます（今、データの方を見ているのは `world/start.ts:11` の1か所だけで、そこは古い地図のスタートを探す用なので問題ありません）。
- 保存の版は **v17 のまま**の見込み（足す項目は全部「省略できる項目」にする）。

### 2-2. 3つの道と、寄り道の地形

今の作り（`src/engine/game/world/generate.ts`）: 行ごとに地域が決まり、マス1つずつ地域の割合で地形をくじ引き → 町・ダンジョンを近い順に道でつなぐ → 宝箱・イベント・祠・敵を地域の中のどこかに置く。**横の位置には意味がありません。**

新しい作り（提案）: 地図のデータ（`ScenarioMapDef`）に、次の4つを足します。エンジンは「データに書いてあれば使う」だけで、シナリオの名前で分岐しません。

| 足すデータ | 中身 | 例（シナリオ1） |
|---|---|---|
| **帯**（`lanes`） | 列の範囲に名前と地形の割合を付ける。地域の割合に掛け合わせる | 西 0〜4列: 森が多い／中央 5〜9列: 平原と街道／東 10〜14列: 丘・山・遺跡 |
| **街道の骨格**（`highway`） | 中央の街道が通る点の並び。町と最後のダンジョンを結ぶ | 王都 [7,40] → 森の村 [8,31] → 沼の集落 [6,20] → 麓の村 [8,10] → 魔王城 [7,0] |
| **仕切り**（`barriers`） | 帯の間に置く山・湖の列と、通り抜けられる切れ目（峠・橋）の数 | 4〜5列目と 9〜10列目に、行の半分くらいの長さで。切れ目は地域ごとに2つ |
| **置く物の帯の指定** | 宝箱・イベント・祠・ランダムダンジョン・祭壇を「どの帯に多く置くか」 | 祠と薬草 = 西／ランダムダンジョンと祭壇 = 東／町 = 中央 |

- **鍵のダンジョン**は、街道から3〜5マス外れた西と東に交互に置き、細い脇道でつなぎます（1つ目 = 西の森 [3,27]・2つ目 = 東の遺跡 [11,16]・3つ目 = 西 [4,4]。提案）。「鍵を取りに行くと、自然に西や東の寄り道の入口に立つ」形です。
- **寄り道の地形**（提案）: 仕切りの山で3方を囲んだ**盆地**（入口1つ）を、真ん中の3地域に1つずつ。中には必ず 良い宝箱（装飾箱以上）か祠 を置きます。**半島**は、湖に突き出した行き止まりの先に宝箱。どちらも「見えているが、回り道しないと入れない」場所です。
- **薬草**（提案）: 西の帯に、新しいマップのイベント「薬草の群生地」（回復の消耗品を1〜2個もらえる。乱数は冒険の Rng）を置きます。
- **歩いて行けない物を作らない**: 今と同じく、ランダムに置く物は「スタートから歩いて行けるマス」にだけ置きます。固定の施設は道でつなぐので必ず行けます。仕切りを置いた後に「全部の固定の施設と、全部の帯に行ける」ことをテストで確かめます（7本 × 種100個）。
- **乱数**: 新しい冒険の地図は今までと別の物になります（古い保存の地図はそのまま）。地図は冒険を始めた時にホストで1回だけ作られ、保存データとして全員に配られるので、**オンラインでも保存して再開しても同じ地図**です。`Math.random` は使いません。

**物の数（1本あたり・提案）**: マスは2.25倍ですが、物は約1.7倍にして、少しまばらにします（広さを感じられるように。戦闘の数を増やしすぎないように）。

### 2-3. 街道ボーナス

- **決まり**: 手番のキャラが街道のマス（そのシナリオの `roadTerrain`）に立って移動のサイコロを振ると、**「街道 +1」**が付く。振り直しても付いたまま。
- **作り方**: 地形のデータに `moveDiceBonus: 1` を足し（街道だけ）、`rollMove`（`world.ts:218`）がサイコロのボーナスの一覧に足す。乱数は増えません（足し算だけ）。サイコロの画面の「＋1（街道）」は、今の「＋1（素早さ）」と同じ出し方で出ます。振る前のボタンにも「街道ボーナス +1」と出します。
- 町・ダンジョンのマス（施設は街道の上にある）でも付きます。船の上では付きません。
- 1台で遊ぶ時の P2 以降・オンラインは、今の移動のサイコロと同じ操作なので新しい危険はありません（操作は増えない）。自動プレイ（bot）は何もしなくても恩恵を受けます。

### 2-4. 見取り図と縮小（スマホの縦画面）

今の作り: 1倍 = 「横8列が画面にちょうど収まる大きさ」（390px でマスの幅 約46px）。縮小は1倍まで（`mapZoom.ts` の `ZOOM_MIN = 1`）。マスの半径には下限18pxがあり、15列にすると**何もしなくても横にはみ出して横スクロール**になります。

新しい作り（提案。依頼は「縮小の下限 または 見取り図」ですが、**両方**をおすすめします）:

| 物 | 中身 |
|---|---|
| 1倍の大きさ | **今と同じマスの大きさ**（横に約8.5列が見える）。広い地図は横にもスクロールする。キャラ・お供・施設の絵の大きさは今のまま |
| 縮小の下限 | **横15列が画面に収まるまで**（約0.55倍。390px でマスの幅 約25px）。0.75倍より小さい時は、小さい文字と飾りを消して、施設の印だけにする |
| **見取り図ボタン**（🗺） | ワンタップで、大陸全体を1画面に出す（390×844 で 約240×570px、360×640 でも収まる）。地形は色だけ、街道は線。**印**: 自分たち（席の色）・町・鍵のダンジョン（済みは✓）・**次の目的地（光る）**・見つけた塔・ランダムダンジョン・💀災厄。霧の中は暗いまま。印を押すと、見取り図を閉じてその場所へ地図を動かす |

- 見取り図は絵の箱庭を描かず、色の点だけなので軽いです。
- **重さの心配**: 箱庭の景色は、地図の広さに合わせて分割して描き、画素の上限（350万）で解像度を自動で下げる作りです（`LandscapeLayer.tsx:31,79`）。広さが2.25倍になると、今より少し粗くなるかもしれません。`scripts/world-perf.mjs`・`world-zoom.mjs` で 360・390 幅を確かめ、粗さが目立つなら上限を上げるか、見えている所だけ描く形にします（やってみないと分かりません）。

- **出る場所（提案）**: 西か東の帯の、街道から3マス以上離れた歩けるマス。世界マップにいるキャラから 5〜9マス。置けるマスが無ければ次のワールドターンにもう一度試します（出現スポットと同じ作法）。**動きません**（巣にいる）。

## 6. 60分に収まるかの見積もり

依頼の配分: **マップと寄り道 25分 ＋ ダンジョン 35分**（鍵 8分×3 ＋ 最後 12〜15分）。

### 6-1. 測り方（軽い測定・2026-11-11）

- 「分」は時間の式の値で、人の実際の時間とは合いません（前の測定では、人は式の約0.2倍。`volume-measure.md`）。**番の数と侵食度で比べます。**

### 6-3. 読み取れること（正直に）

1. **地図の広さそのものは、番の数をあまり増やしません。** 縦が1.2倍になっても、街道ボーナス（平均の移動力 約4.5 → 5.5）がほぼ打ち消します。まっすぐ進む時の差は +1〜6%（侵食度で +0〜7ポイント）。
2. 世界マップの操作の時間は、式の上で冒険全体の **約5〜8%**（2人で約8〜11分／150分）です。時間のほとんどは戦闘です。つまり **60分に収まるかは、地図の広さより「戦闘の数」（今 38〜40戦 → 目標 25〜32戦）で決まります。** これは段階3・8の仕事です。
3. **シナリオ1は、今の時点でもう時間切れが多い**です（今の地図でも、直行2人の12本中5本が侵食度100%）。段階2で「扉1つ＝番1回」にして、ダンジョンの中の番が約2倍になったためです（段階2の記録 §2）。
4. **寄り道の値段（見積もり。測っていません）**: ランダムダンジョン1か所 = 入る +2% ＋ 中の番 4〜5回 × 0.5% ＋ 行き帰り 2〜4番 = **約+6〜8%**。災厄1体 = 行き帰り 3〜5番 = **約+3〜5%**。依頼の「ランダムダンジョンや災厄で装備を整える」遊び方（2か所＋2体）をすると **約+20%**。今の「最後のダンジョンに入る時 51〜63%」に足すと 70〜85% で、最後のダンジョン（13行 = 約+8.5%）は**1回しか挑めない**計算です。
5. そこで **「寄り道のご褒美に浄化を付ける」（提案）**: 災厄を倒すと **どれでも侵食度 −3%**（死霊術師は −5%）、ランダムダンジョンを制覇すると **−2%**。寄り道の値段を半分くらい取り戻せて、「寄り道しないと勝てないのに、寄り道すると時間切れ」という板ばさみを防げます。敵の強さは変えないので、難易度を下げる変更ではありません（寄り道しない人には何も変わりません）。数字は段階7で測って決めます。
6. **分からない所**:
   - 人が遊んだ時の分数（式と人の比が、広い地図でも同じかは分かりません。見取り図や横スクロールで迷う時間は bot には出ません）。
   - 仕切りの山を置いた時の回り道の長さ（切れ目の数で変わります。段階6の最初に同じ測り方で確かめます）。
   - ほかの6本（測ったのはシナリオ1だけ。呪われた群島は船があるので別物です）。
   - 種12個は少ないので、±2ターンくらいのぶれがあります。
