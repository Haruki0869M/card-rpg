# 難しさを元に戻す案（2026-11-12・案）

**これは案です。コードは変えていません。**（測るために一時的に数字を変えましたが、元に戻してあります）

## なぜ

今日の変更（カードの能力の「敵を倒した時」の直し・必殺技6枚・新しい札6枚など）で、自動プレイのクリア率が少し上がりました。オーナーの決定: 敵を強くして元に戻す（カードは弱くしない）。

## 測った結果（ふつう・各60回・自動プレイ）

| 敵のHP | 4人 | 3人 | 2人 |
|---|---|---|---|
| 今日の最初（20回ずつ・参考） | 0% | 0% | 10% |
| **今**（何も変えない） | 8% | 10% | 13% |
| 敵のHP +5% | 7% | 8% | 12% |
| **敵のHP +10%** | **3%** | 8% | **7%** |

- 60回でも、1回は約1.7%です。数%の差は、まだ偶然の幅に入ります。
- 「今日の最初」は20回ずつなので、本当の値は 0〜数% のどこかです。
- これは自動プレイ（決まった動きをする bot）の数字です。憲章のとおり、bot が勝てるかどうかを合格の線にはしません。難しさが動いた向きを見るための物です。

## 案【提案】

変えるのは `balance.ts` の「人数ごとの敵のHPの倍率」だけです。敵の攻撃・カード・装備は変えません。

| 人数 | 今 | 案A（+10%） |
|---|---|---|
| 1人 | 0.6 | 0.6（変えない。1人は測れていないため） |
| 2人 | 1.0 | 1.1 |
| 3人 | 1.35 | 1.49 |
| 4人 | 2.2 | 2.42 |

- 案Aで、4人と2人はほぼ元の難しさに戻ります。3人は 8% で、少し高いままです。
- 戦闘が少し長くなります（敵のHPが1割増えるため）。60分の密度に響くようなら、HPではなく敵の攻撃を上げる案に切り替えます。

## 決めてほしい事

1. **敵のHP**
   - A【おすすめ】: +10%（2人・3人・4人）
   - B: +5%（ほとんど変わらないので、おすすめしません）
   - C: +10% にして、3人だけ +15%（1.55）。作る前に60回で測って、数字を報告します
2. **1人プレイ**
   - A【おすすめ】: 今回は変えない（自動プレイで1人を測る仕組みが無いため。測れるようにする事は、別に相談します）
   - B: 1人も +10%（0.66）にする（測らずに変える事になります）
