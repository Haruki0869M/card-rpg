# 測る道具（直行 bot と工夫する bot）を作った記録と、今の難しさ（2026-11-13）

計画は docs/tasks/overhaul-plan-v2.md §5-3。作ったのは Opus 5.5 の作業役、見直しは Fable。**ゲームの中身は変えていない**（bot と測定のテストだけ）。測った表の全部は docs/review/2026-11-13-balance-two-bots.md。

## 結論

- **直行 bot（寄り道しない・転職しない）は、ほぼ勝てない（5〜10%）。** 憲章4 の狙いどおり。
- **工夫する bot（転職する・レベル上げをする・弱点と BREAK を使う・寄り道する）は、ほぼ勝つ（85〜93%）。** 計画の目標（2人 35〜50%・4人 30〜45%）の約2倍。
- つまり今は、「工夫すれば、だいたい勝てる」釣り合い。オーナーの方針「難しめが良い」から見ると、**やさしすぎる可能性が高い**。

## どの工夫が効いているか（工夫を1つずつ外して測った。各20回）

| 外した工夫 | 2人 | 4人 | 読み取れる事 |
|---|---|---|---|
| （全部入り） | 85% | 93% | |
| 転職を外す | 45% | 45% | **転職がいちばん効いている** |
| 戦闘の工夫（弱点・BREAK・連携・敵の行動への手）を外す | 65% | 75% | 次に効いている |
| 技を磨くを外す | 90% | 80% | あまり変わらない |
| 寄り道（ランダムダンジョン・災厄）を外す | 95% | 100% | **寄り道をしない方が、勝ちやすい** |

- 「レベル上げはするが転職しない」普通の bot は 3〜8%。転職するだけで大きく変わる。
- 寄り道は今、ご褒美（専用の装備・浄化）より、損（侵食度と時間）の方が大きい。憲章2 の「強烈な誘惑」になっていない可能性がある。
- 戦闘が短い（1戦 2.4〜2.8 ラウンド。目標は 4〜6）。敵の特殊な行動は「3つ目の行動」「次の番に効く」物が多いので、出る前に戦闘が終わっているかもしれない。
- 戦闘の数が多い（36〜39戦。目標は 25〜32戦）。

## bot の限界（正直に）

- bot は、転職で Lv1 に戻っても、すぐにレベル上げをやり直す。人が同じだけレベル上げをするかは分からない。bot の方が有利かもしれない。
- bot は、1人が全員を動かす形で測っている。2人で相談する時の迷いは入っていない。
- bot は、町の店で装備を買わない・「浄化の前に起爆する」などの細かい手は打たない。こちらは、人の方が有利。
- 40回ずつなので、1回は2.5%。数%の差は偶然の幅。

## 工夫する bot に入れた工夫

ランダムダンジョンに1か所寄る・災厄を1体倒しに行く（塔に登って探す）・格が上の装備に付け替える・その場でできる転職をする・弱点のカードを優先する・大技を BREAK で崩す・連携の順に出す・休憩で技を磨く。敵の特殊な行動への手（手数読みは3枚で止める・盾砕きの時はブロックに頼らない・仲間を呼ぶ敵と浄化する敵を先に狙う・かばう敵へ単体攻撃を向ける・癒し封じの前に回復する）。画面に出ている情報だけで決める（乱数やこれからの結果は見ない）。

## 次に決める事（オーナーと）

数字合わせは、道のり6（総仕上げ）の仕事。先に、オーナーが遊んだ手ごたえを聞いてから決める。考えられる向き:
1. 転職した後が強すぎないか（転職で前のジョブの力を1つ持ち越す・レベル上げをやり直せる）。
2. 後半（3つ目の鍵〜魔王城）の敵が、転職したパーティに対して弱くないか。
3. 寄り道のご褒美と損の釣り合い。
4. 戦闘が短すぎないか（敵のHP・敵の特殊な行動が出る前に終わる）。
