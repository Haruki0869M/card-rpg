## 気になる点

**強すぎるかもしれない物**
- **王家の杖《王の裁き》**: 大賢者の《万象》（弱点×1.3）と掛け算になります（1.3×1.25＝約1.6倍）。測って強すぎれば×1.2に下げます。
- **記憶の杖《追憶》**: フェーズ2の決め技を2回撃てると強すぎるので、【提案】決め技は対象外にします。装備から「もう一度」を使うのは初めてなので、マナが増える魔法などをテストで確かめます。
- **太陽の錫杖《日輪の祈り》**: 聖光は最大5（+75%）。ためるのに最短5ターンかかり、小さな聖属性の攻撃でも全部消えるのがブレーキです。フェーズ2で聖光を配るカードが増えた時に見直します。
- **夜明けの外套《夜明けの加護》**: フォーカス1つで「ブロック5＋1枚引く」は良い取引です。強ければブロック4にします。
- **潮騒の杖《満ち潮》**: 4人で守り役がいると、ほぼ常に発動します。8という線は遊んで調整します。
- **星環の錫杖《星の導き手》**: 占星術師の持ち味（1戦闘1回）より多い2回です。占星術師は錫杖を持てないので重なりませんが、持ち味を守るなら1回にします（決めてほしい事の2）。

**今より弱く・難しくなる物（わざとです）**
- 歯車の守護鎧・千年の包帯・夜明けの外套・星屑の鎧は、毎ターンのブロックが無くなります。鎧としての守りは最大HP+20だけです。
- 千年の包帯は、敵が毒・呪いを使わない戦いでは何も起きません（自分で毒・呪いを受ける手段があるジョブ向け）。解除のカードと噛み合わないことを説明文に書きます。

**協力プレイ・1人プレイで気を付ける物**
- **星環の錫杖**: 星読みは「保存して再開しても、オンラインでも同じ結果」が最重要です。仕組みは通っていますが、装備から使うのは初めてなので、2人・4人・オンライン・保存再開で確かめます。
- **提督の外套（そのまま）**: 1人の時は自分だけブロック3で、4人向けの性格がはっきりします。共通の守りの護符（全員ブロック2）と同じ形のままです。
- **星屑の鎧・星座の杖・灯台守の錫杖**: 4人で一番生きますが、1人でも自分に効きます。
- **歯車の守護鎧**: 召喚士・機工士の召喚と並んだ時の表示と数え方を確かめます。

**作る時に確かめる小さな点**
- 火花の指輪: 雷3と火傷1は、別々の敵に当たることがあります（ランダムを2回引くため）。能力の雷でも「痺れ30%」が出るかを確かめます。コストを下げて0になったカードも数えます【提案】。
- 嵐の指輪を残すので、雷に変える指輪は呪われた群島だけで手に入ります。
- 春告げの錫杖は、共通の目覚めの錫杖（回復3＋ブロック2）と近いままです。
