4. 戦闘の数・1戦あたりのラウンドは、大きくは変わっていません（少し減ったのは、侵食度で早く終わる冒険が増えたためと、乱数の流れの違いです）。段階3の「1.5倍以上」を見る時の元の数字は、今の **3.6〜4.5** です。
5. bot は「技を磨く」「周囲の警戒」を使いません（休憩は「休む」固定）。人が使えば、ここの数字より有利になります。

今の値は **+0.5%**（`BALANCE.corruptionPerDungeonTurn`。この段階では変えていません）。試しに +0.25% にした時も測りました（`VOL_RATES=dturn=0.25`）。

**Claude のおすすめ（提案）: 段階3が終わるまでは A（今のまま +0.5%）で進め、段階3の測り直しの時に決める。** 理由:
- 「難易度は下げない」の決まりに合う（A は難しくなる方向）。
- 段階3（BREAK・連携・敵の強さの基準）で戦闘の勝ち負けが大きく変わるので、今ここで侵食度だけを合わせても、もう一度合わせ直しになる。
- ただし、オーナーが遊んでみて「敵に負けるより先に時間切れになる」と感じたら、B か C に下げるのが良いです（数字1つの変更で済みます）。
