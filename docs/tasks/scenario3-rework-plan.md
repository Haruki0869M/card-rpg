## 0. 結論（先に）

1. **今の群島は、シナリオ2の作り直し前と同じく「憲章の前の姿」**（8列×35行・3つの道なし・災厄なし・ダンジョン4か所は型の写し）。それに加えて、**群島だけの困り事が3つ**あった（確かめた）:
   - 地図のイベントが**2種類しか無い**（11か所に「潮騒の石碑」「流れ着いた樽」だけ。しかも依頼の名所の石碑が、ふつうのイベントとして何個も出る）。
   - 敵の組が**陸16＋海16＝32組**。シナリオ2の作り直しと同じ「約1.7倍」にすると54組になり、憲章の「全32〜40戦」を越える。**海の敵も数に入れて、合わせて約34組**にする。
   - 広い地図の仕組みの多く（見晴らしの塔・神殿と祭壇・陸の敵の置き場・災厄の置き場・抜け道）は、**「スタートから陸を歩いて行けるマス」だけ**を見る。海で切れた島には、塔も祭壇も災厄も置かれない。だから**中央の街道は海で切らない**（船が要るのは西の海と、一部の島）。
2. **3つの道の軸は「潮（時間）」**【提案】: 西「外海の航路」= 昼（朝・昼）だけ開く**潮の水道**、東「呪いの島々」= 夜（夕方・夜）だけ開く**干潟**、中央「桟橋の街道」= いつでも通れるが魔物が多い。シナリオ1（安全・速い・危険）ともシナリオ2（寒さ）とも違う「**今、どの道が開いているか**」の悩み。
3. **災厄は、群島だけの3体＋共通の「瘴気を紡ぐ死霊術師」**【提案】。悪さ・加護・段階は、今の8体（シナリオ1の5体・シナリオ2の3体）と全シナリオのボスの段階と比べて、同じ決まりにならない物にした（§3-2 の表）。専用の装備は今の固有の品を移す（3つとも武器でないので、どのパーティにも出る）。
4. **ダンジョン4か所の並びは、`dungeonShape.test.ts` の決まりを全部守る形を、計画の段階で1行ずつ書いて確かめた**（§3-4。沈んだ聖堂で2回止まった失敗を繰り返さない）。イベントの2回使いも直す（新しいダンジョンのイベントは足さない）。

### 1-3. 調べていて見つけた事（確かめた）

1. **広い地図の仕組みの多くは「スタートから陸を歩いて行けるマス」だけを見る**（海は数えない）:
   見晴らしの塔（`explore.ts:31-41 walkableFrom`）・神殿と祭壇（`sanctuaries.ts:36-41`）・広い地図の陸の敵の湧く場所（`wanderers.ts:17-27 landReach`）・災厄の置き場（キャラから陸を歩いて。`scourges.ts:98-105`）・抜け道（`detour.ts:200-205`）。
   一方、宝箱・イベント・祠・ランダムダンジョンの置き場は**海を渡れる物として**数える（`generate.ts:124-136 walkable`）。
   → **海で切れた島には、塔・神殿・祭壇・陸の敵・災厄が置かれない。** 中央の街道が海で切れると、それより上の地域ぜんぶがそうなる。
2. 街道の骨格は海のマスを道にしない（`generate.ts:184` の `continue`）。海を通る所は、道が切れたまま海として残る。見取り図の「街道」も海を飛ばす（`guide.ts:183`）。
3. 仕切り（`BarrierDef`）の「通れない地形」の判定は「海でなく、移動力0」（`generate.ts:48`）。**海は仕切りにならない**（船ならどこでも渡れる）。仕切りには、海でも陸でもない「通れない地形」（今は `crag`・`water`・`lava`）が要る。
4. 地図のイベントのくじ（`generate.ts:250`）は、名所（`landmark`）も `placed` が無ければ入る。**シナリオ2の「春の歌の石碑」も同じ**（別件。シナリオ2の地図のイベントも、温泉を除くと2種類）。

6. 画面の確認の台本 `three-roads.mjs` は、**シナリオを選べない**（環境の変数は `DEBUG_SMALL` だけ）。シナリオ2の計画では「選べるようにする」だったが、今の台本には入っていない。`scourge-7b.mjs` は `SC7B_SCENARIO` で選べる（シナリオ2だけの確かめが `:272` にある）。

## 3. 作る物（柱ごと）

### 3-1. 柱1 地図と3つの道

**地図【提案】**: 15列×42行。地域は**5つ・今の並びと id のまま**、行だけ広げる（沈没船の海 0〜2／呪われた島々 3〜11／霧の海域 12〜24／珊瑚の浅瀬 25〜33／港の島 34〜41。シナリオ1・2と同じ行の幅）。`landAround: 1` は残す。

**3つの道【提案】**: 軸は「**潮（時間）**」。潮は世界の時間で決まる（朝・昼 = 満ち潮、夕方・夜 = 引き潮。4ワールドターンごとに入れ替わる。乱数を使わない）。
