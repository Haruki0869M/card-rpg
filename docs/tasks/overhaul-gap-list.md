印の意味:
- **◎ 依頼どおり** … 依頼の文・数字のとおり
- **○ 段階3で寄せた** … 前は違っていたが、段階3で依頼文に合わせた
- **△ 変えて作った** … 理由があって、依頼と違う形にした
- **× 作っていない** … まだ無い
- **→ 段階4** … 計画書の後の段階でやる
