## 条件と記録（後続段階で職のrequiresへ設定する）

| 職 | 元の職 | 条件 | 記録キー |
|---|---|---|---|
| 侍 | 剣豪 | 刀を装備して10体撃破 | kills:weapon:katana |
| 魔剣士 | 剣豪 | 属性攻撃で10体撃破 | kills:element |
| 時魔道士 | 大魔導士 | マナ累計50消費 | mana |
| 死霊術師 | 呪術師 | 呪われた敵を5体撃破 | kills:cursed |
| 暗黒騎士 | 聖騎士 | HP30%以下で5体撃破 | kills:lowHp |
| 巫女 | 司祭 | 祠で3回祈る | prayers |
| 占星術師 | 司祭 | 運判定の完全成功5回 | perfects:luk |
| 機工士 | 弓術士 | 罠・仕掛け判定の成功5回 | checks:mechanism |
| 吟遊詩人 | 怪盗 | 仲間を助けるカード10回 | support:others |
| 賭博師 | 怪盗 | 運判定の成功10回 | checks:luk |

新設の記録は過去を推測せず0から。既存の記録は再利用する。
祈りは恵みを受けたキャラに加算。宝箱の運判定は1枠以上の成功、完全成功は全枠成功（フォーカス込み）。
機構の判定は `purpose: 'mechanism'`。宝箱解錠・罠の回廊・鉄の罠解除・毒針の野営地が対象。
仲間支援はカードの直接効果で生存する他の味方に実際の利益があった時だけ1使用1回。従来のsupportは変更しない。
判定の拒否・画面描画・再送で記録や乱数を進めない。
