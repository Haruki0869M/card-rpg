# 手番のカットインの計画（2026-11-08・OK待ち）

オーナーの声: 「いつ自分のターンが来たのか分からない。特にワールドマップとダンジョンの切り替わりで、自分のターンが来たらいきなり画面が切り替わるので少しびっくりする。キャラのターンが来たことを示すカットインがほしい」

この文書の「【提案】」は Claude が決めた所です。

## 1. 今の作り（調べた結果）

- 手番は `game.world.turn`（キャラのID）。ダンジョンの組も同じ順番に入る（探索力の手番）。
- 画面の切り替えは `store/battleStore.ts` の `commit`。手番が変わり、その新しい手番のキャラを**この端末で操作する**なら、そのキャラのいる場面（世界マップかダンジョン）へ**すぐ**切り替える。前ぶれは無い。
- 世界マップの下に「現在は P1（レオン）の手番です」の帯はあるが、ダンジョンの画面や場面が変わる時には目立たない。
- 世界マップの移動の演出（駒が1マスずつ動く）が終わってから画面が切り替わる仕組みはある（`worldMoves`）。

## 2. 作るもの【提案】

### 2.1 自分のキャラの番が来た時: 大きなカットイン
```
┌─────────────────────────────┐
│░░░░░░░░ 暗くなる ░░░░░░░░░░░│
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ │
│  [顔]  P2 ルーシア の番！      │ ← プレイヤーの色の帯が横から滑り込む
│        翠の神殿（ダンジョン）   │ ← どこで動くか（世界マップ／ダンジョン名）
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━ │
│░░░░░░░░░░░░░░░░░░░░░░░░░░░░░│
└─────────────────────────────┘
```
- 出る時: 手番が変わって、新しい手番のキャラをこの端末で操作する時（1台で回す時は毎回。オンラインでは自分の番の時だけ）。
- ダンジョンの組の番なら「レオンたちの番！ 翠の神殿」と組の名前で出す。
- 出し方: 画面が暗くなり、プレイヤーの色の帯が横から滑り込む→約1.2秒で消える。**タップですぐ消せる**。
- **画面の切り替えはカットインの後ろで行う**。カットインが画面を覆った状態で場面が切り替わり、消えると新しい画面が見える（いきなり切り替わって見えない）。
- 世界マップの移動の演出や戦闘の結果の表示が残っている時は、それが終わってから出す。
- 1台で回して遊ぶ時は、帯の下に「スマホを P2 さんに渡してください」と小さく出す（オンラインでは出さない）。
- 振動の設定がオンなら、短く1回振動。

### 2.2 ほかの人のキャラの番が来た時: 小さなお知らせ
- 画面の上に「P2 ルーシアの番です（翠の神殿）」と約1秒。操作は止めない（オンラインで、自分の番でない時）。

### 2.3 設定・時間
| 設定 | 自分の番のカットイン |
|---|---|
| 通常 | 約1.2秒（帯が滑り込む） |
| 高速 | 約0.6秒 |
| カットイン「簡易」 | 約0.6秒・滑り込まず、ふわっと出るだけ |
| スマホの「動きを減らす」 | 動き無し・表示だけ約0.6秒 |
- 時間は `balance.ts` の `TIMING` に置く。

### 2.4 変えない所
- **見た目だけ**。ゲームの状態・乱数・保存（v15）・オンラインの同期は変えない。各端末が届いた状態の「手番の変化」を見て、自分の画面にだけ出す。
- カットインが出ている間も、ゲームの進行（ほかの人の操作の受信など）は止めない。

## 3. 確認
- テスト: 手番が自分のキャラに移った時だけカットインが出る／同じ手番のままなら出ない／ほかの人のキャラなら小さなお知らせ（store のテスト）。
- 画面: 新しいスクリプト `scripts/turn-cutin.mjs`（360/390/480px）で、1台2人の世界マップで P1→P2 の手番の受け渡し、世界マップ→ダンジョンの組の番への切り替えを撮影し、カットインが出て消えること・タップで消せること・はみ出し/12px未満が無いことを確かめる。今の確認スクリプト一式も通す（カットインで止まらないよう、必要ならタップで消す処理を足す）。

## 4. 進め方【提案】
- 段階B2（ダンジョンの演出）の**前に**これを作る（小さめの作業で、オーナーが遊ぶたびに気になる所なので）。
- 終わったら、お試しURLを更新して実機で見てもらう。
