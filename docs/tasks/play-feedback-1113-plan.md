### 計画と違う所・自分で決めた所

- **「次の目的」の行は、高さ700px未満の画面（例: 360×640）では出ない。** 行を1つ足すと、操作のパネルに隠れていない地図が 74px → 26px まで減り、押せるマスが見えなくなるため。→ 回1の追加で、短い画面では、パネルの「〇〇の番」の下の行に出す。
- 分かれ道で、立て札と脇道が見えるか: 昼（視界2）は、分かれ道の1マス手前から立て札が見える。分かれ道に着くと、脇道4マスのうち2マスが見え、ダンジョンは霧の中だが、次の目的地の印が霧の上に出る。夜（視界1）は確かめていない。
- 立て札は、制覇した後も残る。前の広さの地図（街道のデータが無い）には立たない。
- 依頼が足りない時は「次の目的: 町の依頼をあと1つ果たす（『溶岩の大空洞』の扉が開く）」。
- 保存の版は v26 のまま（足したのは storyQueue? だけ）。自動プレイの測定の表は、変える前と同じ（乱数の流れは変わっていない）。

## 6. 回1の追加（彼女さんの指摘: 「どこがマスで、どこを押せば施設に入れるのか分からない」）【提案】

原因（コードで確かめた事）: 施設の絵は、立体に見せるためにマスの少し上に浮かせて描いている（WorldMap.tsx の FACILITY_LIFT）。地図を押した時は、押した場所にいちばん近いマスを選ぶので、絵の上の方を押すと、1つ上のマスを選んだ扱いになる。施設の名前は、地図の上には出ていない。

| 直す物 | 中身 |
|---|---|
| 絵を押せば入れる | 施設の絵のどこを押しても、その施設のマスを選んだ事にする |
| 施設の足元のマス | 施設の下に、マスの形の台（六角の縁）をはっきり描く |
| 届く時の印 | この番で施設に届くなら、そのマスと絵を強く光らせて「入れる」と出す |
| 届かない時 | 施設を押すと「あと〇マス。この番は、ここまで進める」と出して、そこまでのマスを選べる |
| 名前の札 | 見えている施設の下に、小さく名前を出す（縮小しすぎた時は消す） |
| 短い画面の「次の目的」 | 高さ700px未満の画面では、パネルの「〇〇の番」の下の行に出す |
| ランダムダンジョンのうわさ | 町の説明の下に1行（「うわさ: 西の森に、古代の晶洞があるらしい」） |
