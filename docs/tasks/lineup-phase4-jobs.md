## 1. 拳聖 — 採用（修正）

**Gemini の案**: 《カウンター特化》ブロックで敵の攻撃を防ぐたび、防いだ数値分の物理ダメージで即座に反撃する。

**ほかに無い役割か**
- 今の拳の3職（武闘家・闘士・拳王）は、どれも「1ターンにたくさんカードを使う」です。拳聖は「敵の予告を読んで、受けて返す」で、同じ武器で逆の遊びになります。
- 憲章4の「敵の狙いに合わせる」に、ジョブの力そのものが合っています（大きい攻撃の予告ほど、ブロックを積む価値が上がる）。
- 似ている物: 槍の個性（反撃）・1回目の「返しの一手」。これは「耐えたら次の攻撃が強い」で、拳聖は「防いだ瞬間に返す」。別の物として成り立ちます。

**直す所**

| 項目 | 内容 |
|---|---|
| 戦闘の力《後の先》 | 敵の攻撃をブロックで防ぐたび、防いだ量と同じ物理ダメージで、その敵に反撃する。**1回の反撃は最大12・1ターンに3回まで【提案】** |
| 上限を付ける理由 | 上限が無いと、ブロックを40積めば40返り、守りと攻めが1枚で両方済んでしまう。多段攻撃の敵にも強すぎる |
| 重ねがけの決まり | 黄金箱の「イージスの鏡盾」（防いだ分を返す）と両方ある時は、**別々に数えて、鏡盾はボスに30まで**（2回目の案のまま）。反撃で反撃は起きない |

## 2. 重装衛士 — 採用（修正）

**Gemini の案**: 《ブロック持ち越し＆盾殴り》ターン終了時にブロックが半分消えずに残り、自分の全物理攻撃に「現在のブロック値×50%」のダメージが加算される。

**ほかに無い役割か**

| 項目 | 内容 |

## 3. 竜脈術師 — 採用（修正・確認2点）

**Gemini の案**: 《属性連鎖・BREAK特化》敵に状態異常（火傷・凍結・痺れ・毒）を付与するたび、敵全体のBREAKゲージを削りマナ+1（1ターン1回）。

**ほかに無い役割か**
- 状態異常を付ける事そのものが得になるジョブは、今いません（隠密は「付いている敵に強い」、呪術師は「付ける量が増える」）。
- 憲章4の柱「弱点＋完全成功で状態異常が確定」と、そのまま噛み合います。

**そのままでは作れない所**
1. **BREAK にゲージはありません。** 今の決まりは「大技の予告のターンに、弱点・完全成功・合計ダメージで崩す」です。「ゲージを削る」は作れません。
2. **「付けるたびマナ+1」は、ほぼ毎ターン起きます**（弱点＋完全成功で確定するため）。代償なしで毎ターン マナ+1 は、冥王（毎ターン HP3 を払ってマナ+1）より良くなってしまいます。
3. **幻獣使いからの派生なのに、幻獣と関係がありません**（武器も大魔導士の系列と同じ◎杖○魔導書）。

**直す所**

| 項目 | 内容 |
|---|---|
| 戦闘の力《竜脈》 | (1) 敵に、**その敵にまだ付いていない種類**の状態異常を付けた時、マナ+1（1ターンに1回）【提案】。(2) **違う種類の状態異常が3つ付いた敵は、予告が BREAK する**（敵1体につき1戦闘1回）【提案】 |
| ねらい | 同じ状態異常を付け続けるだけでは得をしない。「火傷→凍結→痺れ」と種類を並べるパズルになる（Gemini の言う「属性連鎖」）。BREAK の4つ目のきっかけになる |
| 幻獣とのつながり | **(3) を足す（Gemini の2回目）**: 幻獣のターン終了時の攻撃に、自分が最後に使った属性の状態異常が1つ乗る（**幻獣だけ・お供は入れない・1ターンに敵1体・1つ**【提案】）。マナ+1 は (1) の「まだ付いていない種類を付けた時」のまま |
| 武器 | ◎杖○魔導書（Gemini のまま）。魔導書の個性（属性の使い分け）と合う |
| HP・転職の条件 | HP58【提案】。条件【提案】: 違う種類の状態異常が2つ以上付いた敵を4体倒す |
| 探索の力 | 《地脈読み》石碑・魔法陣の判定+20%【提案】 |
| 決め技（レジェンド・1戦闘1回） | **竜脈解放**［魔法・コスト2・枠2・成功率75%・敵全体］10/14/20ダメージ。敵1体ごとに、付いている状態異常1種類につき+6。**状態異常は消えない**（起爆のカードは消す。ここが違い）【提案】 |

**Gemini に確認する2点**: (a) BREAK の部分を「3種類で BREAK」に変えて良いか。 (b) マナを得るジョブが3つ目（大魔導士＝完全成功、冥王＝HP を払う、竜脈術師＝新しい種類の状態異常）になるが、役割は分かれているか。

## 4. 錬金術師 — 見送り（確定。Gemini も同意）

**Gemini の案**: 《消耗品＆毒爆破》戦闘中に使う消耗品の効果が2倍になり、50%で消費しない。戦闘勝利時にランダムな消耗品を1つ調合する。

**前の決定**: 錬金術師は、竜殺し・気功師・踊り子と一緒に「見送ったジョブ」です（`CLAUDE.md` §4）。`docs/tasks/lineup-plan.md` で「フェーズ4の計画の時に改めて相談する」としていました。**今がその相談です。**

**見送りをおすすめする理由**
1. **役割が装備と同じ。** 2回目の案で採用した黄金箱の「錬金術師のベルト」が、「消耗品で戦う」遊びを**どのジョブにも**与えます。同じ事をするジョブを足すと、憲章5の「名前だけ違うコピー」に近くなります。
2. **難しさが下がる。** 消耗品は24個に絞り、切り札（不死鳥の羽根・神々の神酒・閃光の破砕玉）を「使い所に悩む物」にしました。「効果2倍・半分の確率で減らない・勝つたびに1個もらえる」は、その悩みを消します（神酒が2倍で減らない、など）。
3. **題の「毒爆破」が、力の文に入っていません。** 毒の起爆は、今ある呪術師・隠密・忍者と「猛毒の飾り」の役割です。
4. **運まかせ。**「50%で消費しない」は、良い判断ではなく運で結果が変わります。

**それでも入れる場合の形（B案）**
- 「錬金術師のベルト」を黄金箱から外す（役割をジョブに渡す）。
- 力を弱める【提案】: 効果2倍は**レア以下の消耗品だけ**・「消費しない」は**1戦闘に1回、確実に**（運にしない）・調合は**勝利3回ごとに1個、レア以下**。
- 決め技【提案】: 「賢者の大調合」— 持っている消耗品を2つ選んで、両方の効果を同時に使う（消費は1つ）。

**獣使い・隠密の空きについて**
- 見送ると、技の系統の中位職のうち 獣使い・隠密 には特殊ジョブがありません（最上位のビーストマスター・忍者はあります）。
- **数合わせでは埋めません。** ただ、獣使いからの特殊ジョブは、憲章5の軸「手数＆お供」と、オーナーが大切にしている**お供（ペット）**を主役にできる場所です。「お供と一緒に戦う事がほかに無い役割になる案」があるかを、Gemini に聞きます（今のビーストマスター＝群れの獣を呼ぶ、との違いが要ります）。

## 6. Gemini に見てほしい所（2回目で返事をもらった。整理は `lineup-gemini2-triage.md`）

1. 拳聖の反撃の上限（1回12・1ターン3回）は、「受けて返す」楽しさを残せているか。
2. 重装衛士は◎槌○槍のままで良いか（転職元の槍騎士は◎槍）。
3. 拳聖と重装衛士が同じ軸（重装カウンター）に並ぶのは多いか。分け方（受け身／攻め）は足りているか。
