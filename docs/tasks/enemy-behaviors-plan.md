## 2. 案: 「ビルドの天敵」5種類と「倒す順を悩ませる」2種類【全部 提案】

**決まり（憲章のチェック表から）**
- **敵を増やしません**（水増しをしない）。今いる「殴る・守るだけ」の43体と、強敵（エリート）の一部の行動を置き換えます。
- **全部、予告で見えます。** 予告の欄に「何をするか」と「どうすれば止まるか」を出します（憲章4: 打てる手が画面で分かる）。見えない所で損をする行動は入れません。
- **天敵でも、手はあります。** BREAK・弱点・倒す順・守りのどれかで受けられます。ビルドを否定するのではなく、「いつもの手順を1ターンだけ変えさせる」のが狙いです。
- 1つの戦闘に、特殊な行動は1〜2種類まで（読み切れる量にする）。2人で遊ぶ時に、だれかの番が止まる行動は入れません（憲章7）。

## 7. 1回目の作り方（2026-11-12・オーナーの返事「A = 7種類とも、シナリオ1で試す」）【数値と割り当ては提案】

### 割り当て（シナリオ1・侵食の魔王）

最初の地域（平原）と、次の森には置きません（中位に転職する前のため）。沼・火山・魔王城の敵7体に、1種類ずつです。敵は増やしません。今ある行動の1つを置き換えます（HP・ほかの行動・弱点はそのまま）。

| 地域 | 敵 | 足す行動 | 置き換える今の行動 |
|---|---|---|---|
| 沼 | 沼の大ガマ | **浄化（脱皮）** | 守る行動 |
| 沼 | 葦陰の狩人 | **手数読み** | 「葦にまぎれる」（守る） |
| 火山 | 玄武岩の虫 | **盾砕き** | 攻撃の1つ |
| 火山 | 炭火の猟犬 | **手負い狙い** | 攻撃の1つ |

| 魔王城 | 砦の小悪魔 | **仲間を呼ぶ**（灰コウモリを1体） | 守る行動 |

### 7種類の中身

どれも「大技の予告」と同じ扱いにして、その予告が出ているターンは BREAK で潰せます。予告の欄には、名前と一緒に下の「予告の文」を出します。

| 行動 | 予告の文 | 中身 |
|---|---|---|
| 盾砕き | 「当たるとブロックを全部壊す。BREAK するか、ブロックに頼らずに受ける」 | 狙った相手のブロックを0にしてから、置き換えた攻撃と同じダメージ |
| 浄化 | 「状態異常を全部消して回復する。その前に起爆するか、BREAK する」 | 自分の悪い状態異常を全部消し、消した1種類につきHPを6回復（何も付いていなければ、何も起きない） |
| 手数読み | 「このターンにカードを4枚以上使った味方に、枚数×2のダメージ」 | 敵の番に、このターンにカードを4枚以上使った味方それぞれへ（使った枚数×2）ダメージ。3枚以下の味方には何もしない。ブロックで防げる |
| 癒し封じの呪い | 「味方全員の回復が、2ターン半分になる。BREAK するか、先に回復を使う」 | 味方全員に新しい状態異常「癒し封じ」2（HPの回復が半分・端数切り捨て。ターンごとに1減る。清めの札で消せる） |
| 手負い狙い | 「HPの割合がいちばん低い味方を狙う。HPが半分以下だと×1.5」 | 狙いは、予告を出す時にHPの割合がいちばん低い味方（挑発で変えられる）。当たる時にその味方のHPが半分以下なら、ダメージ×1.5 |
| 仲間を呼ぶ | 「仲間を1体呼ぶ。その前に倒すか、BREAK する」 | 灰コウモリを1体、戦闘に足す（敵は最大4体。その敵が呼べるのは1戦闘に2回まで。4体いる時・2回呼んだ後は、代わりにふつうの攻撃） |
| かばう | 「次の味方の番の間、ほかの敵への単体攻撃を代わりに受ける。全体攻撃は通る」 | 行動した後、次の味方の番が終わるまで「かばう」状態（敵の上に印を出す）。ほかの敵を狙った単体攻撃のカードは、この敵が受ける。全体攻撃・お供と召喚の攻撃は、そのまま通る。この敵が倒れたら終わる |

- **案（§2）と違う所**: 「かばう」は、予告を出したターンではなく、**行動した後の、次の味方の番**に効きます。予告は「これから敵の番にする事」を見せる仕組みなので、予告のターンの中で先に効かせる事ができないためです。遊ぶ人から見ると「騎士が前に立った。次の番は、後ろの敵に単体攻撃が通らない」と見えます。
- 呼ばれた灰コウモリは、経験値・お金を、ふつうの灰コウモリと同じだけ落とします。
- 乱数は、種から作る物だけを使います。保存して再開・オンラインでも同じ結果になるようにします。

## 8. 1回目を作った結果（2026-11-12・作ったのは Opus 5.5 の作業役、設計と見直しは Fable）

7種類とも、§7 のとおりに作りました。作れずに止めた物はありません。

### 自分で決めた所・後から分かった事

| 何 | 決めた事 | 理由 |
|---|---|---|
| BREAK された時（ダメージの無い4種類: 浄化・呼ぶ・かばう・癒し封じ） | その行動は起きない | §7 の「BREAK で潰せる」のとおり |
| BREAK された時（盾砕き） | ブロックは壊れず、ダメージは半分 | 今の大技の決まり（BREAK で威力半分）に合わせた |
| BREAK された時（手数読み） | 枚数×2 → 枚数×1 | 同上 |
| 手負い狙いで置き換えた行動 | 炭火の猟犬の「炭火の牙」（炎の10ダメージ） | 一撃の大きい方が、狙われる怖さが出る |
| 沼の大ガマの浄化の順番 | 3つの行動の最後 | 1番目だと、1ターン目に何も付いていなくて空振りになるため |
| 魔王軍の騎士が1体だけの時 | 「かばう」の代わりに「闇の剣」 | かばう相手がいないと空振りになるため |
| 呼ばれる灰コウモリの強さ | 呼んだ小悪魔と同じレベル（火山の灰コウモリより少し強い） | 魔王城の敵として出るため |
| 「大技は強敵・ボスだけ」という前のテストの決まり | 予告の文が付いた特殊な行動は、その決まりから外した | ふつうの敵にも BREAK で潰せる行動を付ける、と §7 で決めたため |

- 残っている事: 「かばう」の予告が出た後、その敵の番までにほかの敵が全部倒れた時は、何も起きない「かばう」がそのまま行われます。
- 「癒し封じ」と「呪い」（回復半分）が両方付くと、回復は4分の1になります。全回復の道具（不死鳥の羽根など）は、先に状態異常を消すので半分になりません。
- 保存の版は上げていません（足した項目は任意の項目なので、古い保存がそのまま読めます）。

### 確かめた事

- 型チェック・全部のテスト（1549件）・ビルド・自動プレイ（2人・4人）。
- スマホの幅（375px）で、7体とも予告を長押しすると予告の文が出る事、「かばう」の印、仲間を呼んだ後の敵の並び（画像は screenshots/enemy-behaviors/）。
- 難しさの集計（ふつう・各60回）: 4人 7%・3人 15%・2人 8%（敵のHP+10% だけの時は 3%・8%・7%）。自動プレイの bot は予告に合わせて動かず、この7体が出るのは沼より後なので、数字はほとんど動いていません。
- **確かめていない事**: オンラインの2人で遊ぶ事、呼ばれた敵が出る時・倒れる時の動き、人が遊んだ時の手ごたえ（オーナーが遊んで確かめる）。

### オーナーが試す時の見どころ

1. 沼（2つ目の鍵のあたり）: 「沼の大ガマ」に毒や火傷を付けると、3ターン目に「浄化の脱皮」で消して回復します。その前に起爆するか、BREAK します。「葦陰の狩人」の予告が「手数読み」の時は、カードを3枚で止めるかどうかを選びます。
2. 火山: 「玄武岩の虫」の「盾砕き」は、ブロックを貯めていると全部壊されます。「炭火の猟犬」は、HPの割合がいちばん低い味方を狙います。
3. 魔王城: 「魔王軍の騎士」が「かばう」をした次の番は、後ろの敵への単体攻撃が騎士に吸われます（全体攻撃は通ります）。「砦の小悪魔」は灰コウモリを呼び、「呪紋の魔犬」は回復を半分にします。
4. どの行動も、敵の予告を長押しすると「何をするか・どうすれば止まるか」が読めます。
