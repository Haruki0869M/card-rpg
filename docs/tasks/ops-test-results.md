## T2 選択の意味（`branch`・N=50・15場面・84か所・151秒）

- 観測事実: 道具の数字は「有効選択率 73.8%・偏り 0.09」。**ただし、84か所の全部で、どの手でも勝率100%**。差は「勝った後の残りHP」のごく小さな差（平均 0.04）だけ。フォーカスを使っても結果のばらつきは変わらず（比 1.0）。連携を狙う手とほかの手の差も 0。
- 読み方: 「手の違いで結果が変わる」とは**言えません**。場面（最初のダンジョンの普通の戦闘・最初のボス・HP半分）が bot でも必ず勝てる強さなので、差が出ない。
- 人が確かめること: 最初のダンジョンで「どれを出しても勝てる」と感じるか。
