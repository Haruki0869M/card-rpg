## 2. 案2: シナリオ3「呪われた群島」の災厄の形の作り直し

決定済みで変えない物: 悪さ「潮が止まる」= 今の潮のまま止まる（`WorldState.tideFrozen`。`types/world.ts:450`）／加護「満ちる霧」= 戦闘の中で返す／悪さ「呪われた財宝」= その戦闘の間ずっと減らない呪い。

先に、戦闘の順番（確かめた。`battle/battle.ts`）:
- 敵のブロックは「敵の番の始め」に0になる（`:865`）。だから、**敵の番に付いたブロックは、次の味方の番の間ずっと残る**。
- 味方のブロックは、敵の番の間ずっと残り、「次の味方の番の始め」に消える（持ち越しの装備があれば残る。`:323`）。
- 味方の状態異常は「味方の番の終わり」に1減る（`:861`）。
- BREAK すると、敵は脆弱1・ブロック0・その予告の威力が半分（`balance.ts:297-299`）。BREAK できるのは大技の予告のターンだけ。

### 2-1. 加護「渦潮の衣」（渦潮の大海魔）— 拍子でなく条件に

**A（おすすめ）: 「手を出さなかった味方の数だけ巻き直す」**
- 決まり: 味方の番を終えた時、**そのターンにボス（大物）を1回も攻撃しなかった味方1人につき、ボスの最大HPの4%のブロック**が付く（次の味方の番の間、残る）。全員が1回ずつ当てれば0。倒れている味方は数えない。**1人旅の時は「2回当てれば0・足りなければ4%」**（白い息の「1人の時だけ別」と同じ考え方）。
- 打てる手: 守り役・回復役も、安い札かお供で1回は当てる／あえて張らせて、BREAK（ブロック0になる）・毒と火傷（ブロックを無視）で崩す。
- 画面: ボスの所に小さな札「🌀あと2人」（まだ当てていない味方の数）。長押しで全文。
- 作り: 「このターンにこの敵を攻撃した味方」の記録は、連携のために今ある（`enemy.hitBy`。`effects/index.ts:479`）。それを番の終わりに数えるだけ（小）。
- 良い所: 憲章4の柱2「連携（みんなで同じ敵を攻撃）」と、憲章7「相談が盛り上がる」（「回復の前に1発入れて」）に結びつく。

**B: 「削れなかったターンだけ」**: 味方の番を終えた時、そのターンにボスのHPを最大HPの8%以上削れていなければ、最大HPの10%のブロック。答えは「毎ターンしっかり削る」。分かりやすいが、死霊術師の「瘴気の衣」（毎ターン回復 = 一気に削る）と答えが近い。

### 2-2. 段階「霧の体」（霧を吐く幽霊船）— 「小さく刻む」でない答えに

**A（おすすめ）: 「状態異常で実体になる」**
- 決まり: 幽霊船に**悪い状態異常が1つも付いていない間、受けるダメージは半分**。毒・火傷・脆弱・弱体など、何か1つでも付いている間は元どおり。
- 打てる手: 状態異常を切らさない（毒・火傷は数ターン残る）／大技の予告を聖か火の完全成功で BREAK（脆弱1が付くので、そのターンは実体）／状態異常を付ける道具。
- 画面: 予測欄のダメージの数字が半分で出る（同じ計算を通るので自動）。ボスの所に札「🌫霧の体（半分）」／「実体」。
- 1人と4人: 掛け算なので同じ重さ。お供の攻撃も止めない（半分になるだけ）。
- 前の案で心配だった「背水ブラッド・居合がほぼ働かない」は起きない（状態異常さえ付いていれば、大きな一撃がそのまま通る）。状態異常バースト軸と BREAK が主役になる。

**B: 「小さい当たりは霧に散る」**: 1回の当たりが5以下のダメージは0（毒・火傷・お供は通る）。答えは「大きく当てる」で、鐘のこだまの正反対。ただし手数の軸をほぼ止める。

### 2-3. 加護「満ちる霧」（霧を吐く幽霊船）— 「渦潮の衣」「ブロックを張る敵」との違い

- 画面: ボスの所に札「🌫霧まであと3ターン」→ 始まったら「🌫霧 +6%」。

| | 渦潮の衣（2-1 の A） | 満ちる霧 | ブロックの行動を持つ敵（潮の神官「満ち潮の祈り」`isles.ts:164`・大海魔「潮を吸う」） |

## 7. 確かめていない事

- 動かして確かめた物は1つも無い（テスト・測定・画面は流していない）。
- マスのイベントの中で「残りの移動力を増やす・0にする」が思ったとおり効くか（突発イベントでは使われているが、マスのイベントでは初めて）。効かない時は、釣り小屋の選択肢を作る前に相談します。
- 帯ごとのイベントのマスの数（17か所の割り振りは推測）。
- 「薪の束」を足した時に直すテスト（品の数を決めているテスト）と、ほかのシナリオの宝箱に出さない書き方。
- 霧の体 A: 全部のジョブが、敵に状態異常を付ける手（札・道具・BREAK）を無理なく持てるか。BREAK は大技の予告のターンだけなので、状態異常の札が1枚も無いパーティは半分のターンが多くなる（詰みではない）。
- 伝染: 呪いは「回復が半分」だけなので、回復をほとんど使わないパーティには軽い。測定で効いた回数を数える。
- 満ちる霧: 1人旅で戦闘が6ターンを越える割合（重すぎれば上限を下げる）。
- 樽を「ある間だけ枠に数える」時に、呼び出しが実際に止められる回数。画面で樽が消える見せ方。
- 札が4つ増えた時の、低い画面での重なり（今の加護の札・段階の札の場所に入るか）。
