- **心配だった「こだま＋高い防御で長引く」は、起きない形にしました**: 亡霊は**ふだんも段階も、自分にブロックを張る行動を1つも持ちません**。回復も無し。こだまで「小さく刻む」を選んだ時に、刻んだ分がブロックに吸われる事が無い。

### かみ合い・重さの確かめ

- **段階では「灯を啜る」（回復）を使いません**。灯喰いで攻撃が大きくなる → 回復も大きくなる、という重なりを作らないため。回復があるのは前半だけで、ブロックで0にできる。
- 段階の攻撃は全部1回当たり（×2回などは入れない）。「喰った灯の分」が回数で倍にならないようにするため。
- 段階の行動3つのうち2つが大技なので、**BREAK できる予告がよく出る**（灯を0に戻す機会が多い）。聖・火を持たないパーティは BREAK しにくいので、「フォーカスを使わずに戦う」が答えになる（攻撃は禁じられないので止まらない）。
- 手下の霜の精は「凍結」（味方は次のターンのマナ−1。`foothills.ts:56`）、凍える亡者は「呪い」（回復が半分。`lake.ts:41`）を付けます。本体の決まり（フォーカス）と合わせると「使える物を削られる」戦いになるので、**重いと感じたら手下を替える**候補です（測って記録し、オーナーが遊んで決める）。
- 1人でも4人でも、だれかの入力を待つ所は増えません。

## 8. 確かめていない事

- 動かして確かめた物は1つもありません（テスト・測定・画面・自動プレイは流していない）。数字は今の5体の並びに合わせただけです。
- **吹雪に隠れている間の BREAK**（決める事5）: ダメージが0の一撃でも「弱点・完全成功」で BREAK が起きる作りかどうかは、読んでいません（`effects/index.ts:267-275` の決まりは当たりの中身を見るので、作る時に確かめます）。
- 「追い立てる」: 外れた（ダメージ0の）一撃が「最後に殴った人」に数えられるか（`effects/index.ts:438`）は確かめていません。隠れた次のターンの狙いに関わります。
- 群れの牙: 手下が倒れた時に、予告の数字がその場で減るか。予告の画面（`components/format.ts`）は効果のデータから毎回作り直しているので、できる見込み（推測）。
- 葬送の鐘: 割り込みの条件「倒れた仲間がいる」は、今は1体（人形を組み直す）だけが使っています。「3ターンに1回」の数え方（`intents.ts:137`）が思ったとおりかは、作る時にテストで確かめます。
- 「痺れ」が味方に付いた時の長さ（1ターンで消えるか）は、データの説明（成功率 −15%。`statuses/basic.ts:9`）しか読んでいません。
- 影: 段階に入った後も「順番なし」で動くか（段階の `pattern`）・開幕の一手と一緒に働くかは、型（`types/index.ts:526-547`）で書ける事だけ確かめました。
- 見つけた事2（氷の剣士の中ボスの段階）は、コードの読みからの推測です。作る前にテストで確かめます。
- 仮の絵（雪狼・霜鈴の亡霊騎士・霜蛾を大きくした見た目）は見ていません。霜蛾は小さい敵の絵なので、大きくすると粗く見えるかもしれません。
- 星読み（先に結果を決める）と「順番なし」の敵の組み合わせは読んでいません（シナリオ1の敵で今も動いている決め方なので、同じ扱いの見込み）。
- 手下の霜の精の凍結・凍える亡者の呪いと、灯喰いが重なった時の重さは測っていません。
- 行の番号は読んだ時の物です。
