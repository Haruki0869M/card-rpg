## 参考: 自動プレイで測った、今の難しさ（2026-11-13）

- 寄り道も転職もしない bot は、ほとんど勝てません（5〜10%）。
- 転職して、弱点と BREAK を使う bot は、ほとんど勝ちます（85〜93%）。計画の目標（35〜50%）の約2倍です。
- いちばん効いているのは転職です。寄り道は、今は「しない方が勝ちやすい」という数字が出ています。
- **遊んでみて「工夫したら、あっさり勝てた」と感じるかどうか**を、ぜひ教えてください。くわしくは `docs/tasks/overhaul-stage8-measure.md`。

## C. 見てもらった後に、決めてほしい事

1. **広い世界マップを、残り6本のシナリオに広げて良いですか？**（直したい所があれば、先に直します）
2. **敵の特殊な行動を、残り6本のシナリオの敵にも付けて良いですか？**（良ければ、どの敵に何を付けるかの表を先に出します）
3. **難しさ**: 今のままで良いか・もっと難しく・少しやさしく（上の「参考」の数字も見てください）
4. **寄り道**: ランダムダンジョン・災厄に、行きたくなったか。ご褒美を増やすか・損（侵食度）を減らすか
