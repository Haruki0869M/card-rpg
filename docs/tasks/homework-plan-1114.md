- **今の姿（確かめた）**

  - **歩き回る敵は帯を見ない**（`wanderers.ts` は `isWideMap` しか使わない）。イベントも地域のどこにでも出る。

- **直し方【提案】**: 帯ごとに「損と得」をはっきり分ける。
  - 街道: 速い（今のまま）。代わりに**見回りの敵が出やすい**か、**関所**（少しのお金か侵食度）。
  - 西の森: 遅いが**安全**（遭遇が少ない・祠と薬草で回復）。回復役のいない組の道（宿題7とつながる）。
