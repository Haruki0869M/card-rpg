# 遊びの長さ（ボリューム）の測定 — 人のように「まっすぐ進む」bot

測定: 2026-11-10・Claude（測定セッション）。ゲームの数値・中身は変えていません。

## 結論（先に）

- **まっすぐ進む bot でも、計算上の時間は「クリアまで 2人で約111分・4人で約259分」** と出ます。ただし、この時間の式は**人の実際の速さよりかなり遅く**見積もっています。
- オーナーの実感「**約15分で終盤・同じ頃に最上位**」に当たるのは、bot では **「鍵3つ目の制覇（2人 66分）」「最上位の Lv に届く（2人 80分・20戦目）」** です。つまり **人は式の約5分の1の時間**で進んでいます（15 ÷ 66〜80 ≒ 0.2）。
- この比で直すと、**人の2人プレイのクリアは約20〜25分**。60分以上遊べるようにするには、**今の約2.5〜3倍の量**が要ります（目安）。
- 時間の大半は**戦闘のカード**（2人で 111分のうち 68分）。人は bot よりずっと早くカードを出すので、ここで差が出ていると考えられます。**比べる時は「分」より「戦闘の数・ラウンド」を見るのが確か**です。
  - まっすぐ進む bot: クリアまで **約25〜28戦・22〜38ラウンド**。中位に届くのは **9戦目ごろ（鍵2つ目のころ）**、最上位の Lv は **約20戦目（鍵3つ目のころ）**。
- まっすぐ進むと、**最終ダンジョンで負けて入り直す**ことが多い（平均1〜3回）。レベル上げをしないぶん、最後で詰まりやすい。クリア率は 2人 18/27・4人 15/27。

## 測り方

- bot: `playToEnd(g, 60000, { straight: true })`（`src/engine/bot.ts`）。**レベル上げをしない**・**今の鍵で扉が開く次の鍵のダンジョン → 最終ダンジョンへ直行**・町は**回復（HPが半分を切った時）と船の依頼の時だけ**。ダンジョンの中の動き・戦い方・報酬の選び方は従来の bot と同じ（転職はしない）。従来の bot（オプションなし）の動きは変えていません。
- 全7シナリオ・ふつう・2人（剣士・魔法使い）と4人（＋守護者・狩人）・種 1001〜1004。
- 転職の時期は、経験値から「転職していたら」を計算（中位 = 基本 Lv6・特殊 = 中位 Lv5・最上位 = 中位 Lv7。転職すると Lv1、持ち越しは Lv2 の手前まで。中位→最上位は町・祠・神殿に着いた時を別の列に）。
- 時間 = 操作1回あたりの秒数（カード6秒・移動5秒・敵の行動1.5秒など）を**全員分足した値**（4人だと全員の操作を順に足すので長く出ます）。
- 「詰まり」= 侵食度100で終わり、その前の25ラウンド以上1度も勝てていない（bot の癖。数から外す）。

### 前の測定との違い（大事）

前の測定（冒険の長さの調整の時の pace2）は、戦闘の操作を包みから出しておらず、**戦闘の操作がすべて「1回4秒」**で数えられていました（カード6秒・ターン終了2秒・敵の行動1.5秒の区別が効いていなかった）。今回の測定は直した数え方です（カードが多いので、少し長めに出ます）。前の数え方に戻すには `VOL_OLDTIME=1`。
