## 2. 行く前に画面で分かる手がかり

1. **マスの説明**（地図のマスを押した時）: 広い地図の帯のマスに、1行「🛣街道: 速い・魔物が多い」「🌲西の森: 魔物が少ない・夜襲が半分・祠と薬草」「⛰東の丘: 魔物がLv+1・夜襲が多い・宝箱が多く良い」を足す。

4. 地図の文（「嘆きの沼の東」など、`placeName`）は今のまま。

## 3. 賢い bot の道の選び方（`bot.ts` の道の計算だけ）

- 今: 目的地まで、地形の移動力だけで一番安い道（`walkCostTo`）。敵は見ない。
- 後【提案】: **賢い bot だけ**、目的地へ向かう時（育てるための敵を狙う時を除く）、見えている徘徊する敵のマスを「移動力 +6」と数える。街道が混んでいる時は、西か東の帯へ回り道をする。寄り道の判断（`smartDetour`）・行き先（`worldTarget`）は変えない。
- 直行 bot・工夫する bot は今のまま。

## 4. 保存・オンライン

- 保存の形は変えない（帯の性質は地図のデータ `map.ts` の `lanes` に書く。地図の保存には何も足さない）。古い保存は地図を作り直さず、そのまま読める。帯の倍率は、保存の地図がデータと同じ大きさの時だけ使う（`isWideMap`）。
- 乱数は冒険の `Rng` だけ。敵の湧くマスの重みは「1回の rng.next()」で選ぶ（前の rng.int と同じ回数）。オンラインと保存再開で同じ結果になる。
