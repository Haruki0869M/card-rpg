# 部屋の連続を無くす・黄金箱の秘宝を必ず出す（2026-11-13・オーナーの OK 済み）

憲章の点検（`docs/review/2026-11-13-charter-audit.md` の D1・D2）で見つかった、憲章の文との食い違いを直します。オーナーの返事（2026-11-13）: **部屋の連続 = A（憲章に合わせる）・黄金箱 = A（必ず出す）**。直し方の細かい所は、まとめ役の【提案】です。

## 1. 部屋の連続（憲章3「同じ種類の部屋の連続出現は禁止」）

### 今
- 手作りのダンジョン28か所（7本×4）と、ランダムダンジョンの作り方（`src/engine/game/dungeon.ts`）の決まりは「休憩→休憩なし・イベント→イベントなし・ふつうの戦闘は2連続まで」。
- 28か所すべてに、戦闘→戦闘と続く道がある。ランダムダンジョンは、強敵→強敵・宝箱→宝箱も出る。

### 直した後の決まり
- **どの道を通っても、続けて同じ種類の部屋に入らない。** 種類は、扉の予兆と同じ分け方（ふつうの戦闘／強敵／休憩／宝箱／イベント／店 など）。ふつうの戦闘→強敵、強敵→ボスは「違う種類」として良い。
- 1行目は、今のとおり、ふつうの戦闘。

### 手作りの28か所の直し方【提案】
- **行の数・部屋の数・道のつながり・ボスと中ボスと最後の休憩の場所は、変えない。** 決まりに反する所の部屋の種類だけを、できるだけ少なく替える。
- 戦闘を替える時の順番: (1) イベント（そのシナリオのダンジョン用のイベントで、同じダンジョンでまだ使っていない物）→ (2) 宝箱（コモン・鍵なし）→ (3) 強敵（同じ行に、強敵でない部屋がもう1つある時だけ）。
- **どの道でも、ふつうの戦闘は、鍵のダンジョンで2回以上・最後のダンジョンで4回以上は残す**（経験値とカード報酬が足りなくならないように）。
- 残り6本の24か所は、今は4つの型の写しです。今回は「連続を無くす」だけを行い、型の写しをやめる作業（点検の宿題 H5）は別に計画します。

### ランダムダンジョンの作り方
- 「前の行にその種類が1つでもあれば、この行には出さない」を、全部の種類に広げる（今は休憩・イベントと、戦闘の3連続だけ）。

### 気になる所
- **戦闘の数が減ります。** 狙いどおり（憲章の「全25〜32戦」に近づく）ですが、経験値とカード報酬も減るので、転職の時期（中位 Lv5）が遅れるかもしれません。直した後に、bot で「戦闘の数・ダンジョンに入る時のレベル・転職の数」を、前と比べて測ります。足りない時は、数字（1戦の経験値など）を勝手に変えず、案を出します。
- 難しさは上がる向きです（経験値が減るため）。「賢い bot が約15%」の最後の調整は、この直しと、敵の特殊な行動の直しを入れた後に測り直します。
- 乱数の流れが変わるので、自動プレイの種の結果は変わります。ダンジョンの途中の保存は、入った時の並びのまま続けられます。

## 2. 黄金箱（憲章2「最奥の主を倒すと必ず黄金箱が開き、秘宝装備が手に入る」）

- 今: 箱は必ず開くが、秘宝装備が出るのは60%（`balance.ts` の `randomDungeon.exclusiveChance: 60`）。
- 直した後: **100%**。説明の文やヘルプに「60%」と出ている所があれば、合わせて直す。
- 気になる所: ランダムダンジョンのご褒美が大きくなります（寄り道の値打ちが上がる向き。点検の宿題 H3「寄り道は今は損」にも効きます）。
