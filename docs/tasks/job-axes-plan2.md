## 2. 足す物の案（1職につき2案。おすすめを先に）

### 2-1. 機工士

#### 案A（おすすめ）: 「装甲砲台」— 重装カウンターの「撃つ」側

| 項目 | 中身【提案】 |
|---|---|
| 種類 | 新しい札・技（スキル）・レア・コスト1・成功率80%・機工士の札（置き場は機工士だけ） |
| 効果 | ブロック 4 / 6 / 8 を得て、**砲台を置く**（今の砲台と同じ物を置き直す。2台にはならない。3ターン）。この砲台は撃つたびに、**自分の今のブロックの40%をダメージに足す（最大+10。ブロックは減らない）** |
| どの軸の入口か | 重装カウンター（「貯める」= 堅実な構え・紙一重・黄金の錨 → 「撃つ」= この札） |
| この職らしさ | 「装甲を砲台の動力にする」。置いた砲台が毎ターン勝手に、守りの分だけ強く撃つ |
| ほかに無い役割（1行） | **ブロックを、何ターンも続く自動の射撃に変える**唯一の札（シールドスラム・障壁の魔弾・城塞崩しは、その時1回だけ撃つ） |
| 上限 | 1発の足し算は最大+10（ブロックの上限25の40%）。砲台は1台だけ・3ターン |
| 要る部品 | 小さい部品1つ: 砲台が撃つ時に「持ち主の今のブロックの○%」を足す印（今の `summon` に1項目足す程度） |

- 良い所: 守りを固めるほど、何もしなくても砲台が強く撃つ。「今ターンは守って、砲台に撃たせる」という悩みができる。
- 心配な所: 砲台は戦闘の初めの「自動砲台」とぶつかる（置き直しで上書き）ので、「いつ置き直すか」の判断が要る（悩みとしては良いが、説明の文を分かりやすくする必要がある）。

#### 案B: 「過負荷運転」— 背水ブラッドの入口

| 項目 | 中身【提案】 |
|---|---|
| 種類 | 新しい札・技・レア・コスト0・成功率85%・機工士の札 |
| 効果 | **自分のHPを4払い**、砲台と罠がすぐ1回動く（成功1で2回）。この時の砲台・罠のダメージに、**自分の減っているHPの20%を足す（最大+10）**。1ターンに1回 |
| どの軸の入口か | 背水ブラッド（HPを払う → 減ったHPで強くなる） |
| この職らしさ | 機械を「無理やり回す」オーバーヒート |
| ほかに無い役割（1行） | **HPを払って仕掛けを動かす**唯一の札（ほかの背水の札は、自分の攻撃・マナ・引く札に変える） |
| 上限 | 1ターン1回・足し算は最大+10 |
| 要る部品 | 小さい部品1つ: 砲台・罠が撃つ時に「減っているHPの○%」を足す（`summonStrike` に1項目） |

- 良い所: 0コストなので、クイックドローなどの手数とも組める。HPを削るほど砲台が強くなる、分かりやすい賭け。
- 心配な所: 機工士には「一撃で吸収して回復」の札が届かないので、背水の後半（回復して立て直す）が欠ける。難しめのゲームでHPを払うのは危なく、選ばれにくいかもしれない。

### 2-2. 調教師

#### 案A（おすすめ）: 「かこめ！」— 状態異常の受け皿（お供が弱った敵を囲む）

| 項目 | 中身【提案】 |
|---|---|
| 種類 | 新しい札・物理・レア・コスト1・成功率75%・調教師の札 |
| 効果 | 対象に 3 / 5 / 7 のダメージ。**対象に付いている悪い状態異常1種類につき、お供がその敵へ1回行動**（最大 2 / 2 / 3回）。状態異常は消さない |
| どの軸の入口か | 状態異常バースト（付ける側 = 鞭の音・薙ぎ鞭・子守歌・鋼芯の鞭・お供のレッサーパンダ／黒猫／オカメインコ／小竜 → 受ける側 = この札・総崩れ・獣の群れ） |
| この職らしさ | 「かこめ！」の合図で、お供が弱った敵にぴょんと飛びかかる（お供は傷つかない） |
| ほかに無い役割（1行） | **敵の状態異常の「種類の数」を、お供の行動の回数に変える**唯一の札（獣の群れは威力を上げる・総崩れは消して威力を上げる・竜脈解放は全体にダメージ） |
| 上限 | 1枚で最大3回。お供の行動の「1ターン4回まで」にも数える（無限にならない） |
| 要る部品 | 小さい部品1つ: お供の行動の回数を「対象の悪い状態異常の種類」で決め、狙いをカードの対象にする（今のお供の行動は、先頭の敵を狙う） |

- 良い所: 鞭とお供で弱体・呪い・傷つきやすいを重ねるほど、お供がたくさん動く。お供が主役のまま、2本目の道ができる。
- 心配な所: 「1ターン4回まで」の上限に、相棒の覚醒などで先に届いていると、この札のお供の行動が出ない時がある（その時はダメージだけ）。「バースト（起爆）」と言うには、状態異常を消さない・倍にしない分、おとなしい。

#### 案B: 「ぎゅっ」— オーバーヒールの入口

| 項目 | 中身【提案】 |
|---|---|
| 種類 | 新しい札・技・レア・コスト1・成功率80%・調教師の札 |
| 効果 | 自分のHPを 5 / 8 / 11 回復。**HPからあふれた分は、味方全員のブロックになる**（1人あたり最大6） |
| どの軸の入口か | オーバーヒール（なでなで・癒しの曲・満ち潮の杯 で満タンを保つ → あふれをみんなの守りに） |
| この職らしさ | お供をぎゅっと抱くと、ぬくもりがみんなに広がる。相棒の覚醒で、お供もいっしょに動く |
| ほかに無い役割（1行） | **自分のあふれた回復を、味方全員の守りに広げる**（溢れる祝福は対象1人のブロック＋聖光・満ち潮の杯は回復を1人へ流す・天使の羽衣は自分のブロック） |
| 上限 | 1人最大6・1枚1回 |
| 要る部品 | 小さい部品1つ: あふれた回復の行き先を「味方全員」にする（今の `overflowHeal` に1項目） |

- 良い所: 2人以上で遊ぶと、調教師がお供と一緒に「みんなを守る役」もできる。
- 心配な所: 1人で遊ぶ時は「自分のブロック」だけになり、溢れる祝福とほぼ同じ形になる。回復かブロックで相棒の覚醒が動くので、結局「手数＆お供」の強化に寄りやすい。

### 2-3. 見送った案（理由）

| 案 | 見送る理由 |
|---|---|
| 機工士: 砲台の弾に火傷を乗せる（焼夷弾） | 竜脈術師の《竜脈》（召喚が当たると状態異常を乗せる）と同じ形になる |
| 機工士・調教師: 攻撃を防いだらお供／砲台が反撃 | 2職とも同じ形になりやすく、茨の誓い・スパイクアーマー（受けたら返す）とも近い |
| 調教師: あふれた回復でお供が行動 | なでなで（満タンならブロック）と相棒の覚醒で、もうできている |
| 調教師: 背水（HPを払う） | お供の職で自分を傷つける遊び方は、可愛さ・愛着の方向と合わない |
| 札を作らず、溢れる祝福・シールドスラムを置き場の直しで渡す | 数は増えないが、この2職らしさ（仕掛け・お供）が出ない。聖光やハンマーの札が混ざるだけになる |

## 4. 作る時のこと（OK をもらった後）

- 部品: おすすめの2つなら、小さい部品が2つ（砲台にブロックの割合を足す・お供の行動の回数と狙いを状態異常の種類で決める）。戦闘のルールそのものは変えない。
- 確かめ: 新しいテスト（量・上限・2台にならない・お供の4回の上限・狙い）、型チェック・全部のテスト・ビルド・自動プレイ2人と4人。`scripts/job-axes.mjs` の印に新しい部品を足して、軸が1つの職が 2 → 0 になるか。
- 乱数: お供の行動は今の `Rng` だけを使う（オンラインでも同じ結果）。
- bot: bot は新しい札の使い方を特に知らない（前回と同じ。bot の調整は別の作業）。
- 人が遊んだ手触り（40%・+10・回数）は測れない。数値は全部【提案】。
