# 区切りG-2: 装備の見直しの案（2026-11-12・案）

**これは案です。コードは変えていません。** 機械で確かめた一覧は `docs/review/gear-shape-check.md` です。数値・名前・仕組みは全部【提案】です。

## 結論

- 装備167個を、きびしい見方（能力の種類・条件・相手・属性・状態異常まで見る）で機械にかけました。**「数字だけ違う」組は3組だけ** でした。カードほど重なっていません。
- 直す案を出すのは **5個** です: 魔法の法衣・鍛鉄の刀・均衡の槍・鋼の剣（力を変える）と、鋼の剣・熾火の剣に付ける札（鋼の連撃の代わり）。
- 属性除けの鎧6着・能力値+10の装飾品7個・状態異常の印章4個は、オーナーの決定どおり残します。

## 3. 鋼の剣・熾火の剣に付ける札（「鋼の連撃」の代わり）【提案】

「鋼の連撃」（4/8/13のただの攻撃）は、「手早い攻撃」と形が同じです。武器の力に合う、今ある札に付け替えます。

| 武器 | 力 | 付ける札の候補 | 合う理由 |
|---|---|---|---|
| **鋼の剣** | （§2 の案）成功0の後、次の物理の成功率+20% | A【おすすめ】: **全力の一撃**（コスト2・成功率65%・6/11/17） / B: 手早い攻撃 | 成功率の低い重い札と、外れた後の立て直しが噛み合う |
| **熾火の剣** | 《魔法剣》魔法カードを使った後、次の物理カードの成功率+10% | A【おすすめ】: **炎の術**（魔法・火3/5/8）×1 と **手早い攻撃** ×1 / B: 手早い攻撃×2 | 魔法の札が1枚付いているので、剣だけで力が動く（今は、魔法の札を別に持っていないと力が動かない） |

## 4. 決めてほしい事

1. **能力の無い鎧2着**（学び手の法衣・コモン／魔法の法衣・レア）
   - A【おすすめ】: 魔法の法衣は無くす（レアなのに数字だけで、能力が無い）。学び手の法衣は残す（コモンの鎧は、数字が小さい入口の品として3着だけ）
   - B: 2着とも残す
   - C: 2着とも無くす
2. **力を変える3本**（§2）: A【おすすめ】案のとおり / B 一部を変える
3. **鋼の剣に付ける札**: A【おすすめ】全力の一撃 / B 手早い攻撃
4. **熾火の剣に付ける札**: A【おすすめ】炎の術×1＋手早い攻撃×1 / B 手早い攻撃×2
