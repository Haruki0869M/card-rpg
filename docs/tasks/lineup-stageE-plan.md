# 区切りE（消耗品）の細かい計画（案）（2026-11-12・文書だけ）

`lineup-impl-plan.md` の区切りE（消耗品 50 → 24）を、作れる形にした計画です。中身は `lineup-phase3-gear.md` §3（残す9個・Gemini の15個）のとおりで、オーナーが「9個の案で良い」「消耗品24個」と決めた物です。

**ゲームのコードはまだ変えていません。OK をもらってから作ります。**

## 0. 結論

| | 今 | 区切りEの後 |
|---|---|---|
| 消耗品 | 50個（コモン25・レア25） | **24個**（コモン5・レア9・エピック7・レジェンド3） |

大きさは「中」くらいです（区切りCの半分〜同じくらい）。1回で作ります。

## 1. 残す9個（今ある物）

回復薬（HP20）・上回復薬（HP45）・気付け薬（フォーカス+2）・魔力の薄荷茶（フォーカス+1・マナ+1）・閃きの薄荷茶（フォーカス+2・1枚引く）・万能薬（状態異常を全部治す）・石粉の守り薬（ブロック10）・煙玉（必ず逃げる・ボス以外）・お供のおやつ（懐き度+10）

外す41個は `lineup-phase3-gear.md` §3-1 の表のとおりです（回復量の刻み違い・湿布7種・「2つ混ぜ」の物・煙玉のおまけ違い など）。お店の「いつも置いてある品」に外した物があれば、残す物に置き換えます。
