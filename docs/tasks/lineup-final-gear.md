# 武器・鎧・装飾品の1個ずつの最終の一覧（案）（2026-11-11・文書だけ）

Gemini の2回目の判定（`lineup-gemini2-triage.md`）を反映して、残す物・変える物・外す物を1個ずつ決めた案です。
**まだ何も作っていません。オーナーの OK の後で実装します。**

## 0. 読み方と決まり

- 物差しは憲章5「**ほかに無い役割がある物だけ**」。数は結果です（目標にしていません）。
- **能力の文と数字は、「今のまま」と書いた物のほかは全部【提案】**です（Claude が自分で決めました）。作る時と、遊んでからの調整で変わります。
- 能力値（力+8 など）は、**同じ武器種・同じ格の今の武器と同じ**にします（ここでは書きません）。
- 「今との違い」の言葉: **そのまま**＝今の能力のまま／**変える**＝名前は今の物で、能力を変える／**新しい**＝2回目の案の固有の装備。
- 付くカードに ★ が付いている物は、1回目の案（`lineup-phase2-cards.md`）の新しいカードです。★ が無い物は今あるカードです。
- 名前は、今ある名前をなるべく使いました（絵・古い保存データのため）。能力と名前が合わなくなった物は、作る時に名前を直します。

## 4. 自分で判断した所（指示・Gemini の文と違う所）

1. **属性除けの6着**: Gemini は「シナリオの名前の6着を、6属性の属性除けに」と書きましたが、今のデータは 火2・雷2・闇1・氷1 で、毒と聖がありません。**砂漠の外套を毒、雲の外套を聖**に変えて6属性にしました。
2. **武器の「完全成功で状態異常」**: 装飾品の印章（どのジョブでも使える）と同じ力なので、武器では **短剣の毒・鞭の弱体・炎の大剣** だけに残しました。前の案の「魔導書は属性ごとに1本」はコピーになるので、やめました。
3. **属性の追撃の武器9本を外した**（シナリオ限定が6本）。シナリオの個性が薄くならないか、遊んで確かめたい所です。戻すなら、1シナリオ1本を「そのシナリオだけの力」に作り直します。
4. **能力の無いシナリオ限定のレア12本**: 3本を残し、9本を外しました。
5. **春告げの錫杖・春待ちの外套・守りの護符・王家の杖・巡流の杖・突破銃・絆の錫杖・呪壁の魔導書・呪編みの大鎌**: ほかの物と同じ力だったので、変えるか外しました（表の中に理由）。
6. **錫杖のレアB・魔導書の2本目のエピックなど、役割が見つからない枠は空けたまま**です。合計は90本で、Gemini の目安（90〜105）の下の端です。
7. **楽器の「1人の時」**: 1人だと「自分以外の味方への支援」が起きないので、1人の時は自分への支援でも成立する形にしました（1人でも楽器が役に立つように）。
8. **名前と能力が合わない物**（一騎銃＝早撃ち など）は、作る時に名前を直します。
