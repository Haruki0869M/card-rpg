## 計画と違う所・自分で決めた所

| 何 | 計画 | 作った物 | 理由 |
|---|---|---|---|
| 通れない地形「険しい山」 | 「仕切りの山・峠」とだけ書いてあった | 新しい地形を1つ足した | 今の「山」は移動力3で通れるので、仕切りや盆地が成り立たないため |
| ランダムダンジョンの数 | 2つ（東1・西1） | **1つ（西）** | 2つ目はテーマ違いの別のダンジョンで、段階7a で作る物。今コピーを置くと水増しになる。東に場所の余裕は残してある |
| 街道ボーナス | 道の上で+1 | 広い地図の時だけ | 道の地形は7本で共通なので、そのままだと前の地図の6本と古い保存までやさしくなる |
| 祠 | 西に多く | 4つに3つを西 | 計画に数が無かった |
| 半島 | 数の指定なし | 1つ | 同上 |
| 薬草の群生地 | 西に置く | 回復の消耗品を1〜2個（回復薬が4つに3つ・上回復薬が4つに1つ） | 中身の指定が無かった |
| 寄り道の宝箱 | 寄り道のご褒美 | 15%で黄金箱。鍵は無し | 回り道が鍵の代わり |
| 見取り図 | 印を出す | 次の目的地だけは、霧の中でも出す | 町で聞いた行き先として |
| 地域の地形 | — | 火山に丘1、沼に平原1と丘1を足した | 足さないと、沼の中央に平原・東に丘が出ない |
| 縮小した時 | — | 0.75倍より小さい時は、移動力の数字・敵のLv・木の絵・手前の重ねを出さない | 小さくて読めない物を消して、軽くする |
