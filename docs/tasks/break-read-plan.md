# BREAK を読み合いにする・物理の職にも弱点を出す道を（2026-11-13・案）

オーナーの決定（2026-11-13）: 案Y（大物のHP ×2・後半の攻撃 ×1.5 を含む案）は取りやめ。難しさは、**先に仕組みで作り、足りない分だけを最後に小さな数字で合わせる。** ゲームは回復役がいる前提で良い（回復役がいなくても戦える道は、やりすぎない程度に残す）。測定は、必ず回復役を入れる。

この文書は、その1つ目「ア: BREAK を読み合いにする」と「ウ: 物理の職が弱点の属性を出す道」の案です。**コードはまだ変えていません。** 数値と仕組みは【提案】です。

## 1. 今の問題（測って分かった事）

- BREAK の条件は「弱点で攻撃／完全成功で当てる／合計ダメージ」のどれか1つ。**完全成功なら、どの攻撃でも崩れます。**
- 予告を見ない直行 bot が、1冒険に 48〜60回 BREAK しています。敵の特殊な行動（紫の札）は、予告の93%が BREAK で止まり、実際に出るのは1冒険に 1.4回です。
- 憲章4 の文は「弱点属性で完全成功を出し、確定凍結や BREAK で潰す読み合い」です。今の作りは、読まなくても崩せます。

## 2. ア: BREAK の決まり【提案】

**「紫の札（特殊な行動）」と「ボス・中ボス・災厄の大技」は、弱点の属性で、しかも完全成功した時だけ崩せる。ふつうの敵と強敵の、赤い札の大技は、今までどおり。**

| 予告 | 崩せる条件 |
|---|---|
| ふつうの敵・強敵の大技（赤い「大技」の札） | 今までどおり（弱点で攻撃／完全成功／合計ダメージ） |
| 特殊な行動（紫の札。手数読み・かばう・癒し封じ・増援・手負い狙い・盾砕き・浄化） | **弱点の属性で、完全成功** |
| ボス・中ボス・災厄の大技 | **弱点の属性で、完全成功** |
| 弱点を持たない敵 | 今までどおり（完全成功で崩せる） |

- 「弱点扱いにする」カードや道具（弱点看破・紅蓮の油壺 など）は、弱点として数えます。魔力の楔・閃光の破砕玉など「崩す」効果は、今のまま崩せます。カードは弱くしません。
- この形にする理由:
  - **札の色で、決まりが見分けられます**（赤 = 今までどおり・紫と大物 = 弱点が要る）。地域やレベルで決まりが変わる形より、説明が短く済みます。
  - 序盤の「一撃で崩す気持ちよさ」は残ります（序盤の敵は赤い札だけです）。
  - 紫の札の敵は3つ目の地域から出るので、「中位に転職した後から、読み合いが始まる」形になります（憲章6 の3幕）。
- 画面: 紫の札と大物の予告の下の印を「⚡弱点（属性）で完全成功 → BREAK」に。カードを選んだ時の予測欄は、条件を満たさない時に「BREAK!」と出さない。長押しの説明・ヘルプも合わせます。
- 測定での見込み（賢い bot・回復役なしの古い測定）: 全部の敵に当てた時で 100% → 75〜90%、特殊な行動が実際に出る回数は 2.5 → 13回。今回の形（紫と大物だけ）は、まだ測っていません。

## 3. ウ: 物理の職が、弱点の属性を出す道【提案】

**新しいアイテムは足しません。今ある物を、どのシナリオでも手に入るようにします。**

今ある「属性の付与」の装飾品（属性の無い物理攻撃が、その属性になる。エピック）:

| 装飾品 | 属性 | 今出るシナリオ |
|---|---|---|
| 熾火の指輪 | 火 | 全部 |
| 嵐の指輪 | 雷 | 呪われた群島だけ |
| 氷晶の首飾り | 氷 | 凍てつく王国だけ |
| 流星の指輪 | 聖 | 星降る天空城だけ |
| 悪夢の指輪 | 闇 | 夢幻の大迷宮だけ |

- 今は、シナリオと属性が合っていません（星降る天空城の大物は、弱点が闇だけなのに、出るのは聖の指輪）。
- 直し方:
  1. **5つとも、どのシナリオでも出るようにする**（宝箱・戦利品・店の候補に入れる）。
  2. **3つ目の地域の町の店に、「属性の付与」の装飾品を必ず1つ並べる**（どの属性かは種で決まる。値段は今のエピックの値段）。物理の職が、狙って手に入れられる道を1本作ります。
- これで、点検で「名前だけ違う」と言われていた5つの装飾品に、**「このシナリオのボスの弱点に合わせて、どれを持つか」という、それぞれ別の役割**ができます。
- ほかの道（今あるまま）: 共通のカード「弱点看破」（全職が候補に持つ）、紅蓮の油壺、閃光の破砕玉（今日から、エピックの宝箱で手に入ります）、魔法の仲間に崩してもらう。
- 回復役がいなくても戦える道は、この文書では作りません（難しさを測った後に、やりすぎない程度の案を別に出します）。

## 4. 気になる所

- **難しくなる向きです。** どれだけ難しくなるかは、作った後に、回復役入りのパーティで測ります（2人 = 剣士＋僧侶と魔道士＋僧侶、3人・4人も僧侶入り）。目標は「賢い bot が約15%」ですが、この1つ目だけで届くとは考えていません。
- 属性の装飾品1つに、装飾品の枠を使います。物理の職は「属性を取るか、ほかの装飾品を取るか」を選ぶ事になります（ビルドの選択として、狙った形です）。
- 賢い bot は「ボスの弱点に合う装飾品を選ぶ」作戦を持っていません。測る前に、bot にその作戦を足します（足さないと、物理の職が実際より悪く出ます）。
- 2人で遊ぶ時、弱点を出せる人に BREAK が偏ります。「だれが崩して、だれが殴るか」の相談になる、と考えていますが、遊んで確かめたい所です。
