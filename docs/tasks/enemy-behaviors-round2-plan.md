## 2. 決まり（第1弾と同じ）

- **敵を増やしません。** 今いる敵の行動を1つ、置き換えます。HP・弱点・ほかの行動はそのままです。
- **最初の2つの地域には置きません**（中位に転職する前のため）。3つ目の地域から出します。
- **全部、予告で見えます。** 予告の欄に「何をするか」と「どうすれば止まるか」を出します。全部「大技」と同じ扱いで、BREAK で潰せます。
- 1つの戦闘に、特殊な行動は2種類まで（下の割り当ては、今の敵の組み合わせで確かめてあります）。
- 「仲間を呼ぶ」で呼ばれる敵は、自分では仲間を呼ばない敵にします（呼び続けて経験値を稼げないように）。
- 色違いの敵（亜種。「呪われた〇〇」「夢の〇〇」など）は、**表に書いた敵だけ**を変えます。元の敵を変えた時に亜種へ勝手に伝わらないよう、作る時にコードで確かめます。

## 4. 気になる所（正直に）

- **難しくなる向きの変更です。** 第1弾と同じで、自動プレイの bot は予告に合わせて動きません。作った後に、2つの bot で測り直します（今、6本のシナリオの測定はまだありません）。
- **3つ目の地域に3体置いたシナリオがあります**（凍てつく王国・機械仕掛けの帝国。強敵を含めると4体。砂塵の王朝は2体＋強敵1体）。シナリオ1は、沼に2体でした。中位に転職した直後に、天敵が続けて出ます。
- **影の子（夢幻の大迷宮）は、4〜6番目の地域の敵の組 15のうち 6つに出ます。** 手数の多いビルドには、後半ずっと「まねっこ」が付いて回ります。重すぎる時の代わりの案は、夢の機械兵（4番目の地域だけ・「動きを点検する」）です。
- **貝の騎士（群島）は「かばう」＋「殴られると反撃」の組み合わせ**になります。単体攻撃だけのパーティには、かなり手ごわい敵です（全体攻撃・BREAK・先に倒す、で受けられます）。
- **鋼のゼンマイ犬**は、2回攻撃を1回にまとめます（合計のダメージは同じ）。「置き換えるだけ」から少し外れる所です。
- 竪琴の守り人・セイレーン・月のウサギ・小ダコは、守る行動ではなく、**状態異常の行動を置き換えます**（守る行動を持たない、または名前に合う行動がそれだったため）。その分、脆弱・呪いを付けられる回数は減ります。
- 色違いの敵（雷禿鷲・毒鮫・影のウサギ・毒茨の妖精・呪詛の書記官の影・鋼の銅騎士 など）は変えません。同じ見た目で、行動が違う敵が並ぶ事になります（予告を見れば分かります）。
- 確かめていない事: 強敵の部屋・中ボスの部屋で、どの敵が1体だけで出るか（データの組からは読めた分だけ確かめました）。作る時に、1体だけの時の代わりの行動が入るかを、敵ごとに確かめます。
