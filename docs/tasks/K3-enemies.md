# K3 作業書：敵の量産・亜種・絵の指示文（Codex 向け）

敵の目標は約230体。**量産は、承認された方針どおり K4（シナリオを7本にする）の中でシナリオごとに行う。**
K3 単体で作るのは、共通の敵・隠しレアの敵・corruptionKing の不足分（約30体）。土台（亜種の仕組み・オーラ・検査）は Claude が作成済み。

## 1. 今の数と、K3 の担当

| 区分 | 今 | 目標 | K3で作る |
|---|---|---|---|
| 共通（どのシナリオでも出る） | 5 | 20 | +15 |
| corruptionKing 専用 | 15（森4・沼4・火山4・魔王城3） | 28（通常18・エリート6・ボス4） | +13 |
| 隠し・レア | 0 | 14 | +14 |
| 各シナリオ（残り6本） | 0 | 各28 | **K4 の各シナリオの作業の中で** |

（`design-v2.md` の表の「今28」は古い数。コードの敵は20体。）

置き場所:
- 共通 → `src/content/common/enemies/`
- シナリオ専用 → `src/content/scenarios/<シナリオID>/enemies/`
- 新しいファイルを作る（既存を書き換えない）。1ファイルに何体書いてもよい。`export const 名前: EnemyDef = {...}`。

## 2. 敵のデータの書き方

`docs/adding-content.md` の「敵を足す」を読む。見本は `scenarios/corruptionKing/enemies/forest.ts`。

- `maxHp`・`baseLevel`・`exp`・`gold`・`size`・`actions`・`pattern`（`sequence` か `random`）。
- 通常の敵は行動3つ前後。エリートは行動3〜4と特殊能力。ボスは `phases`（HP50%以下など）で行動が変わる。
- `weak` / `resist` に属性 ID。弱点はダメージ×1.5、耐性は×0.5で状態異常も効かない。
- 行動の `{ kind: 'damage', amount, element }` で属性攻撃。
- 特殊能力 `abilities`（味方と同じ書き方）。
- **シナリオ専用の敵を共通のイベントで使わない。** 共通の敵を足す。
- 難易度は今のまま（難しめ）。同じ階層の敵と、HP・ダメージを見比べて揃える。

## 3. 亜種（全体の2割まで）

仕組み（作成済み）:
- `EnemyDef.variantOf` … 元の敵の ID。**絵は元の敵のものを使い回す**。
- `EnemyDef.aura` … 足元のオーラの色 ID（`src/data/enemyAuras.ts`: `ember` 炎・`frost` 氷・`storm` 雷・`venom` 毒・`shadow` 闇・`holy` 聖・`blood` 血・`iron` 鋼）。戦闘画面で足元が光り、元の敵と見分けられる。
- 作り方: `makeVariant(元の敵, { id, name, aura, ...変える所 })`（`src/data/enemyVariant.ts`）。

亜種を作る時の決まり（`k2k3Foundation.test.ts` が検査する）:
- **属性か開幕の特性を必ず1つは変える**:
  - 行動の `element` を変える（例: 噛みつきを炎属性に）
  - `weak` / `resist` を変える
  - `abilities` に開幕の特性を足す（`when: 'battleStart'` でブロック・状態異常・先制など）
- オーラは属性の色に合わせる（炎属性なら `ember`）。
- 元の敵は亜種ではない敵。亜種の亜種は作らない。
- 全体で2割まで。名前は元の敵が分かる形（例: 森の狼 → 炎の森の狼）。
- 亜種の絵の指示文は不要（絵を使い回す）。

## 4. 隠し・レアの敵（14体）

承認された方針（初期値）: **徘徊する敵の小さな確率でレアが出る** と **イベントの戦闘に隠しボスを置く**。ダンジョンの敵の組（`pools`）に `rare` 枠は作らない。
この出し方の仕組み（徘徊のレア抽選・イベントの戦闘の指定）は **Claude が土台として作る**（未実装）。Codex はデータ（敵の定義）だけ先に書いてよい。レアの敵は通常より強く、経験値・ゴールドを多くする。

## 5. 絵の指示文（Midjourney）

新しい敵（亜種を除く）ごとに、`docs/art/prompts-enemies.md` に1体1ブロックで書く。書き方:

```
### <敵ID> <名前>（<シナリオ>・<通常/エリート/ボス>・size <値>）
置き場所: src/assets/art/enemy/<敵ID>.webp（ボスの第2段階は -1）
文章: <英語の指示文> --ar 5:6
```

- 絵のスタイルは `docs/art/style-reference.png` と既存の敵の絵に合わせる。
- 背景は切り抜きやすい白の無地。文字なし。敵は1体だけ。複数体・背景の小道具・手前の人物を描かない。
- 持たせる武器・体の特徴を具体的に書き、**持たせない物**（別の武器・盾など）も書く。
- 向きは既存の敵に合わせる。大きさは `size` に合わせる（ボスは大きく、堂々と）。
- 最後に、`scripts/art/build_art.py` の ENEMIES 表に足す行も書く（番号は後でオーナーが決める）。
- 第2段階があるボスは、第2段階の指示文も書く（姿が変わる）。
- 絵は 約165枚（210体から亜種を引いた数）。一度に頼まず、シナリオごと・地域ごとに分ける。

絵が入るまで、敵は SVG の絵か頭文字の丸で表示される（動作に問題はない）。
