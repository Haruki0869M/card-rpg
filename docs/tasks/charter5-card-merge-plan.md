## 1. まとめ方の決まり【全部 提案】

1. **1組を1枚にする。** 残す札の数字・成功率は、今のまま変えません（強くも弱くもしない）。
2. **残す札の選び方**: (a) 最初の山札に入っている札 → (b) 置き場所がいちばん広い札 → (c) どの職・どの武器が持っても名前が変にならない札、の順。
3. **消す札があった場所（ジョブの報酬・武器種・系統・武器に付く札）には、残す札を置きます。** なので、ジョブの報酬の枚数は基本的に減りません（同じ組の札を2枚持っていたジョブだけ減ります）。
4. **残す札の名前が、置く先に合わない時**は、(i) 名前をどこでも合う物に変える（表に【提案】と書いた6枚）か、(ii) 置き換えずに消す（5枚）。
5. **武器にだけ付いている札（12枚。斬撃・単発射撃・居合斬り など）は、今回は触りません。** 区切りG（装備の作り直し）で、武器ごとの役割と一緒に決めます。← ここは憲章5の違反が残ります。正直に書いておきます。
6. カードの ID は変えません。消した札を持っている古い保存データは、残す札に読み替えます（保存の版を1つ上げます）。
