### 1-2. 「寄り道しない方が勝ちやすい」の記録

| 条件 | 寄り道する | しない | 記録 |
|---|---|---|---|
| 今の時間（×1.0）・2人 | 100% | 100% | `time-pressure.md` §4-1 |
| 今の時間・4人 | 95% | 100% | 同じ |
| 時間 ×1.75・2人 | 35% | **80%** | 同じ（差 −45） |
| 時間 ×1.75・4人 | 25% | **45%** | 同じ（差 −20） |
| ×1.75 ＋ ランダムダンジョンの制覇で −8% | 2人 40% / 4人 45% | 80% / 45% | 同じ（4人だけ損が消える） |

- 寄り道1回で、クリアまでのワールドターンが 4〜8 増えます。今の時間では余裕があるので損が見えず、時間を厳しくすると「罠」になります。
- 原因（記録とコードから）:
  1. **損は本物、得は弱い。** 損は時間だけですが確実。得（秘宝・専用の装備）は、bot の戦い方では「その後の戦闘が速くなる」形で時間を取り返せていません。
  2. **寄り道しなくても困らない。** 大物（ボス）はどれも、寄り道で取る物が無くても、弱点の指輪（店で必ず並ぶ）と BREAK で倒せます。寄り道の品は「あれば強い」だけで、「無いと困る場面」がありません。
  3. **何がもらえるか、行く前に分からない**（秘宝は開けるまで乱数）。災厄の専用の装備は、5つのうち2つ（強欲王の黄金冠 = 怪盗の系統だけ・魂喰らいの冥獄鎌 = 鎌の3職だけ）が多くのパーティで働きません。災厄の種類はパーティに合わせて選んでいません。
  4. **時間を返す形が無い。** ランダムダンジョンは入る +2%・出る −2% で差し引き 0。行って帰る道のりの分は、返ってきません。
  5. （推測）2人は寄り道の戦闘でHPを削られ、その後の休みで時間を取られる（`time-pressure.md` が推測として書いている。数えていない）。
- bot の側の問題（測る道具）: 賢い bot の寄り道は「ランダムダンジョン1つ・災厄1体」の決め打ちで、得と損を比べていません。時間の見込み（残り1ダンジョン15%）も、×1.75 では合いません。**このままでは、寄り道の値打ちを変えても bot の動きが変わらず、測れません。**

## 2. 案【提案】

**狙い**: 寄り道をすると時間は減るが、その時間に見合う「ほかに無い物」（ビルドを変える物・次の山場への答え）が手に入る。寄り道しないと、後の大物で困る場面がある（ただし前もって見えて、別の答えもある＝理不尽にしない）。

### 柱1: 災厄が生きている間、大物が強くなる「災厄の加護」（寄り道しないと困る形）

- 生きている災厄1体ごとに、**ボス・中ボスの戦闘に「決まり」が1つ足されます**（HP・攻撃の倍率は使わない）。倒すと消えます。
- 今の「悪さ」（店+25% など）は世界への悪さ、加護は「次の山場」への悪さ。2つ合わせて「倒しに行くか、我慢して急ぐか」を悩ませます。
- 前もって見える: 災厄が出た時の窓・上の札・ダンジョンの入口・ボスの長押しに「💀〇〇の加護: …」。

| 災厄 | 加護（大物に足す決まり）【提案】 | 答え（回復役なしでも） |
|---|---|---|
| 強欲の盗賊王 | 用心棒: 戦闘の始めに手下が1体加わる | 先に倒す・全体攻撃 |
| 瘴気を紡ぐ死霊術師 | 瘴気の衣: 大物が毎ターン少し回復する（再生） | 一気に削る・呪い・癒し封じの札 |
| 悪夢の魔獣 | 悪夢の目: 大物の最初の予告が「手負い狙い」 | HPを整えてから入る・ブロック |
| 氷嵐の魔女 | 凍てつく守り: 大物への最初の BREAK が1回だけ効かない | 2回目を狙う・手数で崩す |
| 業火の魔人 | 炉の熱: 段階の境目を越えるたび、味方全員に火傷2 | 火傷を治す・一撃で境目を越えて回数を減らす |

- 加護は保存しません（生きている災厄から毎回求める。今の「悪さ」と同じ作り）。
- 数（再生の量など）は測って決めます。

### 柱2: 寄り道でしか手に入らない「大物への答え」（見破り）

- ランダムダンジョンの主を倒すと、**「見破り」**が1つ手に入ります（パーティみんなの物）。行き先は「次に挑む鍵のダンジョン（全部済んでいれば最後）」のボスで、もらった時に名前が出ます。
- 見破ったボスの戦闘では:
  - 大技と開幕の一手が、**完全成功だけで BREAK できる**（今は「弱点で完全成功」が要る。1つ目の鍵のボスと同じ決まりに戻る）。
  - ダンジョンに入る前から、そのボスの段階の決まり・開幕の一手が地図の長押しで読める。
- これで、**弱点の属性を出せない物理のパーティにも、大物を崩す道ができます**（点検の宿題「星降る天空城は弱点が闇だけで、闇を出せる物理の職が0」への答え）。
- 1つの品ではなく「決まり」なので、コピペの品は増えません。

### 柱3: ビルドを変える物を「選べる・見える」形に

1. **黄金箱の秘宝は3つから1つ選ぶ**（今は乱数で1つ）。3つはパーティの武器種に合う物から（今の決まりのまま）。どれも「ルールを書き換える」装備なので、ジョブを問わずビルドの向きが選べます。2人以上の時は、今の「みんなで決める」（多数決・同じ数なら開けた人）で1つ選び、その後は今の取り合いのまま。
2. **災厄の種類を、パーティに合わせて選ぶ**: 出る災厄を選ぶ時、専用の装備をだれも使えない種類（黄金冠・冥獄鎌）は、使えるキャラがいる時だけ候補に入れる（乱数は今のまま冒険の Rng）。
3. **お金のご褒美を、お金以外に**: 晶洞（宝箱のお金×1.5）・隠れ処（戦闘のお金×1.3）・盗賊王（300G）は、お金が余るので値打ちがありません。【提案】晶洞 = 晶石の祭壇でカードの「変異」を2回に、隠れ処 = 闇商人の専用の装備を2つから選べる、盗賊王 = 300G の代わりに「店の品を1つ無料」。
4. 行く前に見える: ランダムダンジョンの入口の長押しに「主を倒すと: 秘宝を3つから1つ・見破り（〇〇のボス）・抜け道」。

### 柱4: 時間を「形」で返す（抜け道）

- ランダムダンジョンの主を倒して出る時、**「入口へ戻る」か「抜け道を通る」**を選べます。抜け道は、次に挑む鍵のダンジョンに一番近い、歩いて行ける空きマス（○マス以内）に出ます（乱数は使わない）。
- 勝てば時間が返り、負ければ返らない。「寄り道の時間」が、挑む危なさと結びつきます。
- 侵食度の下がる量（ランダムダンジョン −2%・災厄 −3%）は、形を入れて測った後、足りない時にだけ小さく動かします（数字は最後）。
- 盆地・半島が遠すぎる事（往復 7〜10番）・「3つの道」が道になっていない事は、地図の作り直し（6本を広げる段階6b）で扱い、ここではしません。

### 柱5: 中ボス・災厄の段階（ボスの段階の仕組みを使う。どれも別の決まり）

**災厄5体**（HP 50% で段階1つ。開幕の一手つき。1段目の紫の札とも重ならない決まり）

| 災厄 | 段階の決まり（開幕の一手）【提案】 | 使う部品 | 答え |
|---|---|---|---|
| 強欲の盗賊王 | 数え読み3「宝を抱えて逃げる」: 0で逃げる（戦闘が終わり、災厄は地図に残り、HPは元に戻る） | 数え読み＋今ある `flee` | BREAK で1つ戻す・一気に倒す |
| 瘴気を紡ぐ死霊術師 | 巻き戻し「屍の繭」: 1回だけHP50%まで戻す（予告に出る） | `healToPct` | 繭の予告を BREAK・呪い・癒し封じ |
| 悪夢の魔獣 | 溜め「悪夢の大顎」: 次の予告が見える大技 | `chargeTo` | 溜めの間に BREAK・守り |
| 氷嵐の魔女 | 弱点が入れ替わる「氷の鎧」: 火が効かなくなり、雷が弱点に | 段階の `weak`/`resist` | 合う属性の札をその時に |
| 業火の魔人 | 再生「溶岩の湯浴み」: 毎ターン回復 | 再生 | 氷で BREAK・一気に削る |

**最後のダンジョンの中ボス7戦**（2体の組）

- 共通【提案・新しい口】: **相方が倒れると、残った方が段階に入る**（HPの境目とは別の入り方。開幕の一手つき）。「どちらを先に倒すか」の悩みを作ります。HPの境目（50%）でも入ります。
- 中ボスごとの決まりは、7本で全部ちがう物にします（例: 門番ガルザ = 盾砕き、炉の巨像 = 数え読み、クラーケンの触手 = 呼ぶ、夢紡ぎ = 弱点が裏返る、など。作る時に表を作って報告）。

**ランダムダンジョンの主**は、今回は段階を足しません【提案】（5行の短い寄り道なので、主は軽く。見破りと秘宝で値打ちを作る）。

### 柱6: 測る道具（bot）を、寄り道の得と損で動くようにする

- 賢い bot の寄り道を「決め打ち」から「見える物での判断」に変えます（遊ぶ人には見えない、測る道具の直し）:
  - 加護が次のボスに掛かる災厄を優先して倒しに行く。見破りが取れるランダムダンジョンへ行く。黄金箱は点で3つから選ぶ。抜け道を使う。
  - 時間の見込みを、実際の伸び方から出す（`time-pressure.md` §6 の宿題）。
- 直行 bot・工夫する bot は今のまま（比べるため）。

## 3. 画面・2人で遊ぶ時・保存・乱数

- **画面（360×640）**:
  - 災厄の札・出た時の窓: 「💀加護: ボスに〇〇」を1行足す。
  - ダンジョンの入口（地図の長押し）: 掛かっている加護と、見破りの印「👁見破り済み」。
  - ランダムダンジョンの入口: 「主を倒すと: 秘宝3択・見破り（〇〇のボス）・抜け道」。
  - 戦闘: ボスの長押しに加護と見破り。加護はボスの名前の横に小さな 💀 の数字（札を増やしすぎない）。
  - 黄金箱: 3つの秘宝を並べる（今の `ItemPickPanel` を使う）。
  - 360×640 の画像を Playwright で撮って、重なりとはみ出しを確かめる。
- **2人で遊ぶ時**: 新しい操作は2つ（秘宝の3択・抜け道の選択）。どちらも今の「みんなで決める」（`votes.ts`）に乗せるので、だれかが止まる所は作りません。待っている側には「〇〇さんが選んでいます」（今の待ちの表示）。ダンジョンの外の仲間は、抜け道の選択に入りません（場面にいる人だけ）。2台のエミュレーターで確かめます。
- **保存と再開**: 足す状態は「見破り（どのダンジョンのボスか）」と「黄金箱の3つの候補」だけ。どちらも省いてよい形（古い保存は「見破り無し・候補1つ」）。加護は保存せず、生きている災厄から毎回求めます。保存の版は上げずに済む見込み（作る時に確かめる）。
- **乱数**: 冒険の `Rng` だけ。秘宝の3択は箱を開ける時に3つ引く（**乱数の順番が変わるので、自動プレイが別の流れになる**。古い不具合が出たら見分ける）。抜け道の行き先・加護・見破りは乱数を使いません。

## 4. 測り方

- 道具: `src/engine/__tests__/twoBots.sim.test.ts`。重い物は `node C:/dev/card-rpg-tools/heavy.mjs` を通して1つずつ。
- 条件: シナリオ1・ふつう・回復役入りの既定の組（2人 剣士＋僧侶 / 3人 ＋魔法使い / 4人 ＋狩人）・賢い bot が主・40種。直行 bot・工夫する bot も流す。
- 比べ:
  1. **前**（今のまま）と**後**（この案）を、時間 ×1.0 と ×1.75（`SIM_KNOBS=C1.75`）で。
  2. 寄り道あり・なし（`SIM_CLEVER_OFF=detour`）。
  3. 回復役なしの2人（剣士＋狩人・魔道士＋召喚士）を20種。見破りで物理の組が崩せるようになるか。
- 足す数え（テストの側だけ）: 寄り道に使ったワールドターン・抜け道で返った分・ボス戦に掛かっていた加護の数・見破りで止めた大技・ボス戦の全滅・3択で選んだ秘宝・災厄と中ボスの段階ごとの行動。
- 合格の見方【提案】:
  - ×1.75 で「寄り道あり」が「なし」より **5ポイント以上悪くない**（今は −20〜−45）。
  - 寄り道しない時に、**負けの一部がボス戦の全滅に移る**（今は 0）。
  - 直行 bot は中盤で全滅のまま。
- **時間を小さくした時の見込み（推測）**: 加護と段階で大物が少し重くなり、寄り道が損でなくなれば、目標（約15〜40%）に届く時間の倍率は ×1.75 より小さく（×1.4〜1.6 くらい）で済むかもしれません。負けが時間切れだけ、にもなりにくくなるはずです。これは「時間を小さく」の段で測って決めます。
