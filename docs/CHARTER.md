## 1. 根本のビジョン（オーナーの言葉）

これまで何度も修正を重ねてきましたが、私が「15分で終わるのは短すぎる、60分遊べるようにしたい」と言った時にダンジョンを40行・52行にコピペで水増ししたり、直行bot（`straight: true`）が勝てるように敵のレベル上昇を抑えたり、`lineup.md` で名前だけ違う同性能の装備や2刻みの回復薬を量産したりと、**「数字やタスクの表面的な帳尻合わせ」**になってしまっている部分が多々ありました。

私が作りたいのは「水増しされた作業ゲーム」ではありません。
**『For The King』『Slay the Spire』『ファイナルファンタジー』『Hades』のように、プレイヤーが時間を忘れてヤミツキになり、「もう1周、別のビルドで遊びたい！」と脳汁が出るゲーム**です。

今後のすべての設計・実装・バランス調整において、以下の【7つの大方針（マスター憲章）】を絶対の基準として判断してください。

## 2. 7つのマスター設計憲章（オーナーの言葉）

### 1. 「水増しの60分」ではなく「全25〜32戦のすべてが濃密な60分」にする
- プレイ時間を延ばすために「同じような雑魚戦や休憩所を何十行も繰り返す（40行・52行ダンジョン）」のは絶対にやめてください。人間が遊んだら8分で飽きてダレます。
- **1シナリオは約60分（ワールドマップ探索＆寄り道25分 ＋ 鍵ダンジョン3つ計24分 ＋ 最終ダンジョン11分）**を黄金比とします。
- **鍵ダンジョンは「全8〜10行」**、**最終ダンジョンは「全12〜14行（中ボスあり）」**に凝縮し、代わりに1部屋ごとの密度（2〜3行ごとに敵が確実に強くなり、奥へ行くほど「🔥深層チェインボーナス」で報酬とレア率が跳ね上がる緊張感）を高めてください。

### 2. ワールドマップは「横に広く（14〜16列×40〜44行）、寄り道の誘惑に満ちた箱庭」にする
- 横8列の「細長い1本道」では冒険のワクワク感がありません。横14〜16列の大陸に広げ、街道ルート・森林ルート・険しい遺跡ルートなど「どの道を行くか」の選択を作ってください（街道の上は移動ボーナスで快適に、ズームアウトで大陸全体を見渡せるように）。
- そしてマップ上には、メインの鍵ダンジョン以外に2つの強烈な誘惑を置いてください：
  1. **『悪さをする災厄の中ボス（スカージ）』：** 生きている間「店の価格+25%」「毎ターン侵食度+0.5%」「野営回復減少」などの悪影響を世界に与え続けるが、討伐すると悪影響が消え、**そのボス専用の超強力なユニーク装備（エピック〜レジェンド）**を確定で落とす。
  2. **『ランダムダンジョン（全5行の短期決戦）』：** 見晴らしの塔などで発見でき、最奥の主を倒すと必ず**「✨黄金箱」**が開き、通常では手に入らない「ビルドのルールを書き換える秘宝装備」が手に入る。

### 3. ダンジョン探索は「作業」をゼロにし、『Hades / スレスパ』式の「リスクと報酬の選択」にする
- ダンジョン内で「選べる扉の数（1〜3）」を決めるだけのサイコロや、0になった後に手動で押す「手番を終える」はテンポを切るだけなので廃止してください。
- 扉を選ぶ時は「中身不明」ではなく、最初から**「扉の予兆（⚔️通常戦：カード報酬 ／ 💀強敵エリート：高難度・レア装備＆カード率大UP ／ ⛺焚き火：回復orカード鍛錬 ／ 🪙宝箱 ／ 🔮イベント）」**を見せ、「今のHPで強敵エリートに挑んでレアを狙うか、安全に行くか」を毎回悩ませてください。
- 同じ種類の部屋の連続出現は禁止し、HP・フォーカス満タンで入った休憩所が無駄足にならないよう、休憩所には必ず**「⚒️技を磨く（手持ちカード1枚を『＋』に強化）」**の選択肢を用意してください。
- また、3D通路画面に描かれる扉の数・位置（左・正面・右）と、下の選択肢ボタンは100%一致させてください。

### 4. 「脳死botが勝てるバランス」を捨て、「毎ターン頭を悩ませるパズル×戦略バトル」にする
- 「転職もせず、寄り道もせず、左から順番にカードを出すだけの直行bot」がクリアできる難易度は、人間にとっては退屈なヌルゲーです。直行botなら中盤で確実に全滅し、**「マップで装備とカードを集め、敵のインテント（予告）に対してカウンターを合わせたプレイヤー」だけが突破できる歯ごたえ**にしてください。
- **戦略の3本柱：**
  1. **《BREAK（体勢崩し）》と《弱点・確定状態異常》：** 敵の危険な大技予告に対し、「フォーカスを使って弱点属性で完全成功を出し、確定凍結（1回休み）やBREAK（威力半減＋脆弱）で潰す」という読み合いを予測欄でも明確にガイドする。
  2. **《連携（チェイン+20% → +35% → +50%）》：** 仲間と攻撃順を組み立てて大ダメージを叩き出す協力感。
  3. **《FF風のカッコいい打撃感》：** 1枠ずつ止まるスロットのドキドキ感の直後に、必ず敵の立ち絵の上で「鋭い斬撃スラッシュ」「属性の大爆発」「白フラッシュとHP残像ゲージ」が炸裂する爽快感。

### 5. 「コピペ水増しアイテム」を全廃し、「拾った瞬間にビルドが化ける」カード・装備・消耗品にする
- 「名前が違うだけで中身が同じ装備（シナリオ限定装備36種のコピペなど）」や「2〜5刻みで10種類もあるHP回復薬」「誰も使わない受動的な状態異常飾り」はすべて作り直してください。
- 私たちが目指すのは**「どのジョブでも無限のビルド戦略」**です：
  - 溜めたブロックを次ターンに持ち越し、ブロック値をそのまま攻撃力に変える**【重装カウンター・盾殴り軸】**
  - 満タンの味方を回復した超過分がブロックや敵への聖属性ダメージに変わる**【オーバーヒール砲台軸】**
  - 付けた毒・火傷・呪いを一気に倍増・起爆して伝染させる**【状態異常バースト軸】**
  - 0コストカードを高速回転させて多段攻撃とお供の2回行動を叩き込む**【手数＆お供号令軸】**
  - 自傷でHPを削るほど火力が跳ね上がり、一撃で全吸収する**【背水ブラッド軸】**
- さらに、最上位・特殊の全職に「1戦闘1回のド派手なレジェンド決め技」を持たせ、消耗品にも「即BREAK玉」「全体全回復の神酒」「カード強化の砥石」など使い所に悩むエピック・レジェンド消耗品を入れてください。

### 6. 60分の冒険で「基本 → 中位 → 最上位/特殊」の3段階の成長カタルシスを味わせる
- 15分で最終職になれるのも早すぎますが、Lv9/Lv9（100戦前提）は遅すぎてダレます。
- 全25〜32戦（約60分）の旅の中で、**「序盤（Lv5で中位へ転職）→ 中盤（中位職の能力を軸に戦い、Lv5〜6＋実績条件を達成）→ 終盤（最上位・特殊職に覚醒し、専用レジェンド決め技を携えて3つ目のダンジョン〜魔王城に挑む！）」**という3幕構成の成長曲線にぴったり合わせてください。

### 7. 2人で遊んで「相談が盛り上がり、ストレスが一切ない」協力プレイUIにする
- オンラインの宝箱で「みんなの選択を待っています」の黒枠が選択ボタンの上に被さってP2がタップできなくなるようなUI重なりバグは最優先で撲滅してください。
- ダンジョンに別々に入った時の分裂問題や、誰が宝箱を開けて誰がどの装備を貰うかの相談フロー、そして相方に「こっちへ行こう！」とピンを出せる仕組みなど、**「画面の向こうのパートナーや友人とワイワイ相談しながら遊べる快適さ」**を常に最優先してください。

## 4. 作る前・終わった後のチェック表（水増しになっていないか）

計画を書く時と、報告の前に、当てはまる項目を必ず確かめます。**1つでも「はい」と言えない時は、作らずに止まってオーナーに相談します。**

### どの作業でも
- [ ] この変更は、人が遊んで「濃い・楽しい・悩む」になるか（数字やテストが合うだけではないか）。
- [ ] 目標の数字（時間・個数・勝率）を、水増しやコピーで満たしていないか。水増しでしか満たせない時は、作らずに相談したか。
- [ ] 2人で遊ぶ時に、だれも止まらない・押せない所が無いか（憲章7。新しい画面や操作を足した時は必ず）。

### カード・装備・消耗品（憲章5）
- [ ] 1つずつに「ほかのどれにも無い役割」を1行で言えるか（言えない物は作らない・消す）。
- [ ] 名前だけ違う物・数字だけ少し違う物が無いか。
- [ ] 5つの軸（重装カウンター・オーバーヒール・状態異常バースト・手数＆お供・背水ブラッド）か、ほかのビルドの核のどれに効くかを書いたか。
- [ ] 無限ループにならないか（上限を書いたか）。

### ダンジョン・世界マップ（憲章1・2・3）
- [ ] 鍵 8〜10行・最後 12〜14行・ランダム 5行を守っているか。同じ種類の部屋が続かないか。
- [ ] 扉・道の選択が「悩む選択」になっているか（どれを選んでも同じ、になっていないか）。
- [ ] 寄り道（災厄・ランダムダンジョン）に、行きたくなるご褒美と、行く危なさの両方があるか。

### 戦闘・釣り合い（憲章4・6）
- [ ] 直行 bot は中盤で全滅するか。工夫する bot は突破できるか（両方を測る）。
- [ ] 敵の予告に対して、プレイヤーが打てる手（弱点・確定の状態異常・BREAK・守り）が画面で分かるか。
- [ ] 全25〜32戦の中で、中位（序盤）→ 条件の達成（中盤）→ 最上位・特殊と決め技（終盤）の3幕になっているか。
