# 実機の2人プレイで見つかった問題の原因と計画（2026-11-09）

作成: Claude（まとめ役）。

**2026-11-09 オーナーの決定: 「6まで進めて」→ 段階1〜6を、この文書の提案の数値・やり方のまま進める**（消耗品も取り合い・侵食度は案A＋B＋C・転職は Lv6/7/5 と実績を中位から数えて4〜5倍・絵はやり方A（Midjourney）で、来るまではやり方B（仮の図）・塔と出現スポットは提案の数値）。

## 1. お供の顔が黒く欠ける（最優先）

**原因**
- 背景を切り抜く道具（`scripts/art/build_art.py` の rembg という自動切り抜き）が、**体の中の白い部分（顔・お腹の白い羽毛）も「背景」だと判断して透明にしていました。**
- その後、輪郭を黒く縁取る処理が、穴のふちにも黒い縁を付けます。そのため、えぐれたように黒く見えていました。
- スクショの鳥は、セキセイインコの青（`budgie-blue`）です。頭の47%が欠けていました。

**点検の結果（全部の絵を、外側からの塗りつぶしで調べた）**

| 種類 | 本当に欠けている物 |
|---|---|
| お供（48枚） | セキセイインコ青（頭が全部）・三毛猫（お腹）・セキセイインコ虹（お腹）・レッサーパンダ茶・文鳥シナモン（ほお）・文鳥さくら（ほお）・**オカメインコ白顔（お腹）** など7枚 |
| キャラ（176枚） | 白っぽい服の4枚（司教♀・神官♂・幻獣使い♂・影♂）は、欠けていると目で確かめた。ほかに7枚くらい、目で確かめる必要あり |
| 駒・敵 | 調べた物は、腕の輪っかなどの「本当にすき間がある所」だけだった（問題なし） |

- ダンジョンの丸いアイコンの右上のお供が欠ける件は、絵のせいではありません。**並べている欄が上をはみ出した部分を切っている**のが原因でした（`DungeonScreen.tsx`）。

**直し方**
- 元の絵と、切り抜いた途中の絵は残っています（`C:\dev\card-rpg-assets`）。
- 「外の背景につながっていない透明な所＝体の中の穴」を、元の色で埋め戻す処理を足して、作り直します。
- 今のパソコンには、build_art.py に要る Python の部品（PIL など）が入っていません。新しくダウンロードしなくてよいように、**Node と ffmpeg（入っている物）で作り直す**予定です。
- 作り直した後、48枚のお供と、直したキャラの絵を、赤い背景の上に並べた写真でお見せします。

## 2. オンラインのダンジョンで、手番以外の人が道を選べない

**原因**
- 歩く・向きを変えるのは、手番のキャラの担当の人だけ、という決まりです（仕様書 spec.md 388行）。不正な操作を防ぐためです。
- 扉を開けるのは全員の一致ですが、**「どの扉の前まで行くか」に意見を出す方法がありませんでした。** 定型文のスタンプは送れますが、「右の青い扉」のような場所は指せません。
- 世界マップも同じで、手番以外の人ができるのは、誘いへの返事・移動の提案への同意などだけです。

**分かったこと（作りやすさ）**
- オンラインの「スタンプ」は、ゲームの状態や乱数を通らずに送れる仕組みが、もうあります。同じやり方で **「ピン（こっちへ行こう！）」を足せます**。データベースの決まりも変えずに済みます。

**提案**
- **ダンジョン**: 手番以外の人が、ミニマップのマス・見えている扉・方向ボタンを長押しすると、「P2: こっち！」の印が全員の画面に出ます。歩くのは今までどおり手番の人だけです。
- **世界マップ**: マスを長押しすると「P2: ここに行きたい」のピンが出ます。
- **町の店**（下の7と共通）: 品物に「ほしい！」の印を付けられます。
- 印は数秒〜次の移動まで出て、自動で消えます。ゲームの進み方や乱数には一切さわりません。
- 「分かれ道で、全員の投票で扉を決めて自動で歩く」案も考えました。ただ、操作が重くなるので、まずはピンにします（提案）。

## 3. オンラインの宝箱で、相談なしに受取人が決まる

**原因（仕様と実装の抜け）**
- 戦闘で出た装備には「欲しい／余れば」の取り合いがあります。宝箱は別の作りで、「**開けた人が、開ける前に受取人を選ぶ**（選ばなければ開けた人）」になっていました（spec.md 381行）。
- 宝箱を開けるのは投票ではないので、**先に押した人が開けて、受取人も決めてしまいます**。相方の画面からは、開ける人も受取人も選べません。
- ボスの大宝箱も同じ流れです。その後の「ダンジョン制覇！」だけが投票です。
- 仕様書の古い所（spec.md 350行）には「欲しい人が『受け取りたい』を押す」と書いてありましたが、作られていませんでした。

**提案**
- **開ける前**: 2人以上の時は、「誰が開けるか」を全員の画面に、候補ごとの成功率・器用・運・フォーカスと一緒に出します。誰でも「〇〇に任せる」と提案でき、全員が同意したら開けます（扉と同じ形）。
- **開けた後**: 装備は、戦闘の装備と同じ **「欲しい／余れば／いらない」の取り合い** にします。全員が中身と効果（ステップAの詳しい窓）を確かめてから決めます。
- 消耗品も、同じ取り合いにします（提案）。お金は今までどおり山分けです。
- 1人で全員を操作する時は、今の流れのまま（すぐ決められる）にします。

## 4. シナリオが短すぎる・侵食度の意味がない（7本すべて）

**測った数字（シナリオ1・2人・bot）**

| 場面 | ラウンド | 侵食度 | 勝った戦闘 | だいたいの時間 |
|---|---|---|---|---|
| 1つ目のダンジョンを制覇 | 7 | 3% | 8 | 22分 |
| 2つ目のダンジョンに入る | 11 | 10% | 10 | 26分 |
| 最後のボス | 29 | 22% | 29 | 89分 |
| クリア | 33 | **28%** | 33 | 約100分 |

- 7本とも、同じ形でした。**始めが速く、後半（3つ目と最後のダンジョン）が長く、クリアの時の侵食度は30〜45%** です。
- オーナーの「15分で侵食度2%」は、ラウンド4〜5くらいです。bot はダンジョンの前にレベル上げをするので遅く、人はまっすぐ進めます。

**原因**
1. **侵食度がほとんど上がらない**
   - 1ラウンドで+1%、ダンジョンに入ると+2%、制覇すると−5%です。100%になるのはラウンド100くらいで、クリアはラウンド35〜45です。**侵食度で困る場面が、ほぼありません。**
   - 25%・50%の変化（吹雪・町の襲撃）を見ないまま終わることも多いです。
2. **交代運転で、1ラウンドに何回も動ける**
   - 2人なら移動の58%、4人なら72%が交代運転でした。1ラウンドで、2人は約2.2回、4人は約3.6回動けます。
   - それなのに、時間（侵食度）は1ラウンド分しか進みません。
3. **始めの道が短い**
   - 7本とも、地図の形は同じです。1つ目のダンジョンまで9マス、2つ目まで15マスです。
   - 鍵が要るのは最後のダンジョンだけなので、町や依頼を飛ばして、まっすぐダンジョンに行けます。

**提案（どれも、オーナーが決める数値です）**
- **A. 交代運転には時間がかかる（オーナーの案）**: 仲間が手番でグループを動かしたら、侵食度+1%（時間が進む）。交代運転の楽しさは残ります。2人ならクリアの時に約50%、4人なら約75%になります。
- **B. ダンジョンを制覇した時の侵食度の下がり方を −5% → −2%** にする。
- **A＋Bで、ふつうに遊ぶとクリアの頃に60〜80%** になり、25%・50%の変化を必ず体験する、を目標にします。
- **C. 始めの道に関所を作る**: 2つ目のダンジョンは「1つ目の鍵」か「町の依頼を1つ」がないと入れないようにする。町に寄る理由ができます。
- **仕様書の食い違い**: ダンジョンの中で時間が進むかどうかが、spec.md の380行（進む）と484行（進まない）で逆になっています。今の作りに合わせて、どちらかに直します。
- 直した後に bot で測り直して、クリアの時の侵食度・時間・クリア率を表で出します（難しさが上がりすぎないかも見ます）。

## 5. 転職が速すぎる（7本すべて）

**測った数字（2人・bot の経験値で計算。7本とも同じ形）**
- 中位に転職できる（基本 Lv5）: 10〜12戦目。1つ目のダンジョンの最中です。
- 特殊職に転職できる（中位 Lv3）: 12〜14戦目。
- **最上位に転職できる（中位 Lv4）: 14〜18戦目。2つ目のダンジョンの頃です。** 冒険全体は35〜50戦なので、**前半の3分の1で最上位になれます**。

**原因**
1. **中位は Lv4 で最上位になれて、そのための経験値は152しかない**。ボスを1回倒すと173〜314の経験値が入るので、**ボス1体で中位の期間がほぼ終わります**（経験値は山分けではなく、全員が全額もらう作りです）。
2. **転職の条件（実績）が軽すぎる**
   - 冒険の始めから数えるうえに、1回の戦闘で完全成功が約7回出ます。そのため「完全成功12回」などは1〜2戦分で、中位になった時には、もう満たしています。
   - 盗賊王の「300G」も、宝箱のお金も数えるので、すぐ届きます。
3. **転職の場所が制限になっていない**
   - 中位から最上位へは、どの町・祠でも転職できます。スタートの町からすぐ転職できるので、場所が足止めになりません。

**提案（数値はオーナーが決めます）**
- **最上位への転職を Lv4 → Lv7**（経験値584。3つ目のダンジョンの頃）。
- **特殊職への転職を Lv3 → Lv5**。
- **中位への転職を Lv5 → Lv6**（1つ目のダンジョンの後の頃）。
- **実績は、中位に転職してから数え始める**。完全成功・応援・マナの条件は今の4〜5倍に（例: 完全成功12回 → 50回）。
- 転職の場所は、今のままにします（レベルで足止めできるので、場所まで変えなくてよい）。
- 目標: 序盤（1つ目のダンジョンまで）＝基本職、中盤（2〜3つ目）＝中位職、終盤（3つ目の後〜最後）＝最上位・特殊職。
- 注意: 強いジョブになるのが遅くなるので、**中盤が今より難しくなります**。bot で測って、難しくなりすぎないか表で見せます。

## 6. 世界マップの変化が分かりにくい（彼女の感想）

**原因**
- 地域に入ると文が出るのは、初めての時だけです。地形の絵が落ち着いた色なので、地域の境目が見えにくいです。
- 夕方の色の変化は14%しかなく、気づきにくいです。
- 侵食度の紫の暗さは、侵食度に合わせて少しずつ変わります。でも、問題4のせいで、ほとんど上がらないまま終わっていました。

**提案**
- 地域の名前を上の帯にいつも出し、地域に入るたびに短い帯を出す。
- 地域ごとの色づけを少し強くし、地域の境目にやわらかい線を引く。
- 侵食度は25%・50%・75%で、世界の色を一段ずつ変えて、「世界が暗くなった」と知らせる。
- 夕方と夜の色をはっきりさせる。
- 台座にプレイヤーの色（P1は青・P2は赤など）、敵のコマには赤い縁を付けて、味方と区別しやすくする。
- **直す前に、「今」と「案」を見比べる写真をお見せします。**

## 8.【パート1】世界マップの箱庭ジオラマ化（オーナーの新しい依頼）

### 今の作り（調べた結果）
- 世界マップは SVG（ブラウザで描く図）で、六角形のマスに地形の絵（17種類: 平原・森・丘・山・海・砂漠・雪・氷・溶岩・灰・沼・荒地・雲・金属・蒸気・川・街道）を貼っています。**高さの情報も、側面も、影もありません。**
- 町・王都・ダンジョン・祠・名所・宝箱には絵があります（`art/place/` の5枚と宝箱の絵）。**イベント（？）・神殿・祭壇は、絵のないアイコン（線画の記号）**で描いています。
- 街道は、地図を作る時に「場所と場所をまっすぐ結ぶマスの地形を街道にする」作りです（`generate.ts`）。データとしては道がつながっています。でも、**描き方が「茶色いマス」なので、道に見えません**。
- 未探索のマスは、暗い六角形をぼかして重ねています。
- さまよう魔物は、丸い切り抜きの絵です。
- 時間帯は、画面全体に薄い色をかけているだけです（夕方14%など）。

### 実現の考え方
- 六角柱の立体（側面・厚み・影）、高さの差、手前のマスで奥を隠す重ね方（Yソート）、道の線、雲の霧、昼夜の光は、**今の絵のまま、描き方（プログラム）だけで作れます**。新しい絵は要りません。
- 木や山が枠から飛び出す表現と、神殿・祭壇・イベントの立体のミニチュアは、**新しい絵が要ります**（下の「絵の準備」）。
- 『For The King』の絵や見た目そのものは、まねしません。「ボードゲームの立体の箱庭」という、ジャンルとしての雰囲気を目指します。

### 6つの改修の中身（提案）
1. **六角柱のブロックと高さ**
   - 各マスの下に側面（地形の色を暗くした帯）と落ち影を描きます。
   - 高さは4段です。水・海＝0、平原・街道・沼・砂漠など＝1、森・丘＝2、山・火山・魔王城＝3。1段は六角形の半径の約12%（提案）です。
   - 上の行から順に描いて、手前の高いマスが奥の下側を隠すようにします。
   - 水面は、ゆっくり光が揺れます（「動きを減らす」の設定では止めます）。
2. **街道の線**: 隣り合う街道マス・町・神殿・橋の真ん中どうしを、なめらかな曲線の「踏み固めた土の道」でつなぎます。マスの地形の絵の上に描きます。
3. **立体のミニチュア**: 「？」「✨」「🏛」のアイコンをやめて、神殿（石柱）・祭壇（光る石の台）・イベント（旅人のテント・石碑の上に小さな「？」のバッジ）などのミニチュアの絵にします。さまよう魔物は、**赤い台座に乗った魔物の駒**（今ある敵の絵を使い、ゆっくり呼吸するように動く）にします。
4. **枠からの飛び出し**: 森の木・山の頂・町の城・ダンジョンの入口の絵を、六角形より上に飛び出させて置きます（木と山は新しい絵）。
5. **雲海の霧**: 未探索のマスを、ゆっくり流れる雲（侵食度が高い地域は紫がかった瘴気）で覆います。視界が開けたら、雲がふわっと晴れて、下からマスがせり上がる演出にします（0.4秒くらい。「動きを減らす」では即座）。
6. **時間帯の光と、探索の仕組み**
   - 朝は斜めの光、夕方はオレンジ、夜は青い月明かりにして、町・祠・祭壇・たき火は暖かく光らせます。今より、はっきり変えます。
   - **見晴らしの塔**（新しい施設）: 立ち寄ると、周り半径4マス（提案）の霧が晴れて、宝箱・神殿・レアの敵の場所が分かります。各シナリオに2〜3か所（提案）。
   - **時間で消える出現スポット**（新しい仕組み）。マップ上に見えていて、残りのラウンドが出ます。
     - 流れ星の落下地点: 3ラウンドで消える。良いアイテム（提案）
     - さすらいの行商人: 4ラウンドで去る。珍しい品の店（提案）
     - 黄金のコソ泥: 3ラウンドで逃げる。倒すとお金（提案）
     - 出る間隔は、6〜8ラウンドに1回くらい（提案）です。「まっすぐダンジョンに行くか、寄り道するか」の相談のきっかけにします。オーナーの「寄り道は得する時もある」くらいの得にします。

### 絵の準備（オーナーの手が要る所）
- 要る絵（めやす約25枚）
  - 木や山などの、飛び出す飾り。地形ごとに1〜2枚で、約14枚
  - 神殿・祭壇・イベントのテントと石碑・見晴らしの塔・流れ星・行商人の馬車などの、立体のミニチュア。約10枚
- **やり方A（おすすめ）**: 前の J4 と同じく、私が Midjourney の指示文を作り、オーナーが作って、私が切り抜いて組み込みます（新しいお金はかかりません）。今回の白抜けの反省から、**切り抜きは「体の中の穴を埋める」処理を入れてから**行います。
- **やり方B**: 絵が来るまでは、私がプログラムで描いた簡単なミニチュア（SVGの図）を仮に置いて、先に動きを作ります。
- 箱庭化の1〜2・5・6の光は、絵がなくても先に作れます。

### 気をつける所
- **スマホの重さ**: マスは1シナリオで224マス（8×28）です。側面・影・雲・光を足すと重くなるので、動く物を少なくし、作り直し（再描画）を増やさない作りにします。今ある `perf.mjs`（重さの確認）で、前と比べます。
- 拡大・縮小（1〜2.5倍）と、ガックンの直し（パネルを重ねる作り）と、一緒に動くようにします。
- 見晴らしの塔・出現スポットは、ゲームの中身（エンジン）と保存の形が変わります。保存の版を v16 → v17 に上げ、古い保存は地図を作り直さずに移します。地図に空きのマスが足りなければ、無理に置きません。
- 「今」と「案」の見比べの写真（一部の範囲）を、作り始める前にお見せします。
