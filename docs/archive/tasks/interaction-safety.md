# J4前の操作総点検

オーナーは8項目の計画を承認し、第1〜第3段階まで一括で実装・確認するよう指示した。

## 対象

1. 新しい冒険の確認・初期化と画面分岐。
2. 全カード/道具/能力の対象を点検。味方単体・自分以外・戦闘不能・敵単体、星読み予約と複合カードの2対象。
3. 世界マップの全員の手番と交代運転。移動は運転者の判定を使い、同行者の手番を消費しない。
4. 共同施設の各自の利用と全員の終了確認。受け渡しと宝箱の受取人。
5. 敵の狙いを名前と単体/全体で示す。
6. 実処理を使ったダメージ/回復等の予測。元状態/乱数を変更しない。
7. 状態・能力・お供・召喚のタップ詳細。
8. 対象・手番・待機理由・使用結果を明示し、対象や状態アイコンを覆う表示を除く。

## 実装上の判断

- 回復の初期選択はHP割合が最も低い生存対象、同率は表示順。ランダムにしない。
- 自分専用/全体/自動の能力は、その既存の範囲を維持。自動能力に毎回の確認は追加しない。
- 敵への攻撃と味方単体への回復を持つ2枚は、両方を選べるよう副対象を追加する。
- 対象選択中は手札と操作パネルを入れ替える。敵・味方を覆う拡大カードを取り除き、小さい高さではパネル内部をスクロールさせる。
- 祠は一度だけの恵みを維持。施設ごと/キャラごとに勝手に報酬を増やさない。共同施設は全員の利用終了を待つ。
- 旧保存の施設は入場者のみ、旧予約は最低HP割合の味方を補完。過去の行動済みや未記録の条件を推測で増減しない。
- 案Aの移動機会増加は承認済み。敵・侵食度などの難易度の数値を変えない。
- 予測は実際の効果・能力処理を状態の複製上で使う。追加抽選を含む値は目安と明示する。
