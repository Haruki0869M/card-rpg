# J3c: 最上位13職

## 目的
中位ジョブ（Lv4以上＋その道の条件）から転職できる最上位ジョブ13職を作る。最上位は「その道の決め技」で、終盤に暴れる時間を作る。

## 作るもの（各職: クラスのファイル1つ ＋ 専用カード5枚。先頭3枚を signature に）
置き場所: `src/content/common/classes/<id>.ts`、カードは `src/content/common/cards/topJobCards.ts`。
書き方の手本: 中位ジョブ（例 `swordmaster.ts`）と `midJobCards.ts`。`tier: 'top'`、`from: ['<中位のid>']`、`requires: { feat, count, text }`。

- 「奇跡」（教皇。コスト0・1戦闘1回・味方全員のHPと状態異常を全回復）、「強奪」（大怪盗。コスト1・選んだ敵の次の行動の数値を半分にして、その種類に応じた効果を自分が受ける）、「跳躍」（竜騎士。次の敵フェーズに攻撃を受けず、次のターンに大ダメージ）は**レジェンドのカード**にして `jobCards`（転職した時に山札へ）に入れる。1戦闘1回は、カードを使ったら山札から外す効果（例: exhaust）を部品として作ってよい。
- 能力に足りない部品は、条件・効果・常時型の部品として足す（ジョブIDで分岐しない）。
- 中位→最上位の転職は「町の聖堂・祠」でだけできる（もう実装済み。`src/engine/game/jobs.ts`）。

## 確かめること
