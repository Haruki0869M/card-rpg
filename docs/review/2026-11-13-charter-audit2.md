## 4. これから入れる予定の「案Y」について

案Y = ボス・中ボス・災厄の大技は「弱点の属性で、しかも完全成功」の時だけ崩れる ＋ 大物のHP ×2 ＋ 3つ目の地域より後の敵の攻撃 ×1.5。オーナーが OK 済みで、別の作業フォルダで作っている途中（main にも公開にも、まだ入っていない）。

点検役の指摘:
1. **難しさの元は、BREAK の決まりではなく「大物のHP ×2・攻撃 ×1.5」。** 負けの大半は、全滅ではなく時間切れ。大物の戦闘が 3.7 → 6.7〜7.6 ラウンドに伸びる。伸びた分に新しい読み合いが無ければ、憲章が禁じている「数字の帳尻合わせ・水増し」に当たる心配がある。
2. **物理の職が、大物の弱点を出す道が、ほとんど無い。** 星降る天空城は、大物4体とも弱点が闇だけで、闇を出せる物理の職は 0。シナリオ1しか測っていないので、数字に出ていない。
3. **測定が、回復役のいないパーティだった。** 回復役入りだと、案Y は 15%（剣士＋僧侶）〜55%（魔道士＋僧侶）。
4. 攻撃 ×1.5 は、4人の時の倍率（1.7〜1.9）と掛かって、2.5〜2.85倍になる。
5. 画面の文（「弱点か完全成功で BREAK」など）を直さないと、嘘の案内になる（これは、今の作業に入れてある）。
6. ふつうの敵は、案Y でも完全成功で崩せるままなので、N7（特殊な行動が93%止まる）は直らない。
