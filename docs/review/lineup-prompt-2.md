# Gemini への依頼文・2回目（憲章の目で、案を判定してもらう）

2026-11-11 作成。前の依頼文（`lineup-prompt.md`）は「案を出してもらう」用でした。今回は、Gemini の案をもとに Claude が作った**見直しの案を、憲章で判定してもらう**ための物です。

## 使い方

1. 下の5つのファイルを Gemini に添付する。
2. その下の「依頼文」を、そのまま貼る。

| 順 | ファイル | 中身 | 大きさ |
|---|---|---|---|
| 1 | `docs/CHARTER.md` | オーナーのマスター設計憲章（絶対の基準） | 約14KB |
| 2 | `docs/review/lineup.md` | 今のゲームの全データ（ジョブ44・カード504・武器225・鎧83・装飾品149・消耗品50・敵245・ダンジョン・状態異常・お供・同じ物の調べ） | 約390KB |
| 3 | `docs/tasks/lineup-phase2-cards.md` | 案1: カード（決め技・ビルドの軸のカード・同じカードのまとめ） | 約54KB |
| 4 | `docs/tasks/lineup-phase3-gear.md` | 案2: 武器・固有の装備・消耗品・鎧・装飾品 | 約28KB |
| 5 | `docs/tasks/lineup-phase4-jobs.md` | 案3: 新しい特殊ジョブ | 約16KB |

- 全部を一度に添付できない時は、1 と 2 を先に渡し、3 → 4 → 5 の順に1つずつ判定してもらう。
- 2 が大きすぎて読めない時は、1・3・4・5 だけでも判定はできる（その時は「今のデータは見ていない」と Gemini に伝える）。

## 依頼文

```
あなたは、カードで戦うローグライトRPG「DESTINY OF CRYSTALIA」の企画・レビュアーです。
前にあなたが出してくれた「ラインナップの見直しと追加の案」をもとに、開発リーダーの Claude が
3つの案（カード・装備と消耗品・新しい特殊ジョブ）を紙の上でまとめました。まだ何も作っていません。
添付の5つのファイルを読んで、この案を判定してください。

■ 添付ファイル
1. CHARTER.md … オーナーが決めた「7つのマスター設計憲章」。これが絶対の基準です。
2. lineup.md … 今のゲームの全データ（自動で書き出した物）。
3. lineup-phase2-cards.md … 案1: カード。一番上の「★ 憲章の目での見直し」が最新です。下の §2・§3 は前の案で、★ で外した物も残っています。
4. lineup-phase3-gear.md … 案2: 武器・固有の装備・消耗品・鎧・装飾品。
5. lineup-phase4-jobs.md … 案3: 新しい特殊ジョブ。

■ 判定の物差し（憲章から）
- 物差しは「数」ではありません。「人が遊んで、濃くて面白いか」です。数の目標は捨てました（少なくなって良い）。
- 1個ずつ「ほかに無い役割があるか」で見てください。名前と数字だけが違う物・だれも気づかない小さい数字の物は要りません。
- ビルドの軸は、重装カウンター／オーバーヒール／状態異常バースト／手数＆お供／背水（HPを払う）です。
- 戦闘の柱は、BREAK・弱点・確定の状態異常・連携（2人目+20%・3人目+35%・4人目+50%）です。
- 何も考えずに真っすぐ進むプレイヤーは、中盤で全滅するのが正しい難しさです。やさしくする方向の案は要りません。
- 最上位・特殊のジョブは全部、1戦闘1回のレジェンドの決め技を持ちます。

■ 今の作りで、変えられない事
- BREAK に「ゲージ」はありません。敵が大技を予告しているターンに、弱点属性で攻撃・完全成功・そのターンの合計ダメージ（最大HPの20%）のどれかで崩します。
- 連携は「別の味方が続けて攻撃した時」なので、1人プレイでは起きません。
- 冒険をまたいで永久に強くなる仕組み・最大HPが永久に減る代償は入れません。
- 乱数は、オンラインでも保存して再開しても同じ結果になる作りです。
- カード1枚ずつの専用の絵は作りません。新しいジョブには絵（男女の立ち絵と顔）が要ります。
- 1人でもオンライン4人でも成り立つ事。
- 消耗品を「今ある物から9個だけ残す（合計24個）」事は、オーナーが決めました。

■ お願いしたい事（この順で）
1. 【全体の判定】 3つの案は、憲章に合っていますか。合っていない所・「まだ水増しが残っている」所を、名前を挙げて教えてください。
2. 【外した物の確認】 Claude が「外す・まとめる」とした物の中に、「これは役割が違う。残すべき」という物はありますか（カード・武器の能力の型・鎧・装飾品・計画していた装備）。
3. 【残した物・新しい提案の確認】 残した物と、Claude が【提案】と書いた新しい物（背水のカード3枚・悪夢の毛皮・相棒の鈴・決め技・新ジョブの力の直し など）を、1つずつ「採用／修正（直し方）／見送り（理由）」で判定してください。
4. 【質問への答え】 各ファイルの「Gemini に見てほしい所」に答えてください。
   - lineup-phase2-cards.md の ★-5（5問）
   - lineup-phase3-gear.md の §6（8問）
   - lineup-phase4-jobs.md の §6（8問）
5. 【足りない軸】 見直しの後に、「このジョブ・この武器種は、ビルドの軸が無くなった／1つしか無い」という所はありますか。足す時は、数ではなく役割で、最小限の案をお願いします。
6. 【壊れる組み合わせ】 採用した物どうしで、強すぎて考える必要が無くなる組み合わせはありますか（例: ブロックの持ち越し＋盾殴り＋反射、0コスト回転＋マナ回復）。上限の付け方も教えてください。
7. 【次に作る一覧の方針】 この後、武器・鎧・装飾品の「1個ずつの最終の一覧」を作ります。武器種ごとの個性の表（lineup-phase3-gear.md §1-3）をもとに、1種類につき何本くらい・どんな段の付け方が良いか、考えを教えてください。

■ 答え方
- 日本語で。結論を先に。表を使い、名前を必ず具体的に挙げてください。
- 判定は「採用／修正／見送り」と理由を1行で。
- 数値は「案」と分かるように書いてください。迷う所は、2〜3の選択肢とおすすめを付けてください。
- 前にあなたが出した案と、今回の判定が変わる所は、「変えた」と分かるように書いてください。
- 長くなる時は、カード → 装備と消耗品 → ジョブ の順に分けて答えて構いません。
```

## 返事をもらった後

- Gemini の返事は `docs/review/` に日付つきで保存し、Claude が「採用・修正・見送り（理由）」に整理してオーナーに伝える（そのまま採用しない）。
- その後で、武器・鎧・装飾品の1個ずつの最終の一覧を作る。
