## 1. 作った物

### 1-1. 仕組み（エンジン。残り6本でも、データを書くだけで使える）

| 頼まれた事 | した事 |
|---|---|
| (a) 1ターン目に必ず予告する行動 | 敵の `firstActionId` を、順番の敵（sequence）でも使うようにした（今まではランダムの敵だけ）。順番の敵は、2ターン目からその行動の次から続ける。最初の段階・まだ何も予告していない時だけ（`intents.ts` の `chooseAction`） |
| (b) 割り込み（浄化） | 行動に `cutIn: { when: 'afflicted', rest }`。自分に悪い状態異常がある時は、順番を飛ばして予告する。割り込んだら、次の `rest` ターン（既定2）は割り込まない。順番の位置は進めない。順番の中にも、ふつうに残る |
| (c) 優先（仲間を呼ぶ） | 行動に `cutIn: { when: 'canSummon', rest: 1, noRepeat: true }`。呼べる時（生きている敵が上限より少ない・回数が残っている）は優先。`noRepeat` で、順番で来ても前のターンに呼んでいたら代わりの攻撃（2ターン続けては呼ばない） |
| (d) かばう | `firstActionId: 'guard'`。1体だけの時は今のとおり `fallbackIfAloneId`（闇の剣） |
| (e) 空振りを無くす | 敵の番の始めに `fallbackUselessIntent`: かばう相手がいない・呼べない（予告の後に満員・回数切れ）なら、代わりのふつうの攻撃（`fallbackIfAloneId`・`orElse`）に予告ごと替えて行う（足したブロックも付かない）。浄化は、状態異常が消えていたら何も起きないまま（頼まれたとおり） |
| (f) ブロック | データで `block` を足した。BREAK の時は、ダメージの無い特殊な行動は行動ごと止まる（今の決まり）。**手数読みは今の決まりどおり威力半分で起きるが、足したブロックは付かない**ようにした（`blockSkippedOnBreak`。下の §2） |
| 保存 | 敵の状態に任意の `cutInTurn`（最後に割り込んだターン）を足しただけ。保存の版は上げていない。無い時は「割り込める」扱い |

- 札の種類: 行動に `behavior`（`punish`・`guard`・`healSeal`・`call`・`hunt`・`shatter`・`purify`）と、任意の `brief`（1行の案内の上書き）。札の絵文字・名前・既定の1行は `src/data/enemyBehaviors.ts`。
- テストで、特殊な行動の効果を持つ行動には必ず `behavior` が付いている事、かばう・仲間を呼ぶを持つ行動には必ず代わりの攻撃がある事を確かめる（6本でデータを書き忘れると落ちる）。

## 2. 自分で決めた所（提案）

| 何 | 決めた事 | 理由 |
|---|---|---|
| BREAK された手数読みのブロック | 威力半分（今の決まり）で起きるが、足したブロック8は付かない | 指示の「今の決まりのとおり」（手数読みは半分で起きる）と「ブロックも付かない」の両方を守るため。計画 §2 は手数読みを「行動も起きない」側に入れていたが、今のコードは半分で起きる。決まりは変えていない |
| 足したブロックが BREAK で付かないのは、特殊な行動（behavior のある行動）だけ | ほかの敵の行動は今のまま | 今いる敵の決まりを変えないため |
| 割り込み・優先の「次の2ターン」 | 戦闘のターンの差で数える（`cutInTurn`） | オカメインコの先読みで行動が先に決まっても、数え方がずれないため |
| 1ターン目の行動と割り込み | 1ターン目は `firstActionId` が勝つ | 「1ターン目に必ず」のため |
| 小悪魔の休み | rest 1 ＋ noRepeat | 「2ターン続けては呼ばない」をそのまま書いた形 |
| BREAK で付く脆弱 | 悪い状態異常なので、大ガマは割り込む | 状態異常の決まりどおり。崩された次のターンに脱皮する、と見える |
| 災厄の中ボスの特殊な行動（6つ） | `behavior` だけ付けた（紫の札が出る）。数値・順番は変えていない | 「特殊な行動を予告している時は札を出す」のため。データの付け忘れのテストが全部の敵を見るため |
| 古いテストの昔の組の記録（`k3MoreEnemies.test.ts`） | 火山の2組を新しい組に書き換えた | 計画で入れ替えると決めた組のため（ゲームの決まりを変えたのではない） |
