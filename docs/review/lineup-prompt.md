# Gemini への相談文（スキル・武器・防具・アイテムの見直し）

使い方: 下の文をそのまま貼り、`lineup.md`（今のラインナップの一覧）を一緒に添付する。

```
あなたは、カードで戦うローグライトRPG「DESTINY OF CRYSTALIA」の企画・レビュアーです。
添付の lineup.md は、今のゲームのデータから自動で書き出した「全部のラインナップ」です
（カード＝スキル 504枚・武器 225・鎧 83・装飾品 149・消耗品 50・ジョブ 44）。
これを読んで、見直しと追加の案を出してください。

■ ゲームのあらまし
- 1〜4人で遊ぶ（1人・ローカル協力・オンライン協力）。スマホの縦画面。
- 1シナリオ約60分で濃密に終わるローグライト。世界マップを旅して、鍵のダンジョン3つ（8〜10行）と最終ダンジョン（13行・中ボスあり）を攻略する。
- 戦闘はカード。カードには「コスト（マナ）」「スロットの枠の数」「1枠の成功率」があり、使うと枠の数だけスロットが回る。成功した数で効果が変わり、全部成功が「完全成功」。フォーカスを使うと、枠を1つ確実に成功にできる。
- 成功率は能力値で上下する（物理＝力、魔法＝知力、スキル＝器用。カードによっては感知・運など）。
- 属性（火・氷・雷・毒・闇・聖など）と弱点、状態異常（火傷・凍結・痺れ・毒・弱体など）、ブロックがある。
- ジョブは44。基本→中位→最上位／特殊と転職する（転職するとLv1に戻り、前のジョブの戦闘の力を1つ持ち越す）。
- カード報酬は、ジョブ専用・武器種・系統（武・魔・聖・技）・共通から出る。今の山札や装備と相性の良いカードが出やすい「スマート抽選」がある。
- 装備は 武器・鎧・装飾品 の3枠。武器は種類が15（剣・刀・槍・斧・槌・短剣・弓・銃・拳・鞭・鎌・杖・魔導書・錫杖・楽器）で、装備すると山札にカードが加わる。エピック以上の装備は、必ず特別な力《 》を持つ。
- お供（ペット）12種類がいる。

■ これから入る物（今、作っている・計画している）
- BREAK: 敵の大技の予告を、弱点属性・完全成功・一定のダメージで崩せる（威力半分・弱体・ブロック0）。
- 弱点を突いた完全成功で、状態異常が確定（氷＝凍結、雷＝痺れ、炎＝火傷）。
- 連携: 同じターンに続けて攻撃すると、2人目+20%・3人目+35%・4人目+50%。
- 封魔の宝箱（罠・戦闘つきの高レア箱）。
- 世界マップを広げる（横14〜16列×縦40〜44行）。災厄の中ボス（倒すと専用のユニーク装備）。ランダムダンジョン（全5行・最奥の黄金箱・「ビルドが劇的に化ける」特別な装備。例: お供が2回行動、完全成功でマナ回復、ブロックを次のターンへ持ち越す）。

■ 一番大事にしている事
- 「どのジョブでも、無限のビルド戦略」。カードと装備の組み合わせで、遊ぶたびに違う勝ち筋が生まれること。
- 難しめが良い。やさしくする方向の案は要らない。
- 毎ターン「どのカードとフォーカスで、敵の予告を潰すか」を考えるパズルの面白さ。

■ 守ってほしい決まり
- 冒険をまたいで永久に強くなる仕組みは入れない（その冒険の中だけの強化は良い）。
- 最大HPが永久に減る代償は入れない。
- カード1枚ずつの専用の絵は作らない（属性・種類ごとの絵を使い回す）。新しい絵や音が要る案は、要ると分かるように書く。
- 乱数はオンラインでも保存・再開でも同じ結果になる作り。見えない所で確率が変わる仕組みは、説明できる形にする。
- 1人でもオンライン4人でも成り立つこと。

■ お願いしたい事（この順で）
1. 【今のラインナップの診断】
   - 役割がかぶっていて、選ぶ意味が薄い物（名前を挙げて）。
   - 強すぎる・弱すぎる・だれも選ばなそうな物（名前と理由）。
   - レア度の配分のかたより（例: 武器はレジェンドが66本と多い、消耗品はエピック以上が0）。
   - ジョブ・武器種・系統ごとに、ビルドの軸（例: 毒・ブロック・連撃・フォーカス・お供・ドロー）が足りない所、多すぎる所。
2. 【見直しの案】 今ある物の直し方（名前・今の効果 → 直した効果・ねらい）。数は多くても、優先の高い順に。
3. 【追加の案】
   - カード: ビルドの軸を増やす物、BREAK・弱点・連携を活かす物。
   - 武器・鎧・装飾品: 「ルールを書き換える」力を持つ物。災厄の中ボスの専用装備（3〜4種）と、ランダムダンジョンの特別な装備（10個くらい）も。
   - 消耗品: エピック以上を含めて、使い所に悩む物。
   それぞれ lineup.md と同じ書き方で（名前［レア度・種類・コスト・枠・成功率・対象］成功の数ごとの効果《特別な力》）。
4. 【組み合わせの例】 追加・見直しの後に生まれる、面白いビルドの例を5〜10個（ジョブ＋カード＋装備で、どう勝つか）。
5. 【入れない方が良い物】 壊れる恐れが大きい組み合わせ・オンラインで作りにくい物と、その理由。

■ 答え方
- 日本語で。結論を先に。表を使って、名前を必ず具体的に挙げる。
- 数値は「案」と分かるように。迷う所は2〜3の選択肢とおすすめを付ける。
- 一度に全部が長すぎる時は、1→2→3の順に分けて答えて良い。
```
