## 3. 見つけた事（重い順）

### A. 作る前にオーナーに聞く事（計画どおりに作ると成り立たない）

**A1. 災厄「灯を喰らう影」の悪さ「夜は霧の晴れる広さが1マス」は、今でもほぼそうなっている（悪さが空になる）**
- 確かめた: 視界は「2 − 夜は1 = 1マス」（`balance.ts:202-203` visionRange 2・nightVisionPenalty 1、`fog.ts:17`）。つまり、ふつうのキャラは**今も夜は1マス**。
- この悪さが効くのは、狩人の追跡・お供・装備で視界を広げたキャラだけ。ほとんどのパーティでは「悪さが何も起きない災厄」になる。憲章2の「生きている間、世界に悪影響を与え続ける」に合わない。
- 直し方の案: (ア) 夜だけでなく「昼も視界−1（最低1）」にする (イ) 「夜は、もう見えているマスの敵・災厄の印が隠れる」にする (ウ) 「見晴らしの塔が働かない（登っても見えるのは近くだけ）」にする。どれも新しい仕組みなので、オーナーに選んでもらう。

**A2. 新しいテーマ「氷漬けの宝物庫」の役割（封魔の宝箱を選んで開け続ける）は、今の5行の作りでは作れない**
- 確かめた: テーマ付きのランダムダンジョンは「1行目 = 戦闘／2・3行目 = テーマの割合／4行目 = テーマの部屋1つ／ボス」（`dungeon.ts:118-124,164`）。さらに「同じ種類が続かない」「同じ行は全部ちがう種類」「テーマの部屋の手前の行には同じ種類を出さない」（`dungeon.ts:150-158`）。
- 4行目を宝箱にすると、3行目には宝箱が出せず、2行目も宝箱は1部屋まで。**宝箱は多くても「2行目に1つ＋4行目に1つ」**で、「宝箱を開け続ける」にならない。
- 残る違いは「封魔 80%（封魔の地下迷宮は 60%。`dungeonThemes/themes.ts:27`）」「部屋ごとHP−4%」「奥が休憩でなく宝箱」。これは**封魔の地下迷宮の数字ちがい＋HPの税**に近く、憲章5（数字だけ違う物）に当たる心配がある。
- もう1つ: 封魔の宝箱は1つごとに番人（強敵の組）との戦闘が付く（`balance.ts:164-171`）。計画の「戦闘は少なめ」と食い違う。
- 直し方の案: (ア) 宝箱を増やさず、寒さを主役にする（例「凍える深み」: 部屋ごとに寒さ、休憩の部屋でだけ寒さが止まる・奥ほど寒さが強い。「HPが減る前に急ぐか、休憩に寄るか」の悩み）(イ) このテーマだけ「宝箱が続いて良い」決まりにする（憲章3の「同じ種類の連続は禁止」と食い違うので、すすめない）(ウ) 新しいテーマは見送り、共通の3つのまま2か所にする（計画の質問3の B）。

**A3. 3つの道の「西 = 速い」が、今の移動の決まりでは成り立っていない（中央の方が速くて暖かい）**
- 確かめた: 移動力 = 1d6（`balance.ts:210`）。街道は移動力1で、さらにサイコロ+1（`terrains/basic.ts:5`・`lanes.ts terrainDiceBonus`）。計画の「湖の氷」は移動力1だけ。**街道は平均4.5マス、湖の氷は平均3.5マス**で、中央の方が速い。
- すると道の悩みは「西 = 寒い・回復なし・敵が少ない」「中央 = 速い・暖かい・町・敵が多い」になり、西を選ぶ理由が「敵が少ない」だけになる。計画の表の「HPを削られても早く着くか」が悩みにならない（憲章 §4「どれを選んでも同じ、になっていないか」の逆で、「いつも中央」になる心配）。
- 直し方の案: (ア) 湖の氷にもサイコロ+1 を付ける（「滑る」。街道と同じ速さで、敵が少ない分だけ西が速い）(イ) 湖の氷を+2 にして、はっきり西を最速にする (ウ) 街道を曲げて、西の湖を本当の「近道」（マスの数が少ない）にする。数字なので難しさの調整の時でも動かせるが、**道の役割そのもの**なので、作る前に決めたい。

**A4. 加護「白い息」は、1人で遊ぶと「ボス戦は必ず1ターン目を休む」になる**
- 計画: ボス・中ボスの戦闘の始めに、味方1人に凍結1。凍結 = 1回休み。1人の冒険では、その1人が必ず凍る。
- 詰みではない（次のターンから動ける）が、1人と2人以上で重さが大きく違う。オーナーの方針（1人でもオンラインでも大事）から、聞いておきたい。
- 直し方の案: (ア) そのまま（災厄を倒す理由が強くなる）(イ) 1人の時は凍結の代わりに「弱体」。

### B. 直すべき（まとめ役の判断で直せる・計画書に書き足す）

**B1. 災厄の段階2つは、よそのシナリオのボスの段階と同じ決まり**
- 「鐘の共鳴: 弱点が毎ターン入れ替わる（予告に出す）」= 星降る天空城のボス（`starCastle/enemies/hill.ts:112`「ページをめくるたび、弱点が入れ替わる」）・呪われた群島（`isles.ts:175`）と同じ。同じシナリオに出る氷嵐の魔女の段階も「弱点が変わる」（`scourgeBosses.ts:150`）。
- 「灯を奪う: 味方全員のフォーカス−1」= 夢の迷宮のボス（`dreamLabyrinth/enemies/dreams.ts:241`「味方全員のフォーカスを食べる」）と同じ種類。
- 計画 §2-2 の「今の5体とも、3体どうしでも違う決まり」は**災厄の中だけ**で比べている。ボス全部（`rule:` の一覧）と比べ直すと、新しいのは「吹雪に隠れる」だけ。
- 直し方の案: 段階を、このシナリオの軸（寒さ・鐘・灯）で言い直す。例: 凍て鐘の亡霊 = 「鐘が鳴るたびに、味方のいちばん多い状態異常が全員に写る」など。新しい仕組みになるので、案を作ってオーナーに見せる。少なくとも計画書の比べる表をボス全部に広げる。

**B2. 加護「鐘の響き（3ターンごとにブロックが消える）」は、同じシナリオの霜の巨人と重なる**
- 霜の巨人の段階は「当たるとブロックを全部壊す一撃」（`frozenKingdom/enemies/range.ts:148`）。鐘の亡霊が生きたまま鉱山に入ると、ブロックを壊す決まりが2つ重なる。別物ではあるが（周期と一撃）、重装の軸にだけ二重に効く。そのままで良いかを計画書に一言書く。

**B3. 加護「闇の帳（最初の予告が『？』）」は、憲章4・§4「予告に打てる手が画面で分かるか」と向きが逆**
- 計画 §5 はこの行を「はい（予定）」としているが、予告を隠す仕組みを足す以上、正直には「加護が掛かっている間の1手目だけ、分からない」。
- 見破りはボスの部屋だけに掛かり、中ボスには掛からない（`detour.ts applyInsight` の `b.midboss` の条件）。中ボスの「？」を消せるのは灯火のランタン（レア。宝箱・店で運しだい）だけ。
- 直し方: 仕組みは寄り道どうしがつながって良い。計画書 §5 の答えを書き直し、「？」の時に画面で「見破り・ランタン・災厄を倒すと見える」と出す事を作る物に入れる。

**B4. 伝説品3つを災厄へ移す件（点検の結果は「憲章には反しない」。注意が3つ）**
- 今の手に入れ方（確かめた）: 3つとも `scenario: 'frozenKingdom'` で `source` 無し（`frozenGear.ts:15,23,28`）。つまり、このシナリオの宝箱・店のレジェンドの枠でだけ、運で出る（`loot.ts:52,84`）。レジェンドの中身は黄金箱でも15%（`balance.ts:143`）なので、**今はほとんど出会えない**。災厄へ移すと「倒せば必ず」になり、ビルドの選択肢は減らず、むしろ増える。
- 1冒険に3体（4種類から）なので1つは出ないが、シナリオ1（5種類から3体）と同じ形で、憲章2の「そのボス専用」に合う。**憲章には反しない。**
- 注意1: 「春告げの錫杖」は武器（錫杖）。災厄は「専用の装備をだれも使えない種類は出さない」決まり（`detour.ts scourgeFits`）。錫杖を持てるのは僧侶・司教・巫女の系統だけなので、その系統がいないパーティでは「灯を喰らう影」が出ず、**毎回同じ3体**になる。4種類しか無いので、シナリオ1より顔ぶれが固まりやすい。
- 注意2: 「春待ちの外套」（鎧・凍結にならない）と、氷嵐の魔女の「永久凍土の女皇衣」（鎧・氷を受けない）は、同じシナリオの災厄のご褒美が**鎧2つ・どちらも氷の守り**。3つの中では外套が「拾った瞬間にビルドが化ける」（憲章5）からいちばん遠い（守るだけ）。組み合わせを変える（例: 白狼王 = 溶けぬ氷の腕輪）か、そのままかを計画書に書く。
- 注意3: 古い 8×35 の保存では災厄が出ないので、3つは手に入らなくなる（持っている物は使える）。計画 §2-7 に書き足す。
- 小さな事実の直し: 計画の「固有の装備9個」のうち、白狼の毛皮と氷晶の首飾りには `scenario` が無く、全シナリオ共通の品（`frozenGear.ts:21,26`）。

**B5. 「吹雪に隠れる（単体の攻撃が当たらない）」は、新しい仕組みで、止まりを作りやすい**
- 今のデータに同じ決まりは無い（`rule:` の一覧に無い）。決める事: 単体のカードしか無い時は何ができるか（番を終えるだけ？）・お供の攻撃・反撃・毒や火傷は当たるか・狙う画面で押せない事をどう見せるか。
- 戦闘の bot（賢い bot・自動プレイ）が、当たらない敵に単体のカードを出そうとして進まなくなる心配（CLAUDE.md §7 の「新しい操作を足したら同じ問題が出ないか」）。計画 §2-6 の「bot は変えない」のままだと測定と `adventure.mjs` が止まるかもしれない。作る物に「bot が隠れている敵を狙わない」と、そのテストを入れる。

**B6. 災厄の「シナリオの欄」の作りが、やりたい事を表せない**
- 計画: `ScourgeDef.scenarios`（省略 = 全シナリオ）。これだと、欄の無い今の4体（盗賊王・死霊術師・魔獣・魔人）もシナリオ2に出てしまう。
- 直し方: 地図の側に「このシナリオの災厄の一覧」を持つ（例 `ScenarioMapDef.scourges: ['whiteWolfKing', 'bellGhost', 'lightEater', 'stormWitch']`。省略 = 今の5体）。災厄を選ぶ前にしぼる（乱数の流れのため。C1）。

**B7. 温泉は、エンジンの直しが計画に入っていない**
- 「その日の寒さを受けない」は今の仕組みに無い。寒さよけは野営の「そのターンだけ」（`world.ts:460`・`climate.ts:26-27`）。新しいイベントの効果・保存する印（いつまで）・画面の印が要る。計画 §2-1 の4は「エンジンの直しが要らない」と書いているが、置き場の話だけ。
- 決める事: 「その日」は何ターンか（1日 = 8ターン。`balance.ts:205` ×4）・効くのは入ったキャラだけか全員か（2人が離れている時）・何回使えるか。
- 役割は言える（野営 = 番を使って回復＋そのターンの寒さ無し／温泉 = 場所へ行けば回復＋1日寒さ無し）。野営との違いを計画書に1行足す。

**B8. 部屋ごとHP−4% は「HPは1で止まる」と書く**
- 地図の寒さは1で止まる（`climate.ts:33-34`）。ダンジョンの部屋の寒さも同じにしないと、戦闘でない部屋で倒れる流れが要る（今は無いはず）。

**B9. 計画の事実の間違い（抜き打ちで見つけた物）**
- 「`scourge-7b.mjs` は `SC` でシナリオを選べる」→ **選べない**。あるのは保存先の `SC7B_OUTPUT` だけで、いつもシナリオ1で始める（`scripts/scourge-7b.mjs:13,22-32`）。`three-roads.mjs` と同じく、シナリオを選べるようにする作業が要る（区切り4の量が少し増える）。
- 白狼王の手下「霜の狼・白狼」→ 今の敵は「雪狼」（`frostWolf`。`foothills.ts:24-25`）で、「白狼」という敵は無い。新しい敵を足すのか、名前の書き間違いかを決める（計画は「新しく足すのは災厄だけ」）。
- 「凍った壁画…司教の過去が分かる」→ 今の文は「百年前のこの国の春」の壁画で、司教は出てこない（`dungeonEvents.ts:42-45`）。聖堂の真ん中に置くなら文を書き直す（= 中身を変える作業。「新しいイベントは足さない」とは別に、書き直しがあると計画に書く）。

### C. 軽い（作る時の注意）

- **C1. シナリオ1の乱数の流れを変えない事を、テストで守る。** テーマは地図の Rng で混ぜて配る（`randomDungeons.ts:23`）。4つ目のテーマや新しい災厄を足す時、**しぼってから**混ぜる・選ぶ（`scourges.ts:102-106`）。「同じ種で、シナリオ1の地図と災厄が前と同じ」のテストを区切り1に入れる（計画は「シナリオ1の動きは変えない」と書くだけで、確かめ方が無い）。
- **C2. シナリオだけのテーマは、4つから2つなので、出ない冒険が半分ほどある。** 出したいなら「2か所のうち1つは必ずこのシナリオのテーマ」と決める（A2 の答えしだい）。
- **C3. 見晴らしの塔の数と帯（`prefer.tower`）・祠と祭壇の帯が、計画の表に無い。** 災厄の場所は塔で分かる仕組みなので、地図のデータに必ず入れる（シナリオ1は4本）。
- **C4. 湖の氷は、氷原と「移動力2 → 1」の違いだけ。** 役割（速いが寒い道）は言えるので憲章には合うが、A3 の答え（サイコロ+1）で、はっきり別物になる。
- **C5. 白狼王の「寒さ×2」は西の帯（×2）と重なり、1ターンに最大HPの20%。** HPは1で止まり、野営で防げるので詰みは無い。数字は「後でまとめて」のとおり、記録だけで良い。
