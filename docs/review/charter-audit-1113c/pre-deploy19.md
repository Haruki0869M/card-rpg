## 3. BREAK の決まり（6f31074・952a71e・3eff453）

### 3-1. エンジンと画面の文は合っているか → 合っている
- 決まりは `effects/index.ts` の `needsWeakPerfect`・`perfectAloneBreaks`・`breakDamagePctOf` の1か所。予告の印（`BreakHint`）・長押し（`breakHowText`）・ヘルプは `breakRuleOf` か同じ関数から文を作る。
- カードを選んだ時の「BREAK！」は、**本物のエンジンを写しの上で動かした結果**（`predictCardTotals` が `break` のイベントを見る）なので、嘘の「BREAK！」は出ない。「完全成功だけでは崩れない」は、その予測で崩れない時だけ出る。
- 場合ごとに追った結果:

| 場合 | エンジン | 画面 | 判定 |
|---|---|---|---|
| 赤い札（ふつう・強敵の部屋） | 弱点／完全成功／合計20% | 「弱点か完全成功で BREAK」 | 合う |
| 紫の札（どの戦闘でも） | 弱点で完全成功だけ。合計ダメージは無し | 「弱点（属性）で完全成功 → BREAK」 | 合う |
| ボス・中ボス・災厄の戦闘 | 同じ（その戦闘の**全部の敵**に当たる） | 同じ | 合う（下の注1） |
| 弱点の無い敵 | 完全成功で崩れる | 「完全成功で BREAK」 | 合う |
| 弱点看破の印・導きの光 | 弱点として数える（完全成功が要る） | 印は元の弱点の絵だけ。予測欄は正しく「BREAK！」 | 合う（控えめな側） |
| 紅蓮の油壺 | 一時的な弱点として数える | 印に火が足される | 合う |
| 魔力の楔・閃光の破砕玉・城塞崩し | 今までどおり崩れる | 予測欄に出る | 合う |

- 注1（軽い）: ボスの部屋の手下の赤い大技も「弱点で完全成功」になる。長押しの文は手下にも「ボス・中ボス・災厄の大技は…」と出る。また、**ボスの大技は赤い札のまま**なので、計画の「札の色で決まりが見分けられる」は、ボスの戦闘では成り立たない（印の文は正しい）。
- 特殊な行動 65個（52体）は、全部 `big: true`（崩せない紫の札は無い）。

### 3-2. 弱点を出せる手立て（憲章5「どのジョブでも」）→ 一部

数えた物: 大物 63（手作りのダンジョンのボス28・中ボス14・ランダムダンジョンの主14・災厄5。重なりあり）と、紫の札の敵 52体（48＋災厄4）。

- 大物の弱点: **1つだけが 45／63**、弱点なし 2、毒だけは 0。紫の札の敵: **1つだけが 41／52**（雷 28・聖 13・火 11・氷 7・闇 4）。5つの装飾品で届かない属性の敵は 0（毒だけが弱点の敵はいない）。
- 基本8職の最初の山札: **属性の付いた攻撃は、僧侶の聖だけ。ほかの7職は 0**。
- 物理の職（剣士・狩人・武闘家・盗賊と、その先の中位・最上位）が自分の札で出せる属性: 全職共通のレアの札「属性共鳴」（成功の数で火→氷→雷に変わる）1枚だけ。**聖と闇を出す札は無い**（狩人に闇1枚）。
  - 聖だけが弱点の大物（魔王ヴァルグリム・屍術師モルデア・亡霊提督・夢喰い など）と、闇だけが弱点の大物（星降る天空城の5体＋風の番人）= **物理4職は 20／63 が「指輪だけ」**。
- 全職が持てる道: 「弱点看破」（共通・レア・0コスト。完全成功で印 → 次の攻撃が弱点扱い。その攻撃も完全成功が要る）。27枚ある共通の札の1つで、出るかは運。
- 店に必ず並ぶ指輪（`town.ts` の `featuredShopItemOf`）: 種から5つのうち1つ。10万の種で数えて、どれも 20%。
  - **並ぶのは3つ目の地域の町**。1つ目の鍵のボス（2つ目の地域）には間に合わない。
  - 最後のボスの弱点に合う割合: **7本のうち6本で 20%**（砂塵の王朝だけ 40%）。
  - 後半の大物（3つ目の鍵のボス・最後の中ボスとボス）のどれか1体に合う割合: 侵食の魔王 60%・凍てつく王国 80%・砂塵 60%・機械 40%・群島 80%・**星降る天空城 20%・夢幻の大迷宮 20%**。
  - 宝箱や戦利品で狙いの指輪が出る見込みは、エピックの装備 47個のうちの1つなので、ほぼ当てにならない。
- 測定（作業役の表）でも、星降る天空城の剣士＋僧侶は大物の BREAK が 24.7 → 2.6回。「属性の付与」の装飾品を買ったのは1冒険に 0.15〜0.5個。

判定: **オーナーが決めた形（計画 §7 の 2 = A）のとおりに作ってあるが、「道を1本作る」という狙いには、5回に1回しか届いていない。** 回復役（僧侶）がいても、聖に耐性のある星降る天空城では僧侶の聖は効かず、魔道士も闇の札は候補に1枚。憲章5 に照らすと「一部」。直す案（どれもオーナーの判断が要る【提案】）: 必ず並ぶ品を「そのシナリオの後半の大物の弱点に合う物」にする／2〜3個から選べるようにする／1つ目のボスの前にも1つ置く。

### 問題 A2（重い）: 1つ目の鍵のボス（7本とも）が、最初から「弱点で完全成功」。ほとんどの組は崩す手を持っていない

- 根拠: 決まりは「ボスの部屋」全部に当たる（`breakNeedsWeakPerfectRanks = ['boss','midboss']`）。1つ目のボスの弱点は 火・火/雷・氷・雷・雷・闇・火。基本8職の最初の山札には、これに合う属性が1枚も無い（僧侶の聖も合わない）。指輪の店は、まだ先。
- 18回目の公開までは、完全成功で崩せた。今は、最初のボス戦で「⚡弱点（火）で完全成功 → BREAK」と出るのに、たいていの組は何も出来ない（魔道士・召喚士が火の札を拾っていた時と、油壺・破砕玉・弱点看破を持っていた時だけ）。
- 計画の文は「序盤の一撃で崩す気持ちよさは残る」「読み合いは、中位に転職した後から」だったが、これは**ふつうの敵の話で、ボスには当たっていない**。オーナーは表（ボス・中ボス・災厄も）に OK を出しているが、「最初のボスから」とは伝わっていない心配がある。
- 説明は出る（印・予測欄・長押し・ヘルプ）ので、嘘ではない。守る・耐えるという手は残る。憲章4「打てる手が画面で分かるか」は「分かるが、持っていない」。
- 案【提案】: 1つ目の鍵のボスだけ今までどおりにする／1つ目の地域の店かイベントに、そのボスの弱点の道具（油壺のような物）を置く／このまま出して、オーナーが遊んで決める。

## 4. 難しさ（数字は作業役の測定。シナリオ1・ふつう・回復役入り・40種）

| | 18回目の形（Y0） | 今の main |
|---|---|---|
| 賢い bot（2人・3人・4人） | 100・100・100% | **98・98・100%** |
| 工夫する bot | 100・100・100% | 95・98・95% |
| 直行 bot | 18・57・13% | **5・13・13%** |
| 1戦のラウンド（賢い・2人） | 3.48 | 3.65 |
| 紫の札の BREAK（賢い・2人。予告 22.8 のうち） | 19.3 | 7.5 |

- **少しだけ難しくなった。やさしくする向きの変更は、混ざっていない**（案Y の HP×2・攻撃×1.5 は外してある。`enemyHpByRank`・`enemyAttackByRegion` は空）。部屋の並びは戦う部屋が増えた。時間（侵食度）は測っただけで、数値は変えていない（`git diff` で balance.ts を確かめた）。
- ただし、**回復役入りの賢い bot は今もほぼ全部クリアする。** オーナーの目標（15%・40%でも良い）からは遠い。N5（やさしい）・H1（工夫しなくても勝てる）は残っている。次の手（侵食度 ×1.75 など）は測定だけで、まだ入っていない。
- 直行 bot: 2人 5%・3人 13%・4人 13%。全滅の場所は3つ目の鍵（溶岩の洞窟）に移った。「中盤で確実に全滅」には近づいたが、まだ 5〜13% はクリアする（D5 は一部）。部屋の並びの測定（20種）では、直行 bot のクリアが 3→5・2→5 に増えていた（ぶれの中か分からない）。
- 回復役のいない物理の組（剣士＋狩人）は 85% → 40%。回復役入りでも狩人＋僧侶は 100% → 60%。組による差が広がった（オーナーの「回復役がいる前提で良い」の中だが、狩人＋僧侶は回復役入り）。

## 7. 重い順の問題の一覧

1. **A2: 1つ目の鍵のボス（7本とも）が最初から「弱点で完全成功」で、基本8職の最初の山札では崩す手が無い。** 18回目までは完全成功で崩せた。計画の説明（序盤の気持ちよさは残る）と合っていない。
2. **A1: 残り6本の1つ目の鍵のダンジョンは、8行で選ぶのが2回だけ（後ろの5行は選べない）。** オーナーへの質問（ア・イ・ウ）の返事が無いまま main に入っている。
3. **物理の職の「弱点の道」が細い。** 店の指輪が最後のボスに合うのは 20%（6本）。星降る天空城・夢幻の大迷宮は、後半の大物のどれにも合わない冒険が 80%。
4. **A3: 2つ目の鍵のダンジョン（7本）は、強敵を必ず1回通り、選ぶ強敵が無い。**「強敵か別の物か」の本当の扉は およそ 45（直す前 78）。
5. **回復役入りの賢い bot が 98〜100% クリアする（N5・H1）。** 直行 bot も 5〜13% クリアする。
6. **戦闘の数が 32.5〜36.9（憲章は 25〜32）。** 直す前より少し多い。
7. 特殊な行動が7つの型の使い回しで、1回が軽い（N6）。弱点を出せない組には「止められないが、困らない」。
8. 敵3〜4体の時、止め方は短い印「⚡（絵）+完全」だけ。
9. 鍵付きの宝箱が4行目に浅くなった（1つ目・2つ目の鍵）。
10. 残り6本は4つの型の写しのまま（H5）。シナリオ1 のイベントは5種類を10部屋で使う。
11. 軽い: ボスの部屋の手下にも「ボス・中ボス・災厄の大技は…」と出る／ボスの赤い札は「今までどおり」ではない／赤い札の短い印が 10px ほどはみ出す見込み（前から）／STATUS.md が 18回目の後の変更を書いていない。

## 8. 公開の前に必ず直す物／公開の後で良い物

- **公開して良いか**: 止まる・嘘が出る・データが壊れる類の不具合は見つからなかったので、技術の面では出せる。ただし、下の2つをオーナーに伝えて返事をもらってからが良い。
- **公開の前に必ず直す物（不具合）**: なし（読みの範囲。テスト・型チェック・画面の確認は、まとめ役がいつもの手順で回す事）。
- **公開の前に、オーナーに決めてもらう物**:
  1. A2（最初のボスから「弱点で完全成功」）: このまま出すか、1つ目の鍵のボスだけ今までどおりにするか、弱点の道具を手前に置くか。
  2. A1（1つ目の鍵の型の選ぶ所 2つ）: 報告の案 ア・イ・ウ の返事。
- **公開の後で良い物**: 店の指輪の合う割合（3）・2つ目の鍵の強敵（4）・難しさの本体（5。侵食度の案と寄り道の得を組にして）・戦闘の数（6）・特殊な行動の中身（7）・狭い時の止め方の文（8）・宝箱の深さ（9）・型の写し（10）・軽い文の直し（11）。

## 9. 確かめていない事

- テスト・型チェック・ビルド・Playwright（回していない）。360px の画面の実際の見え方。
- 難しさの数字の測り直し（文書の値を使った）。シナリオ1 と星降る天空城の一部の組のほかは、だれも測っていない。
- 途中の保存データ（古い並びのダンジョンの中で保存した冒険）を新しい版で開いた時の動き（部屋は保存データの中にあるので変わらない、と推測）。
- 弱点看破が実際の報酬にどのくらい出るか（スマート抽選の重みは読んでいない）。
