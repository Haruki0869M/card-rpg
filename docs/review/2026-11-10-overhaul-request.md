## 【パート1】「60分で濃密に終わる黄金ボリューム」と「成長曲線」の再設計（水増しの撤廃）

### 1. ダンジョン40行・52行の水増し（`grownLayout`）を撤廃し、「全8〜12行の濃密なダンジョン」にする

**問題点**
- 鍵のダンジョンを40行、最終ダンジョンを52行にループ水増ししたせいで、8分潜っても探索度15%しか進まない。
- 深さの敵レベル補正を9行分に丸めているため、何十部屋進んでも同じ強さの敵と休憩所が続くだけの退屈な作業になっている。

**修正仕様**
- **鍵のダンジョン（3か所）：「入口からボスまで 8〜10行」**（所要時間：1ダンジョン約8〜10分）。
- **最終ダンジョン（魔王城など）：「入口からボスまで 12〜14行（途中に中ボス行あり）」**（所要時間：約15分）。
- **世界マップの高さ：** 49行から **「34〜36行」** に引き締める。移動だけの間延びを防ぎつつ、見晴らしの塔・祠・出現スポットへの寄り道がちょうどよく機能する広さにする。
- **深さによる敵の強化：** 水増しをやめるので、ダンジョンの奥（2〜3行ごと）に進むにつれて敵のレベルと編成がしっかり強くなるようにする。「奥へ行くほど緊張感が増し、報酬（ゴールド・経験値・レアカード確率）も+15%→+30%→+50%と跳ね上がる（深層ボーナス）」ようにする。

### 2. 60分の中で「基本 → 中位 → 最上位/特殊」の3段階ビルドが綺麗に完成する成長曲線へ

全体が「約25〜32回の濃密な戦闘（約60分）」に凝縮されるのに合わせ、Lv9/Lv9（100戦前提）になっていた転職レベルと条件を適正化する。

- **基本 → 中位：Lv5**（1つ目の鍵ダンジョン攻略前後で到達）
- **中位 → 特殊：Lv5 ＋ 条件**（2つ目の鍵ダンジョン攻略前後で到達）
- **中位 → 最上位：Lv6 ＋ 条件**（3つ目の鍵ダンジョン〜最終ダンジョン突入前に到達）
- 最上位・特殊職の条件カウント（中位転職後から計測）も再調整する。この戦闘回数（中位期間で約10〜12戦）の中で、意識してそのプレイスタイル（完全成功を狙う、状態異常を入れる、支援する等）を徹底すれば達成できる数値にする（例：完全成功20〜25回、支援25回など）。

## 【パート2】ダンジョンを「ヤミツキの選択空間」に変えるシステム改修

### 1. 「選べる扉の数（1〜3）のサイコロ」を廃止し、『Hades / スレスパ』式の「扉の予兆（リスク＆リターン選択）」へ

**問題点**
ダンジョン内で「何回扉を選べるか（1〜3）」を決めるだけのサイコロは、テンポを悪くしているだけ。1が出た時の流れは次のとおり。

1. 1部屋進む
2. 選べる扉が0になる
3. 「手番を終える」を手動で押す
4. 次の人がまた振る

**修正仕様**
- ダンジョン内の「扉の数を決める探索サイコロ」と「手番を終える」ボタンは廃止する。1部屋クリアしたら、すぐ次の分岐扉をパーティーで選べるようにする。
- 分岐の扉には「中身は分からない」ではなく、最初から**「その扉のカテゴリとご褒美の予兆」**を表示し、毎回悩ましい選択をさせる。

| 扉 | 表示 |
|---|---|
| ⚔️ **赤い扉（通常戦）** | 「魔物の群れ（カード報酬＋ゴールド）」 |
| 💀 **紫の扉（強敵エリート）** | 「強敵の棲処（🔥高難度 ／ レア以上カード＆装備ドロップ率大UP！）」 |
| 🪙 **金の扉（財宝）** | 「宝物庫（宝箱）」または「封魔の宝箱（罠・戦闘つき高レア箱）」 |
| ⛺ **緑の扉（休憩・鍛錬）** | 「焚き火の休憩所（HP回復 ／ フォーカス回復 ／ カード強化）」 |
| 🔮 **青い扉（イベント）** | 「未知の祭壇・行商人（能力アップ・カード変異・特殊取引）」 |

- さらに先まで読めるようにする場合: 感知が高いキャラやフクロウがいる場合、または「周囲の警戒（クールダウン制またはフォーカス1消費）」を使った場合。読めるもの: 具体的な敵名・宝箱の格・次の次の行の分岐。

### 2. 部屋の偏り防止（同種連続の禁止）と、休憩所の「⚒️カード鍛錬（強化）」追加

- 「休憩→休憩」「イベント→イベント」の連続出現を禁止する。
- 通常戦闘は最大2連続まで（次は必ずエリート・イベント・宝箱・休憩が混ざる）にする。
- **休憩所のヤミツキ化：** HP・フォーカスが満タンの時に休憩所に入っても無駄足にならないよう、休憩所に第3の選択肢**「⚒️ 技を磨く（手持ちのカード1枚を『＋』に強化する）」**を追加する。
- 狙いは、スレスパのような「被弾を抑えて戦えば、休憩所で回復の代わりにデッキを強化できる！」という中毒性。

## 【パート3】戦闘の「戦略性（スレスパ×FTK）」と「カッコよさ（FF風エフェクト）」の強化

### 1. 「ただ殴るだけでは勝てない、考えて崩すのが楽しい」敵の戦略ギミックと弱点ブレイク

**直行bot（`straight: true`）の基準見直し**
- 「転職もせず寄り道もせず、カードを左から出すだけのbot」がクリア率50%以上になるバランスは、人間には簡単すぎて退屈。
- 直行botは2つ目のダンジョンで全滅するようにする。**「装備とカードのシナジーを組み、敵の予告に対処したプレイヤー」だけが突破できる歯ごたえ**にする。

**敵の戦略的な行動と「ブレイク（体勢崩し）」**
- 対象: 強敵やボスが「大技の溜め（次ターン強攻撃）」や「全体攻撃予告」を出している時。
- 次のどれかで、ピンチを覆せるようにする。
  - 「弱点属性で攻撃する」または「完全成功を当てる／一定ダメージを与える」と、敵の大技予告の威力が下がる。
  - または『⚡BREAK!（弱体1＋ブロック解除）』する。
  - または、弱点属性の完全成功で状態異常が確定する。

  | 属性 | 確定する状態異常 |
  |---|---|
  | 氷 | 凍結＝行動キャンセル |
  | 雷 | 痺れ＝30%行動失敗 |
  | 炎 | 火傷 |

- 予測欄に**「❄️完全成功で凍結（敵の行動を止める！）」**と大きく明示する。
- 毎ターン「どのカードとフォーカスで敵の予告を潰すか」のパズル性を前面に出す。

**連携の段階ボーナス**

| 同じターンに続けて攻撃した仲間 | ボーナス |
|---|---|
| 2人目 | 連携+20% |
| 3人目 | 大連携+35% |
| 4人目 | 極連携+50% |

攻撃順を相談する楽しさを高める。

### 2. 実機動画で抜けていた「攻撃・魔法の着弾エフェクト（SVG斬撃・属性爆発）」の確実な表示

- 技名コール帯や敵の行動順バーは入っている。しかし実機動画では、攻撃が当たった瞬間のエフェクトがまだ見えていなかった（敵の上の斬撃スラッシュや火球・雷撃）。
- スロットが止まった直後に、必ず敵の立ち絵の上で次の演出がはっきり見えるようにする。描画レイヤー（z-indexや表示タイミング）を確認・修正する。
  - **「鋭い斬撃の閃光」**
  - **「属性の爆発エフェクト」**
  - **「敵の白フラッシュと揺れ」**
  - **「HPバーの白い残像ゲージ」**
- 次の3つも直す。
  - 頭上スロット枠が敵のインテント文字と重ならないように位置を調整する。
  - 失敗時の「✖」枠が暗くて見えない問題を改善する。
  - フォーカス使用枠（★）の黄金発光を改善する。
