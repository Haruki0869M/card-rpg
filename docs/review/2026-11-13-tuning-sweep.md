# 難しさのつまみを1つずつ測り、「賢い bot が約15%」に届く組み合わせを探した結果（2026-11-13）

オーナーの決定（2026-11-13）「賢い bot が、大体15%しかクリアできない難しさにする。カードは弱くしない（敵の側・世界の側を強くする）。数字をゲームに入れるのは、表を見て OK を出してから」の **測る所まで** です。
**ゲームの決まり・数値は1つも変えていません。** 測るためのつまみ（切り替え）を `src/data/balance.ts` に足しましたが、既定の値は全部「今と同じ動き」です。値の差し替えは測定のテスト（`twoBots.sim.test.ts`）の中だけで行い、本番のコードは環境変数を読みません。

## 0. 結論（先に）

- 1つだけ入れて「15%」に届くつまみはありませんでした。一番効いたのは **侵食度の伸び ×1.5（C2）** で 2人 45%・4人 60% ですが、負けが全部「時間切れ」になります。
- 組み合わせると、効き目は **足し算より大きく** なります（どれも余裕を削り合うため）。8通り試しました（§3）。
- 2つの案を 40種で確かめました（§4）。
  - **案A「BREAK の決まり中心」= B3 ＋ H4 ＋ A2**（弱点の属性で、しかも完全成功の時だけ崩れる ＋ ボス・中ボス・災厄のHP ×2 ＋ 3つ目の地域より後の敵の攻撃 ×1.5）: 賢い bot **2人 10%・3人 20%・4人 13%**。3つの人数とも 10〜20% に入りました。
  - **案B「敵の強さ中心」= H2 ＋ H4 ＋ A2**（3つ目の地域より後の敵のHP ×1.5 ＋ 大物のHP ×2 ＋ 攻撃 ×1.5）: 賢い bot **2人 5%・3人 5%・4人 15%**。2人・3人は少し強すぎました。
- **おすすめは 案A**（理由は §6）。ただし **大きな心配が1つ** あります: 属性の攻撃をほとんど持たない **剣士＋狩人（物理2人）は、案A で 0%**（BREAK が1冒険 1.7回しか起きない）。案A を入れるなら、物理の職が「弱点の属性」を出せる手立て（属性の武器・属性を付けるカード）が足りているかを先に確かめる必要があります（§7）。
- 1戦の平均ラウンドは、どの案でも **2.5〜3.8**（目標 4〜6 には届かない）。大物（ボス・中ボス・災厄）の戦闘は、案A で **6.0〜7.6 ラウンド**、案B で 7.8〜9.9 ラウンドになりました。
- **注意:** この後「敵の特殊な行動を1ターン目に出す直し」（`docs/tasks/enemy-behaviors-fix-plan.md`）を入れると、難しさがもう一段上がります。**最後の数字は、それを入れた後に測り直して決めます。**

## 6. おすすめ: 案A（B3 ＋ H4 ＋ A2）

理由（憲章からの優先の順）:
1. **BREAK が読み合いになる**（優先1）: 案A では BREAK のほとんど（93〜98%）が「弱点の属性で、しかも完全成功」です。直行 bot の BREAK は 1冒険 34〜42回 → 3〜5回に減り、「予告を見ないで殴っても崩れる」が無くなります。案B は今の決まりのままなので、BREAK の5〜7割が完全成功のままです（憲章の点検 `2026-11-13-charter-audit.md` の H2 の指摘が残る）。
2. **大物の戦闘が 6.0〜7.6 ラウンド**（優先2）: 目標の「4〜6 ラウンド以上」に入ります。案B（7.8〜9.9）は少し長すぎる心配があります（人が遊ぶと、ボス戦1回が長い）。
3. **回復役のいないパーティだけが落ちる、にならない**（優先3）: 上の比べのとおり、案A は回復役の有無の差が小さい。
4. **全滅と時間切れの両方で負ける**（優先4）: 案A 賢い bot で 全滅 25回・時間切れ 78回（120回中）。
5. **3つの人数とも 10〜20%** に入った（案B は 2人・3人が 5%）。

ただし、入れる前に必ず考える事:
- **属性の攻撃が少ないパーティ（剣士＋狩人）が 0%** です。憲章の「どのジョブでも無限のビルド戦略」から見ると、ここが一番大きい問題です。賢い bot は「属性の武器・属性を付けるカードを探して取る」工夫をしていないので、人ならもう少し勝てるかもしれませんが、確かめていません。
- 入れる前の案（**提案。作っていません**）:
  - (ア) 物理の職が「弱点の属性」を出せる手立て（属性の付いた武器・属性を付けるカード・弱点看破）が、序盤から店や報酬で手に入るかを数える。足りなければ、それを足す（カードを弱くする方向ではなく、物理の道を増やす方向）。
  - (イ) B3 の「弱点が無い時の扱い」を広げる: 例えば「パーティのだれも、その敵の弱点の属性の札を手に持っていない時は、完全成功で崩せる」。ただしこれは画面の案内が複雑になります。
  - (ウ) B1 と B3 の間の案: 「ふつうの敵は今のまま、大物だけ B3」。これは測っていません。
- 1戦の平均ラウンドは 2.5〜3.0 のままで、目標（4〜6）には届きません。ふつうの戦闘を長くするには、ふつうの敵のHPか、1戦の敵の数を変える別のつまみが要ります（**提案**。今回の13通りには入っていない）。

## 7. 心配な点（人が遊んだ時）

- **「弱点で、しかも完全成功」はフォーカスを多く使う**ので、人は「フォーカスが足りない」と感じやすくなります。今の 2〜3 のフォーカスで、毎ターン崩すのは難しい形です。予告を見て「このターンは守る」と決める遊び方が増えるはずですが、人が楽しいと感じるかは、遊んで確かめる必要があります。
- 魔法の組（魔道士＋僧侶）だけが楽な形になる心配（55% 対 0〜10%）。
- 大物のHP ×2 で、ボス戦が 6〜8 ラウンド。人の手で1ラウンド30秒〜1分なら、ボス戦1回が 5〜8 分です。「60分の冒険」の時間の配分（魔王城 11分など）と合うかは、人の遊びで確かめる必要があります。
- 直行 bot が鍵2の中でほぼ全滅するので、初めて遊ぶ人は「鍵2（沼）で急に難しくなる」と感じる心配があります（3つ目の地域から攻撃 ×1.5 のため）。
- 「やさしい」「むずかしい」の難易度への影響は **測っていません**（ふつうだけ）。案A を入れると、やさしい も同じ割合で難しくなります。やさしい の数字は別に決める必要があります。
