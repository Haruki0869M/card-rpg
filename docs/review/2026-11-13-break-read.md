## 3. 読み取れる事

1. **読み合いは起きている**: 紫の札の BREAK は 1冒険 19〜33回 → 3〜13回、大物の BREAK は 16〜31回 → 4〜11回。理由の「完全成功だけ」は大きく減り（賢い 2人: 32 → 8回）、「弱点」は変わらない（17〜29回）。特殊な行動が実際に出る回数は、賢い bot で 2人 3.9 → 9.7回、直行 bot は 25回前後。
2. **直行 bot は崩せなくなった**: 2人 18% → 5%、3人 57% → 13%（全滅の場所が溶岩の洞窟に移った）。
3. **回復役がいると、賢い bot・工夫する bot はほぼ全部クリアする**（95〜100%）。BREAK が減っても、大物のラウンドが 0.3〜0.9 ラウンド延びるだけで、負けに結びついていない。負けは全部「侵食度100%」。
4. 組で差が出た: 回復役なしの剣士＋狩人は 85% → 40%（弱点を出せる手がほぼ無く、紫の札を崩せたのは 2回）。回復役ありでも狩人＋僧侶は 100% → 60%（侵食度切れ 8回）。魔道士の入った組は崩れにくい。
5. 星降る天空城（大物の弱点が闇だけ）: 剣士＋僧侶は大物の BREAK が 24.7 → 2.6回と、ほとんど崩せなくなった。それでもクリアは 100%。
6. 「属性の付与」の装飾品は、あまり買われていない（1冒険 0.15〜0.5個）。weak を外した方が多く買っていた（0.40 → 0.15。weak は合わない属性を買わないため）。bot は「次のボスとまだ戦っていない」間は地域の敵の弱点で選ぶので、3つ目の地域の町で並ぶ1つが合う事が少ない。weak あり・なしのクリアの差（100% と 95%）は、20種では誤差の範囲。

## 4. 目標との差

- 目標（オーナーの言葉）: 賢い bot が、回復役入りで約15%（40%でも構わない）。
- 今回: **2人 98%・3人 98%・4人 100%**（Y0 は 100%）。目標から大きく外れていて、**この1つ目（BREAK の読み合いと装飾品の道）だけでは、ほとんど難しくなっていません**。計画 §4 の「この1つ目だけで届くとは考えていない」のとおりでした。
- 追加の調整はしていません。

## 5. 心配な点

- 回復役なしの物理の組（剣士＋狩人）にだけ強く効いた（85% → 40%）。弱点の手を持たない組ほど紫の札を浴びる形で、回復役入りの組との差が広がった。
- 星降る天空城の物理の組は、大物をほぼ崩せない（闇の装飾品は、店で並ぶかが運しだい。並ぶのは1冒険に1種類）。
- 直行 bot が負ける場所が、魔王城から溶岩の洞窟に移った（3人の直行 bot は 57% → 13%）。人が予告を読まずに遊ぶと、3つ目の鍵で詰まりやすくなっている見込み。
- 3つ目の地域の町の品は、入れ替わっても同じ物（売り切れの後もまた並ぶ）にした。違う形が良ければ直します。
