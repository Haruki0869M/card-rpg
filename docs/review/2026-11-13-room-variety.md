# 部屋の並びの直し（憲章3「同じ種類の部屋の連続は禁止」・2026-11-13）

計画: `docs/tasks/room-variety-plan.md`（オーナーの OK 済み）。直し方の決まり（まとめ役から）:

- どの道を通っても、続けて同じ種類（部屋の type）の部屋に入らない。ふつうの戦闘→強敵・強敵→ボス・中ボスの前後は「違う種類」。1行目はふつうの戦闘。
- 同じ行の部屋は、全部ちがう種類にする（部屋が1つの行は対象外）。
- 両方を同時に守れない所は「連続なし」を優先し、守れなかった所を書く。
- 手作りの28か所: 行の数・各行の部屋の数・道のつながり・ボスと中ボスの場所・ボスの前の休憩は変えない。type だけを、できるだけ少なく替える。ふつうの戦闘の替え先は (1) イベント → (2) 宝箱（コモン・鍵なし）→ (3) 強敵。
- どの道でも、ふつうの戦闘は、鍵のダンジョンで2回以上・最後のダンジョンで4回以上残す。強敵・休憩・宝箱の数は、ダンジョンごとに今から ±1 まで。

## 2. 決めた事・自分で判断した所【提案】

1. **道ごとの戦闘の下限を、同じ行の決まりより先に守った。** 道のつながりを変えずに「連続なし」と「同じ行は全部ちがう」の両方を守ると、型A・型B・エメラルドの神殿・沈黙の地下墓地では、ある道のふつうの戦闘が1回（入口の1回だけ）、最後のダンジョンは2回になってしまう（行ごとの全部の割り当てを調べる小さなプログラムで確かめた）。経験値とカード報酬が大きく減るので、下限を守り、その代わりに「ふつうの戦闘が2つ並ぶ行」を残した。逆（同じ行を全部ちがう種類にして、戦闘の下限を下げる）にしたい時は、下の「別の案」の並びにできる。
2. **ふつうの戦闘を休憩に替える事はしなかった**（替え先の決まりに無いので）。そのため、いくつかの所で「イベント→休憩」「休憩→戦闘」「強敵→戦闘」など、ふつうの戦闘以外の部屋も替えた（下の表の太字）。
3. **イベントは、同じダンジョンで「替えたので空いたイベント」を先に使い、足りない分だけ、まだ使っていないイベントを使った。** そのため、ダンジョンの中のイベントの顔ぶれは、ほとんどの所で前と同じ（場所が1行ずれただけ）。新しく入ったイベント: エメラルドの神殿なし／沈黙の地下墓地・溶岩の洞窟・魔王城 = 倒木（fallenTree）。ほかの6本は、型Aの1つ目のイベントなど、同じシナリオのイベントを使った（下の「写しの24か所」）。
4. **宝箱の格（レジェンド・エピック）は減らしていない**（替える時に格の高い箱を残す向きに選んだ）。最後のダンジョンのレジェンドの宝箱も前のまま。
5. ランダムダンジョンでは、「同じ種類」を扉の予兆と同じ分け方（宝箱と封魔の宝箱は同じ・イベントと祭壇と闇商人は同じ）で数えた。type より厳しいので、type の決まりも守れる。同じ行の決まりは「予兆の種類が全部ちがう」→「type が全部ちがう」→「決まりなし」の順にゆるめる（つながる前の部屋と同じ種類は、どの段でも出さない）。

## 3. 守れなかった所（同じ行に同じ type）

すべて「ふつうの戦闘が2つ並ぶ」行。テスト（`dungeonShape.test.ts` の `ROW_DUP_ALLOWED`）に書いてあり、これ以外の行で重なるとテストが落ちる。

| ダンジョン | 行（1から数える） | 理由 |
|---|---|---|
| エメラルドの神殿 | 5 | 前から「戦・戦」。直すと、ある道の戦闘が1回になる |
| 沈黙の地下墓地・型B（沈んだ聖堂など6か所） | 3 | 2行目の右の戦闘を宝箱にした（入口の戦闘と続くため）ので、3行目に戦闘を足さないと、右の道の戦闘が1回になる |
| 型A（氷晶の洞など6か所） | 4 | 同じ理由（5行目の左の戦闘をイベントにしたため） |
| 最後のダンジョン（7か所） | 3・5・10 | 戦闘を4回にするには、中ボスの前で2回・後で1回以上が要り、2つの道のどちらにも戦闘を置くため |
| 溶岩の洞窟・型C（巨人の坑道など6か所） | なし | 両方守れた |

### 別の案（同じ行を全部ちがう種類にして、戦闘の下限を下げる）
型A・型B・エメラルドの神殿・沈黙の地下墓地は、ある道のふつうの戦闘が最小1回、最後のダンジョンは最小2回になる（強敵とボスを入れると3回以上）。オーナーが「同じ行の決まりを優先」と決めた時は、この形に替えられる。
