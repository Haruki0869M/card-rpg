## 1. 敵の特殊な行動のばらし（48体）

計画 §3 の表のとおりに作った（シナリオ1の7体は基本の形のまま、残り6本の41体を敵ごとの形に）。1行の案内（`brief`）と長押しの説明（`hint`）も敵ごと。行動のID は変えていない（古い保存のため）。

エンジン（新しい種類は作らず、今の7つの部品に中身を足した。乱数は使わない）:

| 部品 | 足した中身 | 使う敵 |
|---|---|---|
| 手数読み `punishPlays` | 数える札（攻撃の札・攻撃でない札・コスト0）／当たる人（いちばん多い1人・みんなの合計）／1枚ごとに重くなる／状態異常・フォーカスを奪う | 氷の釣り人・小ダコ・書記官の影・砂時計のゴーレム・蒸気砲台長・夢の機械兵 |
| かばう `guardAllies` | 傷ついた仲間だけ／ブロックが0でやめる／半分で受ける／受けた一撃を返す（ダメージ・状態異常） | 氷の騎士・貝の騎士・土人形・空の騎士・毒液の蟹（夢の石像の巨兵は「仲間にブロック」のデータだけ） |
| 状態異常 `applyStatus` | 付ける相手の条件（ブロックの無い相手・もう〇〇の付いた相手） | 砂の精・夢織り |
| 歌の印 `bindSeal`（新しい部品） | この敵が倒れると癒し封じが消える | セイレーン |
| 割り込み `cutIn` | 1体だけ・HP半分以下・倒れた仲間がいる・味方のだれかが半分以下（呼ぶ行動は「呼べる時」だけ）。決め方で選ばない行動も、最初の段階では割り込みで出せる | 凍った兵士・砲手・妖精・スパナのゴーレム・禿鷲 |
| 手負い狙い `damage` | 狙い（HPの量・前のターンに殴った人・状態異常の人）／重くなる時（ブロックが無い・状態異常がある）／半分以下の全員だけ／ブロックを無視（鎧通し） | 弓兵・鮫・月の狼・ゼンマイ犬・夢の鮫・氷の剣士 |
| 盾砕き `shieldBreak` | 飲み込む・壊した量の半分を上乗せ・壊したら弱体・BREAK でも壊す（残り香用） | 鮟鱇・彗星の狐・ピストン拳・霜の巨人 |
| 浄化 `purify` | ブロックに変える・一部だけ消す・投げ返す・蒸気（全員にダメージ）・敵みんな | スライム・ミイラ・フジツボ・プレス機・月のウサギ（枕のゴーレムは「脆弱2」のデータだけ） |

保存: 足した状態は `AllyState.playedAttack`・`EnemyState.guardStyle`・`EnemyState.sealBound` だけ（全部、省いてよい。古い保存は基本の形として動く）。

## 2. 開幕の一手（35手のうち11手）

計画 §4 の表のとおり。残り香6（トレントキング・氷晶の主・霜の巨人・月の乙女・時計仕掛けの賢者・夢喰い）、代償5（イグナヴァル・影の宰相・亡霊提督・風の番人・夢の亡霊提督）。シナリオ7本の全部に1〜2手。最後のボスの山場は今のまま。

- 残り香: BREAK された時、元の効果の代わりに軽い効果だけ（ログ「〇〇は体勢が崩れて「〇〇」が弱まった」・予告の長押し「BREAK: 弱まって「…」だけ起きる」）。溜めは今までどおり消える。
- 代償: BREAK した味方に、その場で小さな状態異常（ログ「〇〇を崩した反動」・長押し「ただし崩した人に「…」」）。
- 止めた手ざわり（脆弱1・ブロック0・行動が軽くなる・溜めが消える）は全部残した。
