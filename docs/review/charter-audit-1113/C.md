## 4. 最上位・特殊の全職に「1戦闘1回のレジェンド決め技」 — **守れている（1件だけ穴）**

- 最上位13職・特殊14職の **27職すべて**が、`jobCards` にレジェンドの札を1枚持ち、どれも「使うとこの戦闘から除く」（`exhaust` か能力の `exhaust`）。27枚とも別の札で、効果も別。持たない職: **無し**。（`auditC-finishers.mjs`）
- **穴: 時魔道士の「時間停止」が2枚持てる。** 転職すると `jobCards` で1枚入ります。その上、転職の時に選べる3枚（`jobs.ts` の `signatureCards`）が「その職にしか無い札を先に並べる」決まりなので、時魔道士は［加速・**時間停止**・時の回復］になり、もう1枚選べます（時魔道士の `cardPool` に timeStop が入っているため）。2枚あれば「1戦闘1回」が2回になります。同じ形（決め技が `cardPool` にも入っている）は 跳躍・奇跡・強奪・神降ろし の4枚もですが、この4職は専用の札が4枚以上あって、選べる3枚には入りません。
- 中身の派手さ（数値が見合うか）は、動かしていないので **確かめられなかった**。

## 6. 無限ループの恐れ — **一部（装備は上限あり。コスト0の札に穴）**

- 守れている所: 黄金箱・災厄の装備の「マナ・引く・お供」は全部上限つき（無限回廊の砂時計 = 1ターン2回、残響の指輪・氷嵐の耳飾り = 1回、悪夢の毛皮 = 2回、強欲王の黄金冠 = 2回）。お供の行動は全部合わせて1ターン4回（`abilities/index.ts` 392行）。効果の繰り返し（`repeatCard`）は深さ3で止まり、剣聖は1ターン1回・記憶の杖は1戦闘1回。
- **穴: 「コスト0で、失敗しても必ず1枚引く」札に、回数の上限がありません。**
  - 当たる札: **契約**（pact。召喚士の最初の山札。成功でマナ+1も）・**詠唱の栞**（axChantMark。魔導書の札・コモン）・**小細工**（lnGiTrick。技の系統・コモン。成功でフォーカス+1も）。
  - 仕組みの側にも歯止めが無い: 山札が切れたら**番の途中でも**捨て札を切り直して引く（`deck.ts` 15〜19行）／1ターンに使える枚数の上限は無い／マナに上限は無い（`gainMana.ts`）／使った札は、効果（引く）の**後**に捨て札へ行く（`battle.ts` 494・633行）／町で山札を5枚まで減らせる（1枚25〜40G。`balance.ts` 300行・`town.ts` 162行〜）。
  - 組める形: この種類の札を2枚（AとB）入れ、山札を「全部が手札に入る枚数」（武器の札2枚を入れて11枚以下）にしぼる。全部を手札に引いた後、A を使う → 捨て札には B しか無いので B を引く → B を使う → A を引く…が、**乱数なしで、いくらでも続きます**。
    - 召喚士の道（契約＋詠唱の栞）: 契約の成功（70%）のたびにマナ+1 → 1ターンのマナが実質いくらでも。
    - 技の系統（小細工×2）: 毎ターン、フォーカスが満タン（コスト0）。小手調べ・クイックドロー・毒針などコスト0の攻撃と合わせると、山札がまるごとコスト0で回ります。
  - 計画の決まり `docs/tasks/lineup-plan.md` 236行「コスト0が永久に続く・山札に戻り続ける形の無限ループを作らない。マナ回復・ドローは『1ターンに何回まで』を付ける」に合っていません。装備には付けたのに、札には付いていません。
  - **コードを読んだ結論で、動かしては確かめていません。** 軽いテスト1本で確かめられます。
- ほかに、上限の書いていない「使うたび」の力（弱い順ではなく、気づいた順）: 拳王《百裂拳》（ターン終了時、使った枚数×2ダメージ。上の回し方と組むと増え続けるが、拳王は上の3枚に届かない）・紅蓮の飾り（火傷を与えるたびブロック2。全体攻撃で人数分）・先読みの首飾り（技カードの完全成功のたびフォーカス+1）・魔道士《魔力暴走》・盗賊《盗む》。どれも札のコストで自然に止まるので、上のコスト0の穴がふさがれば問題は小さいです。
