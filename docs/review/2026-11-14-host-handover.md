### 1. 待ち（`src/store/onlineStore.ts` `proxyReadyAt`・`OnlineScreens.tsx`）
- 押せる時刻 = max(最後に「動いている」を書いた時 ＋ 35秒, 気づいた時 ＋ 5秒, 「もう少し待つ」の終わり)。時刻は部屋の時計（`backend.now()`）。
- 止まったとみなす 35秒（`STALE_MS`）は変えていない。
- 【提案】気づいてから最低 5秒・「もう少し待つ」は 30秒（前は 60秒のやり直し）。

### 2. 古いホストの上書き（`src/net/room.ts`。`database.rules.json` は変えていない）
1. 処理を始める前に `meta/hostUid`・`log`・`requests` を同時に読み直す（前の「記録に追いつく」読みと同じ1往復）。自分がホストでなければやめる。部屋に無い依頼は捨てる。記録に間があれば保存から取り直す。
2. `log/番号` は transaction で「空の時だけ」書く。書けなければ取り直して、その依頼をやり直す（3回まで）。
3. 記録に依頼のキー（`req`）を入れ、記録済みの依頼は二重に記録しない。
4. 断る前に、次の番号の記録がもう無いか確かめる（古い状態で相方の操作を断らない）。
5. 保存（snapshot）も transaction で、今の保存より新しい時だけ書く。
- ホストの自分の操作は、今まで通り先に画面に出す（書けなかった時だけ取り直す）。

### 3. 扉の投票（`OnlineScreens.tsx` `awaitedSeats`）
- ダンジョンの中のみんなで決める場面（扉・撤退・イベント・続ける・宝箱の開け役）と報酬の「続ける」で、まだ選んでいない席も「待っている」に数える。戦闘中・世界マップは今のまま。
- 代わりの席の票は、今の「この端末の席の分を全部入れる」経路（`battleStore.dispatchGame` の `needsVote`）で入る。新しい操作は足していない（CLAUDE.md §7 の「P1 扱い」の形は出ない）。
