## 3. 見つけた事（重い順）

### A. 止めるべき・作る前にオーナーに聞く事

**A1.【止めるべき】潮の首の盆地・入り江の「中」で潮が閉じると、閉じ込められる。大海魔が生きている間は、1人だと詰み**
- 確かめた: 盆地は中のマスの6方向のうち入口以外を全部壁にする（`generate.ts:83-87`）。半島も、中と首のまわりを壁にする（`:88-91`）。つまり**中のマス（宝箱・祠）から出る道は首だけ**。計画は首に干潟（引き潮だけ）・潮の水道（満ち潮だけ）を置く（§3-1「盆地・半島」）。
- 計画 §3-1 の5・§4 の表の「閉じても出られる」は、**潮のマスの上**に立っている時の話（首のまわりは陸か海になる。これは正しい）。**中**で宝箱を開けている間に時間帯が変わると、出る道が無い。`reachable`（`hex.ts:68-96`）は入る先のマスの移動力だけを見るので、出られない。
- 普段は次の満ち引きまで（`turnsPerTimeOfDay: 2` なので最長4ワールドターン）野営か待つだけ（`world.ts:415 waitTurn`・`:444 camp`）。止まりではないが、憲章3「作業ゼロ」に反する「待つだけの番」。2人なら片方だけ4ターン何もできない。
- **詰み**: 災厄「渦潮の大海魔」の悪さ「潮が止まる」（潮の水道も干潟も開かない）は、地図の上で生きている間ずっと効く。大海魔が出た時（侵食度の節目でいつでも出る。`scourges.ts tickScourges`）に、だれかが盆地・入り江の中にいると、**大海魔を倒すまで出られない**。1人の冒険では倒しに行けないので、霧の濃さが100%になるまで待つしかない（町へ戻る道具・魔法は無い。`帰還` を探して0件）。2人以上でも、外の人だけで大海魔を倒す事になる。
- bot も同じ（`bot.ts:352` 道が無ければ `WORLD_WAIT`）。測定で「止まらない」に見えて、実は閉じ込められて待っているだけ、が起きる。
- 直し方の案（オーナーに選んでもらう）:
  - (ア)【おすすめ】**「内側からはいつでも出られる」**: 潮で閉じたマスでも、そのマスの向こうが盆地・入り江の中なら、中から首へ・首から外へは通れる（入る向きだけ閉じる）。エンジンは `moveCostOf` に「今いるマスが閉じ込められる側か」を1つ足す。大海魔の悪さも「入れない」だけになり、詰みが消える。
  - (イ) **「潮に流される」**: 時間帯が変わった時に、閉じた首の内側にいるキャラを首の外のマスへ動かす（ログに1行）。分かりやすいが、2台で同時に動くので画面の確かめが要る。
  - (ウ) 盆地・入り江の首には潮を使わない（いつも通れる首。潮は仕切りの切れ目だけ）。いちばん安全だが、「干潟の先の宝の小島」の悩みが消える。
- あわせて、大海魔の悪さは「閉じたまま」でなく「**今の潮のまま止まる**」（満ち潮で止まれば水道は開いたまま）にすると、悪さの効き方が冒険ごとに変わり、(ア) と組めば詰みも無い（提案）。

**A2. 加護「満ちる霧」は、ダンジョンの中の戦闘で霧の濃さを進める。オーナーの決定 2-A と向きが逆**
- 確かめた: 死霊術師の悪さは「世界マップの番だけ（ダンジョンの中の番には掛けない）」がオーナーの決定 2-A（`content/common/scourges/scourges.ts:35`）。満ちる霧は、鍵と最後のダンジョンのボス戦（＝ダンジョンの中）で、6ターン目から1ターンごとに+0.5%。
- もう1つ: 霧の濃さが100%で負け。最後のボスに勝った戦闘の終わりに足して100%を越えたら、勝ちと負けのどちらが先か、決まっていない（計画は「戦闘の終わりにラウンドの数で」とだけ書く）。
- 1人の方が戦闘が長くなりやすい（手数が少ない）ので、1人の方が重い（推測。測ってから）。
- 直し方の案: (ア) そのまま（「長引くほど世界が沈む」を新しい形として認めてもらう。勝ちが先、と決める）(イ) 霧の濃さでなく、戦闘の中に返す（例: 6ターン目から、ボスが毎ターン「霧の加護」でブロック+5。一気に削る、の答えは同じ）(ウ) 戦闘の後の世界マップで、最初の番にまとめて足す（ダンジョンの中では進まない、を守る）。

**A3. 悪さ「呪われた財宝」は、ほとんど何も起きない悪さになりそう（シナリオ2の A1 と同じ種類）**
- 確かめた: 呪いは「回復が半分」だけで（`statuses/basic.ts:14`）、`decay` が無いので毎ターン1減る（`battle/statuses.ts:74-78`）。呪い2は**戦闘の1〜2ターン目の回復だけ**半分。1〜2ターン目に回復することは少ない。
- しかも掛かるのは開けた人だけ（回復役でない人が開ければ、ほぼ無害）・宿屋や浄化で消える（`town.ts:239`・`cleanse.ts:13`）・次の戦闘が弱い敵でも消える。憲章2「生きている間、世界に悪影響を与え続ける」に合わない心配。
- 直し方の案: (ア) 「呪いが減らない」呪いにする（`decay: 0` の別の状態異常「呪い金」= その戦闘の間ずっと回復半分・浄化で消える）(イ) 宝箱の中身の格が1段下がる（寄り道の値打ちを下げる、の狙いをそのまま数字に）(ウ) 開けるたびに霧の濃さ+1%（宝箱を開けるか悩む）。

### B. 直すべき（まとめ役の判断で直せる・計画書に書き足す）

**B1. ②海賊の隠れ島の「宝箱（レア）→ 封魔の宝箱」は、扉の予兆が同じ金（宝）のまま続く**
- テストの決まり（同じ type が続かない）は通る（`chest` と `sealedChest` は type が違う）。しかし予兆の分け方 `roomKind`（`dungeon.ts:89`）では両方とも「宝」で、ランダムダンジョンはこの分け方で連続を禁じている（`dungeonShape.test.ts` の「ランダムダンジョンの偏り防止」）。憲章3「同じ種類の部屋の連続出現は禁止」の意味では連続。シナリオ1・2の固定のダンジョンにも、この並びは無い（氷の城の封魔の宝箱の前は戦闘か強敵。`frozenKingdom/dungeons/dungeons.ts:130-139`）。
- 直し方: 2行目の「イ 海賊の隠し財産」と「宝 レア」の場所を入れ替える（2行目 = 強（0,1）／宝 レア（0,1）／イ 海賊の隠し財産（2））。隠し通路は「隠し財産のイベント → 封魔の宝箱 → 戦闘 → 強敵」になり、形のテーマのまま。数え直した: 道は11本のまま・ふつうの戦闘3〜4回・戦わない部屋の連続は最大2・選ぶ所6つ・強敵なしの道あり。

**B2. ①難破船の洞窟は、ほぼ1つ目の鍵の型（`keyLayout1`）の写し**
- 確かめた: 型との違いは「2行目の宝箱の行き先 (0,1)→(1,2)」と「3行目に休憩を1つ足した」だけ。4〜8行目は型と全く同じ（`dungeonLayouts.ts:30-51` と計画 §3-4 ①）。テスト（R13 = 並びの形が型と違う）は通るが、計画 §7 の「ダンジョンは型の写しをやめる」とは言い切れない。
- 直し方: 4〜5行目を「岩棚と潮だまり」の形に合わせて変える（例: 4行目を「宝 レア・鍵 / 戦 / イ」の並びを左右で入れ替え、潮だまり側（右）から鍵の宝箱へ行く形にする）。並べ直したら全部の道を数え直す。少なくともオーナーに「①は型に近い」と一言書く。

**B3. 災厄の比べる表に漏れが2つ**
- 加護「渦潮の衣（奇数ターンにブロック）」は、「決まったターンに起きる」形が凍て鐘の亡霊の加護「鐘の響き」（`bellToll`: every ターンごと。`types/world.ts:369`）と同じ拍子の形。計画は「加護で決まったターンにブロックは初めて」とだけ書く。中身（ブロック と 響くダメージ）は違うので憲章違反ではないが、表に足す。
- 段階「霧の体（1回の当たりの上限12）」は、答えが「小さく刻む・多段」で、凍て鐘の亡霊の段階「鐘のこだま（いちばん大きな一撃が返る。小さく刻む）」と答えの軸が同じ。白狼王と比べているが、こだまと比べていない。仕組み（上限 と 跳ね返し）は別。同じ「刻む」を求める物が2シナリオ続くので、表に足してオーナーに一言書く。
- ほかの比べ（引き潮 と 盾砕き、伝染、火薬樽 と 用心棒）は、`rule:` の全一覧と照らして計画のとおりだった。

**B4. 漂流物の山は「新しい操作が無い」ではない（新しい命令が要る）**
- 確かめた: 黄金箱の「秘宝の3択」は、宝箱の場面で**開け役1人**が選び、選ぶまで立ち去れない形（`game.ts:1125-1183`・`votes.ts:21`）。晶石の祭壇は、キャラごとの「あとでやる仕事」（`Hero.cardTask = 'altar'`。`rooms/behaviors/altar.ts`）。計画の「黄金箱の3択の画面を使い回す」と「だれも待たない = 祭壇と同じ形」は、作りが別物で両立しない。
- 祭壇の形で作るなら、キャラごとに候補3つを部屋に入った時に引いて保存する欄と、**「選ぶ」新しい命令（`heroId` 付き）**が要る。CLAUDE.md §7（P1 扱い）に当たるので、命令に `heroId` を入れ、store の `actorOf` で担当の席に直ることを確かめる。計画 §4・§7 の「新しい操作は無い」を直す。
- 袋が満杯の時、消耗品はお金に換わる（`common.ts:44-52`）。選ぶ画面で袋の空きを見せるか、入れ替えを選べるようにするかを決める（軽い）。
- 候補から外す物: `scourgeElixir`（災厄討ちの秘薬・`source` が災厄。`items/scourgeGear.ts:74`）。計画の「エピック・レジェンド11種類」にはこれが入っている（`consumables3.ts` の10＋これ）。外すと10種類。

**B5. 火薬樽の決め事が足りない**
- 勝ちは「生きている敵が0」（`battle.ts:358-363`）。計画は「ボスを倒したら樽も消える」と書くが、**爆発した後の樽**（倒れるのか・残るのか）、**爆発で倒れた時に「壊すと敵全員に12」が出ないこと**が無い。
- 中ボス（クラーケンの触腕＋幽霊水夫）は「相方が倒れると入る段階」がある（`units.ts:88-96`）。樽は `summoned` の印を付けて相方に数えない、と書く。樽が枠を1つ取ると、幽霊水夫の「仲間を呼ぶ」（`canSummon`）が呼べなくなる。
- bot は敵の並びの最初の敵を狙う（`bot.ts:376`）。樽を並びのどこに置くかで「壊すか」が決まってしまう。測定の数えのために、置き場所（最後）を決める。
- 画面: 樽の長押しの文に「3ターン目に爆発（味方全員12）／先に壊すと敵全員に12」を必ず出す（憲章4）。

**B6. 霧の体・引き潮の「何を数えるか」が未定**
- 霧の体: 毒・火傷の毎ターンのダメージ、反撃、お供、火薬樽の12は「1回の当たり」か。計画は「毒と火傷で削る」と書くので、毎ターンのダメージは上限の外と読めるが、書いていない。背水ブラッド軸（一撃で全吸収）・居合（上限4倍）は、この段階でほぼ働かない（憲章5の軸を1つ止める）。それで良いかを一言。
- 引き潮: 味方のブロックを「吸う（味方から消える）」のか「同じ量を写す（味方に残る）」のか。重装カウンター軸（ブロックの持ち越し）に毎ターン効くので、どちらかで重さが大きく違う。

**B7. 専用の装備を上げる2つは、今のテストを直す必要がある**
- フジツボの鎧・霧払いのランタンは、格がエピックだと決めているテストがある（`lineupPhase1b2.test.ts:66,89`・`lineupPhase1Gear.test.ts:82,114`）。計画 §3-7 の「直す今のテスト」に無い。

**B8. 計画の事実の間違い・ずれ（抜き打ちで見つけた物）**

### C. 軽い（作る時の注意）

- **C1. bot の道選び**: 賢い bot は今の潮だけを見て道を決める（`bot.ts:279-296 walkCostTo`）。潮が開いた時に干潟へ向かい、閉じたら遠回り、を4ターンごとにくり返す心配（推測）。測定で「潮のマスを通った回数」と一緒に「向きを変えた回数」も数える。簡単な直しは「bot は潮のマスを通らない」。
- **C2. 漂流物の洞は、冒険の半分ほどで出ない**（テーマ4つから2つを混ぜて配る。`randomDungeons.ts:33-38`）。シナリオ2の C2 と同じ。出したいなら「2か所のうち1つは必ずこのシナリオのテーマ」。
- **C3. 潮の切れ目の場所**: 仕切りの切れ目は乱数で行を選ぶ（`generate.ts:57-63`）。潮の切れ目が、いつも通れる切れ目より遠い所に出ると、近道にならない。「潮の切れ目は、施設に近い方」などの決まりを足すか、測定で数える。さらに、脇道が仕切りを横切る所は道のまま残る（`generate.ts:47,67`）ので、海賊の隠れ島・沈んだ神殿・難破船の洞窟への脇道が、いつも通れる切れ目を増やす。
- **C4. 立て札**: 立て札は道のマスだけをたどる（`guide.ts:195`）。脇道が海で切れる海賊の隠れ島には立て札が出ない（推測）。見取り図で光るのは別の仕組みなので困らないが、計画に一言。
- **C5. 戦闘の数が32を割った時の手が無い**: 海の敵14組は、西へ行かないパーティには会わない。幽霊船団の悪さも西だけ。計画は「40を越えたら海を減らす」だけ。下に割ったら陸を足す、と書く。
- **C6. 時間の札の文字**: 「満ち潮・引き潮」は、潮の神官の段階（戦闘の中。`isles.ts` の rule）でも使う言葉。世界の潮と戦闘の潮が別物だと、札に一言（混ざると「ボスの弱点が世界の潮で変わる」と思われる）。
- **C7. 悪さ「幽霊船団」「潮が止まる」も、西・潮を使わないパーティには効きが薄い**。A3 ほどではない（倒せば戻る悪さ・寄り道を閉じる悪さ）が、測定で「効いた回数」を数える（計画 §3-6 の③にある）。
- **C8. ランダムダンジョンのテストのテーマの一覧**（`dungeonShape.test.ts` の `[undefined, 'crystalGrotto', 'sealedLabyrinth', 'outlawDen']`）に新しいテーマを足す（氷漬けの宝物庫も入っていない）。
- **C9. 春の歌の石碑（シナリオ2）も同じ不具合**（`frozenKingdom/events/mapEvents.ts:6`・`placed` 無し）。1行で直るが、シナリオ2の新しい地図の乱数の流れが変わる（指紋のテストに当たるかも）。計画は「記録だけ」。オーナーに一緒に直すか聞く（§5 の4）。

## 5. オーナーに聞くべき事

計画 §8 の5つ（3つの道・災厄・ランダムダンジョン・並び・進め方）は、数も中身も多すぎない。それに次を足す（全部「A（おすすめ）」で進められる）。

1. **潮で閉じ込められた時**（盆地・入り江の中で潮が閉じると、次の満ち引きまで出られない。大海魔が生きていると、1人では詰み）
   - A: 内側からはいつでも出られる（入る向きだけ閉じる）。大海魔の悪さは「今の潮のまま止まる」
   - B: 潮が閉じたら、中のキャラを首の外へ流す
   - C: 盆地・入り江の首には潮を使わない（潮は仕切りの切れ目だけ）
2. **加護「満ちる霧」**（ダンジョンの中のボス戦で霧の濃さが進む。前に「ダンジョンの中では進めない」と決めた）
   - A: 霧の濃さでなく、戦闘の中に返す（6ターン目から、ボスが毎ターン霧のブロック）
   - B: 霧の濃さのまま。ただし戦闘の後、世界マップの最初の番にまとめて足す（勝ちが先）
   - C: 計画のまま（ダンジョンの中でも進む）
3. **悪さ「呪われた財宝」**（今の呪い2は1〜2ターン目の回復だけ半分で、ほとんど効かない）
   - A: その戦闘の間ずっと減らない呪い（浄化で消える）
   - B: 宝箱の中身の格が1段下がる
   - C: 宝箱を開けるたびに霧の濃さ+1%
4. **春の歌の石碑（シナリオ2）も、潮騒の石碑と同じ直しを今するか**（1行の直し。シナリオ2の新しい地図の並びが少し変わる）
   - A: 一緒に直す
   - B: 計画のとおり記録だけ（7本の最後にまとめて）

（火薬樽と用心棒が近い件は、計画書 §3-2 で一言書いてあるので、質問2の「災厄」の中で見てもらえば足りる。）
