## 3. 見つけた事 A（重い順）

止めるべき物は無い。

### 直すべき（区切り3と一緒に。オーナーに一言）

**A-1. 地図のイベント「難破船の残骸」は、シナリオ1の「打ち捨てられた野営地」の1つ目の選択肢と、判定も結果も同じ**
- 確かめた: 残骸 = `check: { stat: 'dex', slots: 3, need: 2, purpose: 'mechanism' }` → 成功はレアの装備・失敗は8ダメージ（`cursedArchipelago/events/mapEvents.ts`）。野営地 = **同じ判定** → 成功はレアの装備・失敗は毒3（`corruptionKing/events/mapEvents.ts:49-52`）。違いは失敗の中身（8ダメージ / 毒3）と、野営地にある「休む」が無い事だけ。
- 計画の役割の文「流れ着いた樽（消耗品）と違う」は、同じシナリオの中だけで比べていた（計画の時の点検も、シナリオ1とは比べていない）。同じ地図に並ぶ事は無いが、憲章 §4「名前だけ・数字だけ違う物が無いか」には当たる。
- 直し方の案【提案】: **潮に結びつける**（群島にしか作れない形にする）。例:「引き潮の間は船室まで歩いて入れる（判定なしでレア）／満ち潮の間はもぐる判定」。今の `EventOption` には時間帯の条件が無いので、小さいエンジンの直しが要る。作る前にオーナーに案を見せる。

**A-2. 「潮だまり」の役割の文が事実と少し違う（お供のイベントはほかにもある）**
- 計画: 「お供の地図のイベントは群島に無い（突発のイルカは海の上だけ）」。確かめた: 共通の突発イベントに、陸で起きるお供の物がある（`randomEventsK7.ts:132` = 懐き度+8と30G・`:166` ほか）。群島の突発「お供の船酔い」も懐き度+8（全員）。潮だまりの2つ目の選択肢（感知3枠2成功で40G）は、同じシナリオの潮騒の石碑の2つ目と同じ形・同じ額。
- お供は大切にする決まり（CLAUDE.md §5）なので消す話ではない。A-1 と同じく潮に結びつけると、役割がはっきりする（例: 引き潮の間だけ出る／満ち潮では小魚が多くて懐き度が多い）。軽い。

**A-3. 漂流物の洞は、冒険の半分で出ない**
- 確かめた: 群島で選べるテーマは共通3つ＋漂流物の洞の4つ。2か所に、混ぜた順で2つ配る（`randomDungeons.ts assignDungeonThemes`）→ 出るのは2回に1回。計画の時の点検 C2 で「作る時の注意」になったまま、オーナーには伝わっていない。
- プレイヤーに見える事なので、聞く（§6 の A-ア）。直すなら「2か所のうち1つは必ずそのシナリオのテーマ」（シナリオ2の氷漬けの宝物庫も同じ形）。新しい地図の指紋のテストは取り直し。

**A-4. 漂流物の山: 袋が満杯だと、選んだエピック以上の品が40Gほどに換わるだけで、入れ替えができない**
- 確かめた: 袋は4つ（`POUCH_LIMIT = 4`）。満杯だと `addItem` がお金に換える（エピックは 2×15+10 = 40G）。選ぶ画面（`HeroTasks.tsx` の `Flotsam`）は全画面で、**閉じるボタンも「あとで」も無い**（選ぶまで、道具袋を開けて使う・渡す事もできない）。
- 点検 B4 の決まり（「お金に換えると画面に出す」）どおりに作ってある。作った人の間違いではない。ただ、テーマの役割「強い消耗品を選んで持ち帰る」が、袋が満杯の人には働かない。袋4つは満杯になりやすい。入口の文に注意は出る（`detour.ts`）。
- 直し方の案【提案】: 満杯の時は「袋の品1つと入れ替える」を選べるようにする（点検 B4 に「入れ替えを選べるようにするかを決める」とあった物）。オーナーに聞く（§6 の A-イ）。

### 軽い

**A-5. 漂流物の洞の2〜3行目は、古代の晶洞の「少し弱い版」**: 晶洞 = 戦闘22・強敵8・イベント30・宝箱30・休憩10 ／ 漂流物 = 25・15・30・15・15。説明の文も「イベントと宝箱が多い」と「やや多い」。役割の違いは4行目の部屋だけで出ている（計画の数字どおり・オーナーも OK 済み）。しかも3行目には宝箱が出ない決まりなので、宝箱15は2行目だけに効く。数字は後の調整でよいが、「消耗品の洞」らしく（例: 宝箱の中身が消耗品寄り）するかは、その時に。

**A-6. 潮の切れ目が、いつも通れる道のすぐ近くに出る心配（推測）**: 作業者が点検 C3 を受けて「潮の切れ目は町・ダンジョンに近い切れ目から」に変えた（`generate.ts`）。しかし、ダンジョンへの脇道が仕切りを横切る所は、道のまま「いつも通れる切れ目」になる（6本の仕切りのうち3本: 海賊の隠れ島・沈んだ神殿・難破船の洞窟への道）。ダンジョンに近い切れ目 = その道のすぐ近く、になりやすく、潮の切れ目が近道にならない。動かしていないので推測。測定で「潮のマスを通ると何歩短くなるか」を数えるか、道が横切る仕切りでは「道からいちばん遠い切れ目」を潮にする。

**A-7. 船を借り忘れた時の引き返し**: 新しい地図は、町4つ・難破船の洞窟・沈んだ神殿・最後の船まで、船なしで歩ける（計画どおり）。船は港町アルカ（行40）の依頼だけ（`towns.ts`）。前の地図は海ですぐ気づいたが、今は2つ目の鍵（海賊の隠れ島・行16）で初めて困り、港まで引き返す事がある（止まりではない。冒頭の物語に「船を貸そう」はある）。海のマスの説明「船が必要です」に「港町アルカの老船長から借りられる」を足す、で足りる。

**A-8. 漂流物の山のご褒美の重さ（後の調整の時に）**: 候補の「残り2つ」はレア以上の全部から引くので、エピック・レジェンドも入る（`flotsam.ts rollFlotsam`）。レジェンドの消耗品（神々の神酒・不死鳥の羽根・時の砂時計）が候補に入る割合は、手で数えて4〜5割（推測）。4人なら1回の洞でレジェンドが約2個。計画の文（「1つはエピック以上」）どおりだが、難しめを守る調整の時に数える。

**A-9. 物語の文と地図のずれ**: 冒頭「島々は孤立してしまった」・悪化25%の文「幽霊船が増える」（実際に増えるのは陸の敵。前からの作り）。今は歩いてつながっている。文を直すかは区切り3の時に。
