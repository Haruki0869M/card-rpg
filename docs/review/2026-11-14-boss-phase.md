## 0. 計画どおりにできなかった所・自分で決めた所

- **夢の迷宮の写し3体は段階が2つあるのに、割り当て表の決まりは1つずつ。** 2つ目の段階は「同じ決まりをもう一度・強めて見せる」にした【提案】（夢の白の女王 = 侍女をもう一度呼ぶ・夢の亡霊提督 = 癒し封じ＋呪い・夢の砂塵の王 = 裏返った弱点が表に戻る）。表に無い新しい決まりは作っていない。オーナーに確かめてほしい所。
- **凍結の決まり**: 凍てつく王国には「凍結は単体に1だけ」の決まり（テスト）があるので、白の女王の「永久凍結」は「全体に氷10・狙った1人に凍結1」にした（表の「凍結の前触れ」の形は保った）。
- **取り巻き**は新しい敵を作らず、今ある敵を呼ぶ（絵があるため）【提案】。名前は表の案から変わった所がある（氷晶のかけら → 氷柱の虫・影の分身 → 土人形（かばう）・作業ロボ → ベルトコンベアの機械兵・大機械の部品 → ゼンマイの犬・夢の侍女 → 子守歌の鳥）。報酬なし・レベルは今の増援の決まり（呼んだ敵とのレベルの差を保つ）。
- **数字は動かしていない（柱4）。** 測った結果、段階ごとのボスの行動は全部 1 以上になったので、境目の% は今のまま。一方で「負けの一部がボス戦の全滅に移る」は起きなかった（§4）。境目の% を動かしても全滅は増えない見込みなので、ここで止めてオーナーに相談する。
- main の 0c07ca9 の型チェックの失敗（format.ts の本気の札の型）は、まとめ役の直し（de451ed）を取り込んだ。

### 測定の見方
- **段階ごとのラウンドが1以上**: できた（どのボスも、どの段階でも 1.3〜2.3 行動）。前から1以上あったので、計画書の推測（「段階を見る前に終わる」）は当たっていなかった。

- クリア率はほぼ同じ（±1〜2種）。仕組みだけでは難しさは変わらない、が今回の結果。

## 4. 心配な点

1. 開幕の一手は、ほとんど「BREAK で止まる大技」にした。賢い bot が 6〜8割止めるので、ボスが怖くならない。止められても効く形（例: 呼ぶのは止まっても、境目を切った時点で1体は出る）にするか、「止まらない開幕の一手」を混ぜるかは、設計の判断なのでオーナーに相談したい（作っていない）。
2. HPバーの線はHPの数字に重なる（数字は読める。360×640 の画像で確かめた）。
3. 前からのデータの重なり: いくつかのボスで、元の行動と段階の行動が同じID（例: 砂蠍王の `armor`・砂の守護獣の `guard`）。予告の表示と実際の行動が、元の行動の数で動く。今回は触っていない（新しく足したIDは重ならない事をテストで確かめた）。
4. 巻き戻し（脱皮・時を巻き戻す）は、境目を大きく越えて削った時ほど戻る量が多い。一気に削るビルドが少し損をする（BREAK か呪いで止められる）。
5. 取り巻きのレベルは「呼んだ敵とのレベルの差を保つ」ので、大機械の犬・夢の白の女王の鳥は弱め。
