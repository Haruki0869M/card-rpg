# 駒を Gemini で作る指示文（基本職16人・2026-11-14）

オーナーの決定（2026-11-14）: 駒は基本職の16人分だけ作る。転職しても、基本職の駒を使う（`HeroPiece.tsx` の `baseClassId`）。ChatGPT では見本の人を再現できなかったので、Gemini で作る。

## 進め方（スマホで）

1. Gemini で**新しい会話**を始める。モデルは、オーナーのアプリの「3.1 Pro」（画像を作る道具を使う）。
2. 1人ずつ、下の指示文（決まりの文も入っています）を貼る。添付は `人物-<職>・<男|女>.jpg`（転職の立ち絵の時と同じ画像）。
3. **1枚目ができて合格したら**、その駒の絵も2枚目に添付する（形・塗りをそろえるため）。
4. できた絵は、このセッションに貼る（まとめて良い）。

## 決まりの文（各指示文の頭に入っています）

```
私のゲームの主人公を、ボードゲームの盤に置く「チェスの駒」の絵にしてください。添付の1枚目が、このキャラの立ち絵です。2枚目を添付した時は、それが駒の見本です（形・塗り・質感・大きさを、見本にそろえてください）。

【絵柄（いちばん大事）】
・かわいい、ちびキャラのおもちゃの駒。立体感（3D）はあるが、リアルにはしない。
・2〜2.5頭身。頭はとても大きく丸い（駒全体の高さの4割くらい）。体は短く、ずんぐり。
・顔はシンプルなアニメ顔。大きな目、小さな鼻と口。リアルな顔・リアルな体つき・大人の体型にしない。
・形は単純で丸い。鎧の細かい線・布のしわ・細かい模様・リアルな陰影は入れない。色の面を大きく、はっきり。
・質感は、なめらかでやわらかい、つや消しのプラスチック（ソフビ人形やボードゲームのおもちゃの駒）。
・英語で言うと: cute chibi vinyl toy figure shaped like a chess pawn, 2.5-head proportions, huge round head, short stubby body, simple rounded shapes, smooth soft matte plastic, simple anime face with big eyes, stylized, not realistic, no fine detail.

【形】
・全体のシルエットは、チェスのポーン（歩兵）の駒。上が大きな丸い頭、その下に短い胴、胴のすそが少し広がって終わる。
・腕は短く、体にくっつける。持つ物は小さく、体の前か横で縦に持つ。
・胴の下は、服やマントのすそが、駒の胴のようにすべすべの円すい形にまとまる。足は見せない。胴の色は、キャラの服の色。
・胸や腰に、輪・段・ドーナツの形を付けない。
・台座・丸い台・地面・床の影は描かない（台座はゲームが描きます）。すその一番下が、そのまま絵の下のほうで平らに終わる。

【キャラ】
・髪の色と髪型・瞳の色・服の色・目印の小物は、1枚目の立ち絵と同じ。同じ人だと、ひと目で分かるように（顔や服は、ちびキャラに単純にしてよい）。
・持つ物は、下に書いた物だけ。片手で持つ武器なら、もう片方の手は空。

【見せ方】
・全身。やや斜め前から、少し上から見下ろす角度。光は左上から。
・背景は真っ白の無地（光・影・模様・グラデーションを入れない）。
・正方形。駒は真ん中に。上と左右に少し余白。駒の一番下が、絵の下のほうに来るように。
・描かないもの: 文字・サイン・枠・景色・ほかの人や動物。
```
