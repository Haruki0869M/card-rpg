# ChatGPT 用の指示文: 転職しても同じ人に見える立ち絵（80枚）

設計は `docs/art/hero-lineage-design.md`。この一覧は `gen-lineage.py`（Claude の作業用）で作った。

- 毎回3枚を添付する: 1枚目「人物-<基本職>」、2枚目「絵柄の見本」、3枚目「今の絵-<番号>」。
- 添付の絵は `C:/dev/card-rpg-assets/chatgpt-hero-lineage/` にある（オーナーには会話で送る）。
- 保存の名前は `転職-<職ID>-<male|female>.png`。
