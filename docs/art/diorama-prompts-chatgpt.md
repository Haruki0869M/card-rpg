## ① 最初に1回だけ貼る決まり

```
これから、ボードゲーム風のファンタジーRPGの「世界マップ」に置く、小さな部品の絵をまとめて作ってもらいます。全部の絵で、次の決まりを必ず守ってください。

【絵柄】
・墨の線（太さが少し不ぞろいの手描きの線）＋くすんだ淡い水彩。絵本のような手描きの雰囲気。
・添付した2枚の絵（木と村）と同じ絵柄にそろえる。
・輪郭の線は少し太め。とても小さく表示しても形が分かるように、形ははっきり・シンプルに。

【見る角度】
・斜め上（約45度）から見下ろす、ボードゲームの駒のような2.5Dの見え方。全部の絵で同じ角度。

【光と影】
・光は左上から当たる。
・地面に落ちる影は描かない（影はゲームのプログラムが描きます）。

【背景と置き方】
・背景は透明（PNG）。地面・台・草地の丸い敷物なども描かない。物だけ。
・1つ1つの物は離して置き、重ねない。周りに十分な余白をとる。
・物の足元（地面に接する所）は、それぞれの区画の下の真ん中に来るようにする。

【描かないもの】
・文字・数字・サイン・透かし・枠・番号札。
・人・動物・キャラクター。
・六角形のマス・景色・空・地平線。
```

## うまくいかない時の直し方（同じ会話で、そのまま送る言葉）

- 背景が白い・模様がある → `背景を透明にして、同じ絵をもう一度作ってください。`
- 地面の丸い敷物や影が付いた → `地面の敷物と影を消して、物だけにしてもう一度作ってください。`
- 物どうしが重なった → `物どうしを離して、周りに余白をとって、もう一度作ってください。`
- 1つだけ気に入らない → `〇番だけ、〔直してほしい所〕にして、ほかはそのままでもう一度作ってください。`
- 絵柄が変わってきた → もう一度「① 最初に1回だけ貼る決まり」を貼ってから、依頼を貼り直す。

全部が完全でなくても大丈夫です。少しの影や余白のずれは、私が切り分ける時に直します。

## Claude の作業メモ（切り分けと組み込み）

- 切り分け: 透明の部分で区切られた「かたまり」を1つずつ取り出す（並べた順＝上の段の左から番号）。透明でなかった時は、今までどおり背景を切り抜き、**体の中の穴を埋める処理**（`scripts/art/fill-holes.mjs`、ブランチ `claude/art-holes-782bf6`）を通す。
- そろえ方（設計書の決まり）: 足元を下の真ん中に。大きさは小物 256px・木 384px・施設 512px・目印 1024px 幅。webp。
- 名前（提案）: `tree/plains-1|2`・`tree/forest-1..4`・`prop/hill|rock|grass|flower|mushroom`・`place/town|capital|shrine`・`landmark/tent`・`skyline/demon-castle`。最終的な置き場と名前は、箱庭のセッションの `src/components/world/landscape/`（パーツの一覧）に合わせる。
- 今の `place/town`・`place/capital`・`place/shrine` の絵は、試作の見え方を比べてから差し替えるか決める（オーナーに見比べの写真を見せる）。
