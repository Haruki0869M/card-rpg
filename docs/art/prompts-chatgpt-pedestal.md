## 1. 台座の本体 保存の名前 `piece-base.png`
```
ボードゲームの盤に置く「立体のミニチュアの駒」の、丸い台座だけの絵を1枚作ってください。添付の絵（この台座の上に立つ駒）と同じ、手描きの線とくすんだ水彩のような塗りにそろえてください。

【形】
・丸い円盤の台座。斜め上から少し見下ろす角度（上の面が横長のだ円に見える。横:縦 = 4:1 くらい）
・厚みは、だ円の横幅の8分の1くらい。側面がしっかり見える
・上の面: 深い焦げ茶の木。木目がうっすら。真ん中には何も置かない（あとで駒を立てます）
・上の面のふち: 細い真ちゅう色（くすんだ金）の金属の輪
・側面: 上と下に細い真ちゅう色のふち。その間は「明るい灰色の無地の帯」（模様なし。左右の端が少し暗くなる程度の陰影だけ）。この帯は、あとでゲームがプレイヤーの色に塗ります
・正面から見て左右対称

【見せ方】
・台座だけ。人・駒・草・地面・床の影は描かない
・背景は透明（PNG）。透明にできなければ、真っ白の無地。市松模様は描かない
・横長（1536×1024）。台座は真ん中に、横幅いっぱい近くまで大きく
・描かないもの: 文字・サイン・枠・宝石・帯の模様

返事は絵だけで大丈夫です。
```

## 2. 銘板の枠（4つ） 保存の名前 `piece-plates.png`
```
ボードゲームのミニチュアの駒の台座の前に付ける、小さな「盾の形の銘板」の絵を作ってください。添付の絵（この駒の台座に付けます）と同じ、手描きの線とくすんだ水彩のような塗りにそろえてください。

【中身】
・同じ形・同じ大きさの盾形の銘板を4つ、横2つ×縦2段に、十分に離して並べる
・形: 上が平らで下がとがった、小さな紋章の盾。正面から見た形。ふちが少し盛り上がった金属の枠
・4つの違いは、枠の金属の色だけ
  上の段（左から）1. 銅（赤みのある茶色の金属） 2. 銀（青みのある白い金属）
  下の段（左から）3. 金（明るい黄金） 4. 紫の水晶（紫の宝石を削って作った枠。ふちに小さな光）
・枠の内側は、4つとも同じ「深い紺色の無地」。内側には何も描かない（あとでゲームが武器の絵を入れます）

【見せ方】
・背景は透明（PNG）。透明にできなければ、真っ白の無地。市松模様は描かない
・正方形（1024×1024）
・描かないもの: 文字・数字・武器・紋章の絵・リボン・影・サイン・枠

返事は絵だけで大丈夫です。
```
