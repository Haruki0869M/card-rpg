# 駒（ちびキャラ）の指示文（基本職16人・2026-11-14）

オーナーの決定（2026-11-14）: 駒は基本職の16人分だけ作る。転職しても、基本職の駒を使う（`HeroPiece.tsx` の `baseClassId`）。
チェスの駒の形の案はやめて、リセット。立ち絵のキャラを、オーナーの下書き（`docs/art/piece-chibi-sketch.jpg`）のような約2.5頭身のちびキャラにする。

## 進め方（スマホで）

1. 画像AIで**新しい会話**を始める。
2. 1人ずつ、下の指示文（決まりの文も入っています）を貼る。添付は1枚目 `人物-<職>・<男|女>.jpg`、2枚目 オーナーの下書き（`piece-chibi-sketch.jpg`）。
3. **1人目が合格したら**、そのちびキャラの絵も3枚目に添付する（頭身・塗りをそろえるため）。
4. できた絵は、このセッションに貼る（まとめて良い）。

## 決まりの文（各指示文の頭に入っています）

```
添付の1枚目のキャラを、ちびキャラ（SD）にして描いてください。2枚目は、オーナーが手で描いた「ちびキャラにした時の見本」の下書きです。1枚目の人が、2枚目のような姿になるイメージです。3枚目を添付した時は、それが合格したちびキャラです（頭身・塗り・大きさを、それにそろえてください）。

【頭身と形（いちばん大事）】
・約2.5頭身。頭は大きく、体は小さい。2枚目の下書きと同じくらいの頭と体の比率。
・髪は、1枚目と同じ髪型を、毛の束を大きくまとめて描く。目は大きめ。
・手足は短いが、ぬいぐるみのように丸くしすぎない。鎧・服・マントの形は、1枚目の特徴を残して、大きな形に単純にする。
・ポーズは2枚目のように、足を少し開いてしっかり立つ。武器は1枚目と同じ持ち方を、ちびの体に合わせる（2枚目の剣のように、片手で斜め下へ向けて持つ、など）。
・マントやすそは、2枚目のように少し横へなびいてよい。ただし、体の幅の1.5倍くらいまで。

【塗り】

・ちびなので、細かい模様や線は減らして、色の面を大きく、はっきり。小さく表示しても、誰か分かるように。

【キャラ】
・髪の色と髪型・瞳の色・服と鎧の色・目印の小物は、1枚目と同じ。同じ人だと、ひと目で分かるように。

・英語で言うと: chibi (super-deformed) version of the character in image 1, about 2.5 heads tall, big head, small body, same pose idea as the sketch in image 2, same anime painting style and colors as image 1, simplified details, full body, standing, plain white background, no pedestal, no ground shadow.
```
