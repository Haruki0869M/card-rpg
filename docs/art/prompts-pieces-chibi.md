# 駒（ちびキャラ・転職しても使える）の指示文（基本職16人・2026-11-14）

オーナーの決定（2026-11-14）: 駒は基本職の16人分だけ作る。転職しても、基本職の駒を使う（`HeroPiece.tsx` の `baseClassId`）。
チェスの駒の形の案はやめて、リセット。立ち絵のキャラを、手描きの下書き（`docs/art/piece-chibi-sketch.jpg`）のような約2.5頭身のちびキャラにする。
転職しても使えるように、ジョブが分かる物（専用の鎧・ローブ・帽子・武器）は描かず、顔・髪・瞳・目印の小物・系統の色だけで、その人を表す。武器は持たない（オーナーの決定 2026-11-14・案A）。
絵を作るのは ChatGPT。ChatGPT が使えない間は Mose（Meta 社の AI。画像の添付ができる）。Gemini には頼まない（オーナーの決定 2026-11-14）。

## 進め方（スマホで）

1. ChatGPT（使えない間は Mose）で**新しい会話**を始める。
2. 1人ずつ、下の指示文（決まりの文も入っています）を貼る。添付は1枚目 `人物-<職>・<男|女>.jpg`、2枚目 手描きの下書き（`piece-chibi-sketch.jpg`）。
3. **1人目が合格したら**、その駒の絵も3枚目に添付する（頭身・塗りをそろえるため）。
4. できた絵は、このセッションに貼る（まとめて良い）。
