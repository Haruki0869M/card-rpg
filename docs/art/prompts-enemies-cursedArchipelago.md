# 呪われた群島：敵の絵の指示文

新規23体分（Midjourney に貼る形）。亜種5体（熾火の大蟹・雷クラゲ・呪われた溺れた水夫・毒鮫・嵐の海の魔女）は元の絵を使い回す。ボスの変身5段階を含め、画像は計28枚。

作風: 今ゲームに入っている敵の絵（森の狼・樹木の番人）に合わせる。`--sref` で公開中の敵の絵2枚を指定し、画面の「Style References」は空にする。`docs/art/style-reference.png` は使わない。
持たせない物は文の中に書かず、最後の `--no` にまとめた。このシナリオの色: 青緑の霧、濡れた木と錆びた金具。幽霊は半透明で青白い。
白背景・1体のみ・左向きの3/4・全身。切り抜きは `scripts/art/build_art.py`。
