### 1-2. ビルドを作る4つの掛け算
1. ジョブの能力（今の職＋前の職から持ち越した能力）
2. スキルカード：手数・一撃・属性・状態異常・ブロック変換・スロット操作・フォーカスの使い方・お供との連動
3. 武器の横の広がり：同じ剣でも、火力型・火傷型・吸血型・スロット数型（1枠の一撃か5枠の多段か）・コスト軽減型
4. 装飾品：ルールを書き換える効果（例「毒のダメージ分ブロックを得る」「完全成功でマナ回復」「お供が2回動く」）

**装備の決まり**
- 鎧はレア以上なら必ず固有の効果を1つ持たせます。例：被弾時に反撃、開幕にブロック、特定属性の無効・吸収、移動・野営のボーナス。
- 武器は同じレア度の中に、属性型・状態異常型・スロット数型・特殊能力型（貫通・吸収・連携強化）を並べます。

## 2. スマート抽選（カードが多くても狙ったビルドを尖らせられる）
- **カードにタグを付けます。**
  - 例：炎・氷・雷・聖・闇・毒・火傷・連撃・一撃・ブロック・高コスト・低コスト・お供・フォーカス・回復・状態異常。
  - 効果から自動で付くタグと、手で付けるタグの両方を使います。
- **報酬の3枚の抽選**
  - 2枚は重み付きで抽選します。今のデッキ・武器・装飾品のタグと重なるほど出やすくします。
  - 重みは「1＋0.5×重なったタグ数」で、上限は3倍。数値は `balance.ts` で調整できます。
  - 残りの**1枚は完全ランダム**です。新しい方向への発見を残します。
- 町のショップのカードの品揃えにも、弱めに同じ重みを掛けます。

## 3. 転職

### 3-1. 転職できる場所（v1から：神殿のみ → 段によって分ける）
| 転職 | できる場所 |
|---|---|
| 基本 → 中位 | 町・野営・ダンジョンの休憩部屋・神殿（どこでも、ただし戦闘中は不可） |
| 中位 → 最上位 | 神殿、または町の聖堂 |
| 中位 → 特殊 | 神殿、または各特殊ジョブの「祭壇」（マップの特別なマス） |

- レベルアップの時は「〇〇に転職できる」と知らせるだけで、その場では転職しません。
- 条件の進み具合（例：属性で倒した数 7/10）は、パーティ画面でいつでも見られます。
- 神殿はマップの通り道の近くに置き、寄り道が1〜2手番で済むようにします。

### 3-2. 経験値の持ち越し
- 転職する時、次のレベルに向けて貯めていた経験値は**捨てずに新しい職のLv1へ持ち越します**。
- ただし持ち越せるのは**新しい職のLv2に上がる手前まで**です。
- 上限を付ける理由：上限がないと「転職Lvのまま稼ぎ続けて、転職した瞬間に何レベルも上がる」遊び方が一番得になります。転職するとLv1に戻るという仕組みの意味がなくなります。
- 今の作りでは、転職Lvに達した後もその職のまま普通にレベルが上がります。成長の上乗せもすべて引き継ぎます。だから「転職が遅れても損をしない」は、この上限付きの持ち越しで満たせます。

### 3-3. 転職した時のカード
- 転職すると、その職を象徴する専用カードが**3枚出て、1枚をその場で選んでもらえます**。
- 残りの2枚は、その後の報酬に出るようになります。
- 転職先の残りの専用カードも、その時点から報酬に出るようになります。

## 4. お供（ペット）※v2.1で全面改訂

### 4-1. 基本の決まり
- どのジョブでも、旅のお供を1匹まで連れて歩けます。新しい子を迎える時、もう1匹いれば入れ替えるかを聞きます。
- 獣使い系統（獣使い・ビーストマスター）が連れていると、**効果の数字や対象の数が2倍**になります。下の表のカッコ内の数字です。
- 同じ種類のお供を、仲間の何人かが連れていても構いません。
  - 状態異常は重ねがけしても強さは変わらず、続く長さが延びるだけなので、強くなりすぎません。
- **鳥（オカメインコ・文鳥・セキセイインコ・シマエナガ）は肩か頭の上**、それ以外は足元に表示します。小竜は浮いています。
- 召喚士の幻獣・死霊術師の骸骨・忍者の分身・機工士の砲台・竜騎士の竜は、ジョブの能力なのでペットとは別枠です。

### 4-3. 愛着の仕組み（強さは永久に上がらない）
1. **うちの子図鑑・マイペット**
   - 仲間にしたお供と色は、伝承の書の「うちの子図鑑」に記録します。
   - 懐き度が♡5になるか、一緒に3回クリアしたお供は「マイペット」に登録できます。名前と色もそのまま残ります。
   - 次の冒険からは、最初の町で少しのお金（30G）を払うと、最初から連れて歩けます。
   - 記録は遊んでいる端末に保存します。協力プレイでは、それぞれが自分のマイペットを連れて来ます。
2. **懐き度♡1〜♡5**
   - 一緒に歩いたマスの数と戦闘の回数で上がります。強さは変わりません。
   - ♡3でリボンかバンダナが付きます。
   - ♡5で特別な待機の動き（ハートが出る、羽繕いなど）が増え、戦闘ログの文が親しげになります（例「〇〇が得意げに胸を張った！」）。
3. **なでる（鳥はカキカキ）**
   - 野営とダンジョンの休憩部屋で、お供をタップするとハートと鳴き声が出ます。
   - 1回の冒険で最初の1回だけ、フォーカスが1回復します。
4. **戦績に功労賞**
   - クリア・ゲームオーバーの戦績画面に1行で表示します（例「旅のお供：〇〇（オカメインコ・ルチノー）／活躍 14回」）。

## 5. 突発ランダムイベント（世界マップ）

### 5-1. 基本ルール
- **起きる場所**：何もない普通のマス（平原・街道・森・沼・山など）に**移動し終えた時**です。1マス進むごとではありません。
- **確率**：約20%（`balance.ts`）。
  - 同じキャラに2手番続けては起きません。
  - 夜や侵食度が高い時は、悪いイベントの割合が上がります。
- **見せ方**：0.3秒の「！」の演出のあと、中央のイベント窓（金の四隅枠）を開きます。1画面で選べます。
  - 判定がある選択肢には、**使う能力値と成功率%を最初から表示します**（今のイベント窓と同じ仕組みです）。
- **選ぶ自由**：悪いイベントや戦闘でも、必ず次のどれかを用意します。理不尽に必ずダメージを受ける、ということはありません。
  - 能力値の判定で突破する
  - お金やフォーカスで解決する
  - 逃げる・迂回する
- **データ**：`src/content/common/randomEvents/` に1イベント1ファイルで置きます。
  - 結果はすべて、今あるイベント結果の部品（登録表）を組み合わせて作ります。
  - 足りない部品は新しく作ります（§5-3）。
- 能力値は今の7つ（力・体力・知力・感知・器用・素早さ・運）を使います。
  - レビュー案にあった「信仰判定」は、知力または感知に置き換えます。聖系統のジョブには成功率の上乗せを付けます。

## 6. レビュー案から直した点・採用しなかった点
| レビュー案 | 扱い | 理由 |
|---|---|---|
| 信仰判定 | 知力・感知に置き換え | 能力値に「信仰」がないため。聖系統への上乗せで雰囲気を残します |
| 超過経験値をそのまま持ち越す | 上限付きで採用（Lv2の手前まで） | 上限がないと、転職を遅らせて稼ぐのが一番得になってしまうため（§3-2） |
| 仮面商人の「最大HPの25%を支払う」 | 今のHPを最大HPの25%分失う | 最大HPを永久に減らすと、ローグライトでは取り返しがつかず重すぎるため |
| 仮面商人の「全能力値+1」 | ランダムな能力値+1 | 能力値1は成功率に直結します。全部+1は他の報酬と比べて強すぎるため |
| 突発イベントを1回の移動ごとに | 移動し終えたマスで判定 | 今の移動は1手番に何マスも進みます。1マスごとだと起きすぎるため |
| フォルダ名 random-events | randomEvents | 他のフォルダの名前の付け方に合わせるため |
| カード460枚それぞれの絵 | 採用しない（属性・種類ごとの絵を使い回す） | 1枚ずつ絵を作るのは現実的でないため。敵230体の絵を優先します |
| お供の色違い（12種類×2〜4色 ≒ 40色） | 採用。ただし絵は色ごとに1枚 | ハチワレ・三毛・パールなどの柄は、色を変えるフィルターでは出せないため。Midjourneyの絵が約40枚になります。絵ができるまでは仮の絵で動きを作ります |
| うちの子図鑑・マイペット | 採用。作るのは K5（伝承の書）の時 | 図鑑の画面と、冒険をまたいだ保存の仕組みを伝承の書と一緒に作るため。懐き度・なでる・功労賞は J3b で先に入れます |
| オカメインコの「次の行動まで先読み」 | 採用 | 敵の次のターンの行動を前もって決めておく仕組みを足します |
