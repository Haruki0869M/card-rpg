- HP/能力値は前半と同じ+8/+6/+4。上乗せ以外と成長幅は元職を維持し、難易度や他職の数値を変更しない。探索は新しい専用ルールを増やさず、役割に合う既存判定へ15〜20%の補助を割り当てた。

- 賭博師はフォーカス満タン時に0成功の回復回数を消費しない。利益のない発動でそのターンの救済を失わせないため。
- 通常の新カードは既存のコスト帯の目安で作成。武器カードは各2枚、コスト1・1枠・基本成功率80%。装備の初期カードとして扱いやすくし、特殊職の専用カードと分けるため。詳細数値はカードデータ、特殊能力の調整値はbalance.specialJobs。

## 3. 自分で判断した所と理由

以下はJ3c実装時の判断で、オーナーの明示決定とは区別する。

- 跳躍のコスト2は、回避と次ターンの大技を兼ねるため。聖王の自分への再臨は、1人でも能力が働くため。この2点は今回オーナーが維持を明示。

- 教皇の転職条件は、指示書の「回復カード成功20回（success:magicでも可）」から回復カード成功を採用。実装の条件・数値は [最上位一覧](../spec.md) と [J3c指示書](./tasks/J3c-top-jobs.md) を参照。

- 分身の追撃は各攻撃効果の基礎威力の半分（切り捨て）。自分のHP支払い・継続ダメージで分身を消費しない。決め技は同名を複数持ってもキャラごとに1戦闘1回、次の戦闘で戻る。奇跡は生存する味方のHPと悪い状態異常を回復し、復活効果にはしなかった。処理の一貫性と役割の区別のための細部で、[spec.md](../spec.md) に記録済み。
- J3cの通信テストではWindowsの0ms待機の累積による時間切れを避けるため仮想時計を使用。同期結果の検証は残した。これは今回の担当者修正より前の変更。
- 冒険の停止調査では、手番制限を弱めず担当者選択を直す方針を提案し、オーナーのOK後に実施。画面確認の再現性と失敗検出のためスクリプトも改善した。
