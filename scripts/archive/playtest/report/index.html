テストプレイ記録：プレイヤー目線の手触り

主ブランチの最新（c0f153f）を自分でビルドして、2人・ふつう・「侵食の魔王」で10の場面を遊びました。コードは直していません。気づいた点を、良い所も含めて正直に書いています。重要度は「大＝遊ぶ人が困る・誤解する」「中＝気になる・迷う」「小＝できれば直したい」です。

まず直したい「大」8つ

  1. 世界マップ: 行き先を選んだ時・歩いている間、下のパネルが画面の半分まで広がり、駒が地図の下の端で隠れる。歩く様子がほとんど見えない（場面3・4）。
  2. 世界マップ: 最初の画面で地図の上の半分以上が暗い霧で、見えている地面と駒は下の方に小さく寄っている（場面3）。
  3. 戦闘: 敵の狙いが「→P1」とだけ出る。2人とも P1 のままだと、誰が狙われるかは小さな顔の丸でしか分からない（場面8）。
  4. 戦闘: 狙う敵を選ぶと、その敵の上に「予測 下の一覧へ」の札が出て、敵の絵がほぼ隠れる（場面8）。
  5. 戦闘: 結果の帯が1行で横にはみ出して切れる（「! 4 DMG 7 BLOCK ぴーちゃんの応援の歌（応…」）。英語の DMG・BLOCK も混ざる（場面9）。
  6. 戦闘: 「ターン終了」を1回押すと、まだ5枚持っている仲間の番も一緒に終わる。小さな注意書きだけで確認が出ない（場面9）。
  7. 報酬: カードの3択がほとんど同じ（レオンは2枚が数字まで同じ。セシルには最初から持っている「ガード」が出た）。選ぶ楽しさが弱い（場面10）。
  8. 戦闘: 敵の番が約1.2秒で終わり、数字や「敵のターン」「ターン2」の帯が次々に重なる。何をされたか追えない（場面9）。

出し方: ふつうに操作。「はじめから」の確認は、保存データを置いてから「新しい冒険」を押して確かめました。

  • 中「新しい冒険」を押した時の確認が、ブラウザ標準の確認の窓（「〜よろしいですか？」）。ゲームの見た目と合わず、スマホではサイトの住所が見出しに出ます。自動の撮影では標準の窓を写せないので、出ることはプログラムの中身で確かめました。
  • 小「つづきから」の下が「・拠点・60G」。世界マップにいるのに「拠点」と出て、先頭に「・」だけ残ります。お金は2人の合計。

  • 良準備画面は1画面にまとまっていて、押す所が迷わない。シナリオの絵も雰囲気があります。

場面3世界マップの始まり

出し方: ふつうに操作（物語の窓 → つづける → 同行を切る・戻す → 移動力の判定）。

  • 大見えている地面と駒が画面の下の方に小さく寄り、上の半分以上が暗い霧。最初に「どこへ行けるか」が分かりにくいです。判定の後はパネルが大きくなって、駒がさらに下へ押されます。
  • 中「移動力の判定」を押すと、0.3秒以内に結果が出ています。スロットが回るドキドキがほとんど無く、全部×の時の「くやしさ」も伝わりにくいです。
  • 中始まりの物語は、最後の段落（「侵食度が100%に達すれば…」）が下の「つづける」の後ろに隠れて読めません。
  • 小上の「×3」（炎の印）と「★4/6」が何の数か、説明がありません（残りの命・フォーカス？）。
  • 良2人の駒は同じマスで左右に並び、重なりません。同行の ON/OFF は顔の色で分かり、1回押すだけで切り替わります。

場面4移動 → 到着 → 突発イベント（0.3秒おき）

出し方: 保存データを書き換え（移動力を3、乱数の状態を7、所持金200G）。突発イベントが起きる乱数の値を探して使いました。

  • 大移動を決めた瞬間、下のパネルが画面の半分まで広がり（中身は「移動中… 0/2マス」の1行だけ）、地図が狭くなって駒が地図の下の端で半分切れます。行き先を選んだ時も、駒が「丘（移動力2）」の帯の後ろに隠れます。
  • 中行き先のマスには「3」と出ていたのに、歩く時は「1/2マス」。「使う移動力」と「マスの数」が別の数字なので混乱します。
  • 中歩くのは約0.6秒と速いのに、到着 → 暗転 →「！」→ 窓まで約1.2秒待ちます。歩く所を見せて、待ちを短くしたほうがテンポが良さそうです。
  • 小到着の瞬間、2人の駒が横に4〜5px動きました（地図の位置の調整）。目で見て気になる程ではありません。駒の重なりはありませんでした。
  • 良「！」の演出と窓は重ならず、順番に出ます。

場面5お供を迎える（迷い鳥の口笛）

出し方: 場面4の続きをそのまま操作（エサを買う → 先へ進む → 名前「ぴーちゃん」）。

  • 中毛色の「抽選」の演出がありません。迎える画面を開いた時にはもう「黄緑 出会った時の毛色です」と出ています（0.3秒おきに2.4秒撮って変化なし）。「何色かな？」のワクワクを作れる場面です。
  • 中迎える画面の下半分が空いていて、後ろの地図が透けて見えます。お供の絵は画面の幅の4分の1ほど。愛着を作る一番の場面なので、もっと大きく見せたいです。
  • 小地図でも戦闘でも、インコは勇者の横の胸の高さに浮いていて、「肩に乗っている」ようには見えにくいです。
  • 小「お供のおやつを差し出す」の下に「お供のおやつを払う」「お供のおやつを持っていません」と似た文が2行。上の「突発」の札は字が小さく読みにくいです。
  • 良セキセイインコの絵がとても可愛いです。名前を付けたらすぐ地図で一緒にいる流れも短くて良いです。

場面6町（切り替え・買い物・聖堂）

出し方: 保存データを書き換え（2人を王都へ戻す・所持金300G・レオンを剣士Lv5／中位の剣豪Lv3に）。転職の条件「0/10」などを見るため、剣豪の状態も作りました。

  • 中上の「P1・レオン：利用中」「P1・セシル：利用中」がどちらも「利用中」。今どちらを操作しているかは枠の色だけで分かります。
  • 中セシルに切り替えても、上の帯のお金はレオンの「270G」のまま。中の行は「300G」で、食い違います。
  • 中買った時の手応えがありません（ボタンが「売り切れ」に変わるだけ）。指輪を誰が着けたのかも出ません。
  • 中聖堂: 侍・魔剣士は「条件：刀を装備して敵を10体倒す（0/10）」が、鍵の欄にもう一度出ます。剣聖は「条件 0/15」と「Lv4で転職できる」の2つがあり、両方要るのか分かりにくいです。
  • 小タブの「売却」が右で切れていて、横に動かせると気づきにくいです。カードの「0／1／2」の行（成功の数）や記号は、初めての人には意味が分かりません。「8ワールドターン」も分かりにくい言葉です。
  • 良転職先の能力が《》で2つ並び、◎○で得意な武器も分かります。「中位」「最上位」「特殊」の札も見やすいです。

場面7ダンジョン（探索力の判定 → 歩く）

出し方: 保存データを書き換え（2人を翠の神殿の入口へ・セシルに子狼のお供「ころ」）。歩く画面は、場面10の戦闘の後に続けて操作しました。

  • 中入った直後は「扉を開ける」も矢印もすべて暗く、先に「探索力の判定」を押す必要があります。押せない理由が書かれていません。
  • 中戦闘の後の部屋で、左右の通路の先が真っ黒な四角に見えます（壁の絵が抜けているように見える）。
  • 小「1歩・扉で1歩（向くのは0歩）」が折り返して読みにくいです。「左へ」を押すと歩数が1減るので、「向きを変えるだけ」だと思うと驚きます。
  • 小誰の番かが、右上の小さな顔2つでしか分かりません。
  • 良一人称の通路の絵に雰囲気があり、扉の赤い縁取りとドクロで「この先は戦闘」と分かります。

場面8戦闘：敵を選ぶ・味方を選ぶ

出し方: 保存データを書き換え（最初の部屋の敵を森の狼2体・毒キノコ1体に）。

  • 大敵の狙いが「→P1」。今回のように2人とも P1 だと、どちらが狙われるかは小さな顔の丸でしか分かりません。名前（レオン・セシル）で出したほうが確実です。
  • 大狙う敵をタップすると、その敵の上に「予測 下の一覧へ」の札が出て、毒キノコの絵がほぼ隠れます。カードを選んだ時点で敵の絵も小さく縮みます。
  • 中流れが「カード → 敵 → 発動」の3回。敵を選ぶ前の「発動 敵をタップ」は押せるのか分からない見た目で、選んだ後の「発動 運に任せる」は言葉の意味が分かりにくいです。
  • 中ダメージの予測が2か所で違います。色の帯の下は「完全 7」、下の一覧は「完全：ダメージ9」。
  • 中回復カードでは、「使う人（セシル・金色の枠）」と「回復する相手（レオン・青い枠）」の区別が枠の色だけ。下の予測は「効果は上の表示を確認」が3行並ぶだけで役に立っていません。
  • 中セシルのお供の子狼が、レオンの足元に立っています。誰のお供か分かりにくいです。
  • 小HPが満タンの味方にも回復を使えて、何も起きません（注意が出ない）。手札が重なって「ストライク」が「ストライ」で切れます。
  • 良敵の上に「誰に・何を・いくつ」の予告が出るので、作戦を立てやすいです。味方を選ぶ時は「選択中：セシル」と文字でも出ます。

場面9戦闘：お供のカットイン・能力・数字の重なり

出し方: 場面8の続きをそのまま操作（レオンがカードを3枚使う → ターン終了）。0.25秒おきに撮りました。

  • 大3枚目を使った時の結果の帯が1行で、画面の外にはみ出して切れます（「! 4 DMG 7 BLOCK ぴーちゃんの応援の歌（応…」）。英語の「DMG」「BLOCK」も混ざります。
  • 大レオンの番の後に「ターン終了」を押すと、カードを5枚持ったままのセシルの番も終わりました。「まだ行動できるキャラがいます」は小さな字で出るだけで、確認がありません。
  • 大敵の番は約1.2秒。「-3」「防御7」「毒+3」「-6」「-6」「HP+3」が画面の真ん中に次々と出て、「敵のターン」「ターン2」の大きな帯が敵の予告や数字の上に重なります。何をされたか追えません。
  • 中ダメージの数字が、キャラの体ではなく画面の真ん中の黒い札に出ます。誰が受けたのか分かりにくいです。
  • 小お供のカットインは、左上の小さな札（「ぴーちゃん：応援の歌！」）だけで、侵食度の帯に重なります。アイコンもインコの絵ではなく赤い鳥です。せっかくの見せ場なので、もっと大きく可愛く出したいです。
  • 良ジョブの能力が「【癒しの祈り】」と名前つきで出るので、何が起きたか分かります。レオンが動き終わると自動でセシルに切り替わるのも楽です。

場面10勝利 → 報酬 → カードを選ぶ

出し方: 保存データを書き換え（敵3体のHPを2にして1回で勝つ）。

  • 大3択の違いが小さすぎます。レオンは「払い斬り」「まとめ打ち」が数字まで同じ（75%・2／3／5）で、3枚とも剣の攻撃。セシルには最初から持っている「ガード」が出ました。予定の「1枚はジョブ・系統・武器種のカード」に変えると、ここは大きく良くなりそうです。
  • 中カードに説明文が無く、数字と記号だけ。「払い斬り」と「まとめ打ち」の違いが画面から分かりません。
  • 中カードを1回押すと、すぐ山札に入ります（確認なし）。押し間違えると戻せません。
  • 小「コモン72%・レア24%・エピック4%」と出ますが、カードの見た目（枠の色）で格が分かりません。
  • 小3枚目が裏返る途中は押せない時間があります。2人分だと「ボーナス → ボーナス → カード → カード → 先へ進む」で5回押します。
  • 小お金は「+10G（2人で山分け）」で、1人5G。少なく感じます（数値の判断はおまかせします）。
  • 良勝利の記録（完全成功・特殊能力の発動の回数）が楽しいです。P1 → P2 の順に「○○の山札に1枚加える」と名前つきで出るので、受け取り方に迷いません。
